# clubfront · 资产清单和规格（白模阶段）

俱乐部的露天前台和大门：印第安维尔斯沙漠，和 desert3d-v2 同一个世界。主角是凉棚下的前台（会员签到、拿毛巾和水），大门在左下角做框，石板步道从大门引到前台、再引到右上的台阶和球场门。总监以后能操控（站到柜台后面接待会员），这一轮只定构图、站位和路线。

- 页面：`http://[::1]:5190/clubfront.html`（构图 + 占位；`127.0.0.1:5190` 可能是别的 app，用 `[::1]`）
- 画廊：`clubfront.html?asset=<id>`（`&v=1` 变体、`&ground=sand` 换地面、`&ref=0` 去掉 1.8 米人形比例尺、`&cy=1.5` 放大窗看的高度，放大窗可拖）。新资产、复用资产都能看。
- 标签：**灰 = 占位（要画的新资产）**，绿 = 已画的新资产，青 = 从 desert3d-v2 复用的。洋红圆盘 = 站位，洋红小点 = 路线（`labels=0` 时都不画）。
- URL：`px`（默认 1）、`zoom`、`tx`/`tz`、`sunel`/`sunaz`（默认 50° / 偏东 22°）、`pause=1`、`labels=0`、`ph=0`（不放占位）、`nav=0`、`clouds=0`、`edges=1`、`warm`、`seed`。
- 钩子：`window.__club = { scene, pipe, step, setSun, own, reused }`。

**先读**：`docs/lab/2026-11-07-3d-pixel/lessons.md`、`material-spec.md`、`apps/sandbox/src/desert3d-v2/ASSETS.md`（材质规范 v2 的 API：`elem` / `tones` / `toneW`、各 kind 的参数；硬规则：厚度 ≥ 3 纹素、少而胖、三档分开、细节放在主角上、不加新颜色、预算）。那些规则这里全部照用，下面只写这个场景自己的。

## 主角的几何（画凉棚和前台的人必须守）

- 凉棚顶高 **≥ 3.4 米**，垂边底 ≈ 3.15 米；顶的南沿（垂边）在 z −1.4，**不要再往南伸**。
- 遮挡算式：站在 z_d 的人（帽顶 2.0 米）露得出来，当且仅当 `z_d > z_垂边 − (y_垂边底 − 2.0)`。现在 `−1.95 > −1.4 − 1.15 = −2.55`，余量 0.6 米 ≈ 1× 下 9 行：总监的帽子和肩膀在垂边下面露出来，脸被帽檐挡（总监的设计就是这样）。
- 帆布顶在屏幕上盖住它北边 3.5 米的地（z −8.9…−4.9）；垂边下面露出来的那条地（z −4.6…−2.9）**由后柜的暗正面填满**（后柜 1.4 米高、在柜台后 2.2 米、满宽 7.6 米）：总监的帽子永远落在深色底上。后柜比 1.35 米矮就会露出一条亮地，读成"漏光"。
- 柜台和后柜都在帆布的投影里：平时露出来的是暗档（柜台漆 L 72、柜台面 L 127）。柜台面那条浅薰衣草色 + 前沿的凸边亮线是投影池里柜台的轮廓，**别把柜台面也做成深色**。

### 每个资产的要点

**pergola（主角的上半）**——四根 0.3 米的染色木柱（角上，x ±4.05、z ±1.95）+ 前后两根东西向的主梁 + 5～7 根南北向的椽子，**椽子头伸出帆布两边 0.3～0.4 米**（剪影读成"凉棚"而不是"盒子"）。帆布一整块绷在顶上（最多 0.1 米下垂），2～3 条宽的俱乐部蓝条纹南北走向（屏幕上是竖条，每条 ≥ 0.9 米 = 10 纹素宽）。前沿垂边 0.35 米、5～6 个大扇形（每个 ≥ 1.2 米宽、扇深 ≥ 3 纹素），朝镜头 = 暗档，蓝白跟着条纹走。帆布 `noShadowReceive`（已在 palette 的 `THIN`）、**要投影**（投影池是构图的一部分）。条纹边是这块唯一的强边缘（奶油和蓝差 63），别再加别的高对比。几何约束见上「主角的几何」。

**front-desk（主角的下半）**——直柜台 4.4 米，正面俱乐部蓝竖板 + 底下一道深色踢脚 + 正中一个网球徽标（≥ 6 纹素的圆，`ball`，朝镜头用 `lightUp` 让它落中档）；柜台面浅石面、前沿伸出 0.06 米（凸边亮线）。柜台东头和东柱之间是员工口（不挡）。台面上东半边成簇放 2～3 样胖东西：一叠白毛巾、一碗网球、一个铜铃 —— 总监站的位置（x 0.45）前面空着。后柜：满宽 7.6 米、1.4 米高的木柜，格子里是卷好的毛巾（端头朝镜头 = 一个个 3 纹素的圆点，白和蓝条纹交替）和几瓶水；它整个在投影里，是总监身后的深色底。

**gate（左下的框）**——两根 0.9 米见方的土坯柱（3.4 米），灰泥面、柱脚和柱顶露几块土坯砖；柱顶陶砖帽 + **一颗网球做的柱顶球**（0.45 米，画面里最亮的点之一，暗档要露出来）；一根伸出两头 0.3 米的木横梁（椽头 vigas）；横梁下用两根铁链挂一块 2.8 × 1.0 米的招牌（深蓝底、奶油金字/徽标）。招牌朝镜头：`lightUp` 0.5～0.65 + 低 `bands`，让它落中档。字最多 4～6 个、笔画 ≥ 2 纹素、字高 ≥ 7 纹素；读不出来就只画徽标（网球 + 交叉球拍）。柱子南面正好在前庭挡土墙的墙面上（z 13.0），不要往外伸（会悬空）。

**towel-cart**——两层木推车 + 4 个胖轮子（≥ 3 纹素）；每层一排卷毛巾，端头朝镜头，白/蓝条纹交替；顶上搭一条展开的毛巾垂下来（一块 `canvasStripe`）。在投影池里。

**water-station**——木架（0.8 × 0.9 米）+ 一只大圆水桶（0.45 米直径、0.55 米高，`jug`，球面法线、亮顶）+ 一个铁龙头 + 一摞白杯子（≥ 3 纹素）。在投影池外（亮着），是右边的一个冷色点。

**planter**——灰泥花箱，陶砖压顶（顶沿 1～2 纹素亮唇），土面略低于沿。v1：正面一条蓝白瓷砖带（`counter` 蓝 + `clothWhite`，砖 ≥ 4 纹素）。花箱里的植物是复用的龙舌兰/桶形仙人掌/脆灌木，单独放在 SLOTS 里（y = 0.55）。

**pot**——大陶罐（窄底、鼓肚、卷边口），口沿下一道浅箍；龙舌兰单独放在罐口（y 0.85）。

**court-fence**——每段 8 米：3 根柱（≥ 2 纹素，`metal`）、一根顶杆、挡风布一整块（0.2～2.8 米高，朝镜头 = 暗档深青），每 2.65 米一条稍亮的竖接缝（1 纹素）、顶边一行亮边。**不画网眼**。v1 中间开 1.4 米的门（`ironwork` 门框，门半开），门上挂一条小横幅（俱乐部徽标）。挡风布 `noShadowReceive`（`THIN`）。

**golf-cart**——Q 版电瓶车：白车身、奶油帆布顶（和凉棚同一块布）、俱乐部蓝座椅、4 个胖黑轮子、后面一个装网球的筐。顶靠 2 根 ≥ 2 纹素的杆撑着。只是"停车区"的暗示，细节别多。

## 核心要做的（不是资产，一个"核心"代理改 palette/toon/terrain）

1. **陶砖方格**：给 toon.ts 加一个规整方砖的 kind（或给 `stones` 加"方格"开关）：屏幕上 7 × 5 纹素一块（≈ 0.3 米），灰缝 1 纹素、按行错开半块或对缝，每块一个深浅（本色/高一级/低一级），50% 的砖上沿亮边，零星几块缺角（缝色）。现在借的 Voronoi 读成"碎拼"，投影池里尤其碎。
2. **土坯墙**：现在借岩层（一层 4 行的砖），读成砖墙。要的是灰泥面（大块浅深斑、几乎平）+ 墙脚、墙角少数地方灰泥剥落露出土坯砖（`accent`）。女儿墙的陶砖压顶每 0.5 米一道接缝。
3. **地面中间层**（照 desert3d-v2 的 `ground.ts`，手摆的簇）：步道边、石板缝里的草、墙脚的干草团、到达区的碎石；陶砖铺地上不放。
4. 球场一角现在是平涂占位（`terrain.ts` 的 `court:*`），要不要换成 `surround`/`court` 带 `paint` 元素，等围网画好再看。

## 玩法（以后；这一轮只定数据，`layout.ts`）

- **站位 `SPOTS`**：`deskStand` (0.45, −1.95) 总监接待；`serve` (0.1, 0.4) 会员站在柜台前；`staffGap` (2.6, −1.0) 员工口（柜台东头和东柱之间）；`towels` (−3.3, 0.3)；`water` (4.7, 0.25)；`gateTop` / `gateFoot`；`arrive` (24.6, 18.4) 会员从岛东沿走进来；`courtStairsFoot` / `courtStairsTop`；`courtGate` (4.9, −17.5)。
- **路线 `ROUTES`**：会员 = 到达 → 土路 → 大门台阶 → 石板步道 → 柜台 → 毛巾 → 水 → 球场台阶 → 球场门；总监 = 站位 → 员工口 → 前庭。
- **能走的地方 `WALKABLE`**：到达区（岛顶，离岛沿 0.6 米）、前庭（减掉花坛、女儿墙、凉棚柱、柜台、花箱、陶罐、长椅、推车）、球场台地南边那一条（z −13.5…−18，门在 `courtGate`）、两段台阶（按级插值高度）。碰撞照 desert3d-v2 的 `control.ts` 做法（`terrain.outlines` + 资产的脚印）。
- 相机跟着总监（desert3d-v2 的 play 模式）；总监走进 `deskStand` 2 米内时，柜台前排队的会员上前一位。

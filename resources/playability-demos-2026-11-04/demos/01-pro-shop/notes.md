# 01 球具店：货架和定价（支柱 A · 奸商）

**一句话：** 你经营 Palm Oasis 的球具小店，四天里决定进什么货、摆哪一格、标多少钱。每个客人走到价签前都会当场给你脸色看。

## 怎么玩

1. 每天开门前是备货时间（时钟停着）：从底下的进货托盘把货**拖到货架**上，扣进货钱。门口两格是黄金位（客流 ×1.7），里角只有 ×0.5。
2. **点价签**选中货架，用大 **＋/−**（按住连发）或者**上下拖价签**改价。价签和下方的刻度条会变色（划算 / 正常 / 偏贵 / 宰人），也显示每件赚多少。
3. 点「开门营业」。一天约 54 秒（08:00–20:00），右下角有 ×2 快进。客人（退休老人、网球妈妈、发烧友、游客）进门，逛 2–4 格货架，看到价格当场反应。
4. 天气每小时在变：热浪（水、防晒、帽子需求暴涨，水只有两箱）、大风（帽子卖不动，人少）、比赛日（11 点和 17 点散场的人潮，发烧友和游客多）。13:00 来一趟补货车。
5. 奸商工具：**限量!** 标签（拖到货架上）；**捆绑**（把一种货拖到另一种货上变成套装）；热浪时 Dale 来问要不要**水价 ×3**。
6. 四天后按总利润和口碑给称号：沙漠吸血鬼 / 又黑又亏 / 沙漠精明掌柜 / 良心小店 / 会算账的老板 / 老实买卖人 / 上报专业户。

一局约 4–5 分钟（4 天 × 54 秒 + 每天的备货和日结）。`?fast=6` 加速，`?seed=N` 固定天气。

## 在测的假设

- **20–40 秒：** 价签本身就是一个随时想动、动之前会犹豫的动词。天气一变、货一空、一个老人骂了一句，你就想去改价。
- **3–5 分钟：** 热浪天水价 ×3 是"赚到了"（一瓶多赚 $4），上报纸是"搞砸了"；球拍卖出 $140 的大单有金币爆炸。
- **一局：** 称号是"良心小店"还是"沙漠吸血鬼"，由你一路上的定价决定，不是一个选项决定。

## 取舍表

| 决定 | 换来 | 付出 |
| --- | --- | --- |
| 定高价 | 每件多赚 | 客人皱眉走开（口碑 −0.5）、骂"抢钱啊"（−1.8，客人直接离店）；就算买了，≥2 倍市价的每一单也掉口碑；口碑低了以后进店的人少（口碑 0 时客流只有四成） |
| 定低价 | "划算！"一人买 2–3 件，口碑 +0.5 | 每件利润薄；货很快卖空，空货架让人失望 |
| 门口黄金位 | 客流 ×1.7、冲动购买更多 | 只有两格：放贵的球拍还是热天的水 |
| 进货 | 有东西可卖 | 现金压在货上；每种货每天只有几箱，进晚了就没了 |
| 限量! 标签 | 14 秒里看的人 ×1.7，肯掏的钱 ×1.3（发烧友不吃这套） | 货多（>6 件）还贴限量，买的人有 30% 会拆穿（口碑 −2）；一天第三次起每次 −3 |
| 捆绑 | 清掉滞销货，单笔更大；妈妈和游客觉得是优惠（忍耐 ×1.15） | 老人和发烧友嫌硬塞（×0.88）；整箱只能按配对件数用 |
| 热浪 · 水价 ×3 | 热的时候大部分人照样买，利润翻几倍 | 每瓶掉口碑；被宰的单子多了可能上《沙漠日报》（口碑 −12）；热浪过去后忘了改回来，客人会大骂 |
| 热浪 · 免费冰水桶 | 口碑 +6，热的时候进店的人多三成 | −$10，不涨价 |
| 撤下 | 退一半进价，腾出货架 | 亏一半 |

脚本跑出来的参考（同样的进货量）：全部照市价卖 ≈ +$750–840、口碑 90+（良心小店）；只在热天和游客爱的货上宰 ≈ +$870–1030、口碑 45–85；全部大涨价 ≈ +$560–600、口碑 0（又黑又亏）。所以"挑时机宰"最赚钱，"一直宰"最亏。

## 反馈清单

- **拖货：** 拿起来有幽灵卡片，悬停的货架闪虚线，幽灵下面的标签写着"补货 / 捆绑 A+B / $进价"；放下时出红色 −$、木屑粒子、"咚"的一声。钱不够、货没了、堆不下：卡片抖动 + 横幅 + 错误音。
- **改价：** 每一步一声"嘀"，价越高音越高；价签变色；刻度条的指针滑动；第一次超过 2 倍时价签上冒出"宰！"。
- **客人看价（核心）：**
  - 惊喜：心形气泡、小人跳起来、绿字"划算！来几个！"、价签绿色弹一下、三连音。
  - 正常买：感叹号气泡、金币声、绿色 +$ 飞向左上角现金，现金数字跳动，柜台后的总监跳一下。
  - 犹豫：省略号气泡、"嗯……"、两声低音；0.9 秒后掷骰子，买了是"好吧…"加流汗气泡。
  - 皱眉：怒筋气泡、橙字"太贵了吧"、脸变红、冒蒸汽、价签红色晃动、口碑条闪红。
  - **抢钱啊：** 大号红字（带价格，例如"$6？比拉斯维加斯还黑！"）、屏幕抖动、红色闪屏、低沉的锯齿波、"−2 口碑"飘字、客人红着脸冒着蒸汽小跑出门。
  - 被宰但还是买了：交易完 0.3 秒后飘一句"渴死了…算你狠"。
- **大单（利润 ≥ $30）：** 金色闪屏、金币爆炸、横幅"大单！球拍卖了 $140"、五连音。
- **卖空：** "卖空了！"飘字，价签变成虚线"空"。
- **天气：** 横幅（起风 / 热浪 / 比赛散场 / 下午的货到了），窗外天色、热浪扭曲、风线和风滚草、看台人头；酷热时整个画面泛橙。
- **上报纸：** 一张转着落下来的《沙漠日报》，标题写着你卖的实际价格，屏幕重抖、黑闪。

## 如果选中，怎么接进现在的游戏

- 球具店是 Indian Wells 地图上的一个设施（会所里的一间），修好以后解锁；货架格就是设施状态的一部分，在场景里直接点价签（不是菜单）。
- "有人在岗才卖得动"：店里必须有人守柜台（前台 Ben/Lily，或者总监本人）。总监守店时可以实时改价、对热浪卡做决定；没人守店就关门。这正好把"总监是劳动力"变成一个取舍：总监去店里赚快钱，就不在场地上。
- 热浪水价、限量、捆绑做成事件卡（热浪卡已经是一张卡的样子：谁来找你、处境、三个选项的代价）。上报纸是后续卡，写进因果日志。
- 口碑接到现有的声望上，按周日结算把一周的"被骂次数 / 被宰单数"折算成声望变化；客流来自场地上的会员和访客（比赛日就是现在内容里的赛事日）。
- 进货车可以接 Rosa/Gus 的维护工单，或者变成一张"供货商"卡（便宜但不准时 / 贵但准时）。

## 和玩法准则的冲突（制作人说这轮不用迁就，只记下来）

- 准则 6：收入取决于价格和进货，不只是"有人在岗 × 基数"；口碑实时涨跌，客人当场流失，不等周日结算。
- 准则 1：改价本身是一个随时可以操作的旋钮，用得多了会变成 HUD 上的"数值面板"。目前靠"点场景里的价签"守住，但接进游戏时货架数量要少。
- 准则 4：热浪卡每天最多一张，比较稀；但店里每个客人都在给反馈，节奏比现在的事件快得多。

## 已知不足 / 第二轮可以加什么

- 捆绑只能"从托盘拖到已有的货上"，还不能把两格货架之间互相拖；套装剩下的散货直接丢了。
- 客人不会讨价还价、不会说出"你家比隔壁贵"——可以和 04 推销台合并：特定客人（发烧友）走到柜台前跟总监砍价。
- 没有竞争对手和记忆：被宰过的老人第二天不会认出你。可以给几个常客起名字，让他们记仇或者成为回头客。
- 只有一张地图的一间店；限量和冰水桶之外的工具（打折日、会员价、"今日特价"黑板）都可以加。
- 数值用机器人跑过三种打法，但手动玩的时候热浪那天的体验最强，平淡的晴天比较闷，可以每天至少来一个小事件（大巴游客团、校队来买球）。

# 网球总监 · 玩法设计文档 v0.1

Oct 29, 2026 · @Enting

## 概述

玩家扮演网球总监，依次经营三个网球项目：Hollow Creek → 枫岭高中 → 顶级网球中心。画面是 3D 体素像素风、上帝视角。游戏不是回合制：时间持续流动，进度只由事件推动。

每一幕给玩家一种不同的感受（MDA 框架里的美感目标）：

| 幕 | 场景 | 玩家应该感到 |
| --- | --- | --- |
| 第一幕 | Hollow Creek（原 Scene 2） | 翻身：把烂摊子救活 |
| 第二幕 | 枫岭高中（原 Scene 1） | 成长：看着自己栽培的球员变强 |
| 第三幕 | 顶级网球中心（原 Scene 3） | 掌控：同时照顾很多人，办成一场大赛 |

五条核心原则：

- ~~**事件推动进度。**~~ 已被"核心玩法决定（2026-10-31 晚）"取代：进度靠经营，事件是偶发点缀。时间一直在走，没有"结束回合"按钮；重要事件出现时自动暂停。
- **每个事件都是有代价的选择。** 没有永远正确的选项，短期利益和长期利益互相冲突。
- **总监的注意力最稀缺。** ~~总监小人要亲自走过去，才能谈判、督导、安抚。~~ 改为：总监是可分配的劳动力，指派到哪里就只能在哪里（见"核心玩法决定"）。
- **栽培的东西会继承。** 总监和玩家培养的人员会带进下一幕。
- **美术就是反馈。** 决策的结果在球场上用活动动画演出来。

### 玩法准则（Tenets）

2026-10-31 定。所有玩法改动和评审都对照这三条；互相冲突时，排在前面的优先。

1. **不做菜单式操作。** 玩家的每个动作，要么是对事件的回应（事件卡、有人走过来找你），要么是直接和场景或界面里的东西互动（点地点、点人、点设施、点 HUD 上的提示）。不加"打开面板 → 选子菜单 → 按按钮"的管理操作。数据可以放在 HUD 和状态条里给玩家看，但改变局面的动作不从菜单发起。检验：一个新功能的第一反应如果是"加个按钮或面板"，先想它能不能是一张卡、一个人走过来，或者点场景里的某样东西。
2. **选择要有取舍。** 每个选项都换来一些东西，也付出一些东西：钱、时间、总监站在哪儿、某个人的好感、以后的风险。不存在各方面都更好的选项。检验：机器人报告里没有被压制的选项；同一张卡，不同的玩家都有理由选不同的项。
3. **不同的选择通向不同的后果。** 选择要留下痕迹：后续事件、人物态度、设施状态、结局。玩家事后能在"因为……所以……"里看到自己的选择在哪里起了作用。检验：同一个种子换一种打法，故事和结局明显不同；每个结局都有一条走得到的路。
4. **事件是偶发的，每一张都有分量。** 事件卡不多，来的时候要配足够的界面，让选择有意义：谁来找你、此刻的局面、每个选项会动哪些东西、之后可能怎样。检验：一个游戏日里大多数时间没有卡；每张卡打开时，玩家不用翻别处就能看懂这个选择的分量。
5. **日常经营靠和界面互动。** 让俱乐部变好的主要手段，是玩家主动去点场景里的设施和人（修场地、排课、安排教练、调时段），而不是等卡来。这些动作同样要有取舍（准则 2），也同样不走菜单（准则 1）。检验：一局里玩家主动发起的动作多于回应卡片的次数。
6. **玩家不操作时，局面基本不动，世界照样在动。** 数值不会自己大幅漂移；模拟继续跑：人来人往、上课、天气、季节更替、偶发事件。画面要有动态的模拟感。检验：放着不管一个游戏日，关键数值变化很小，但画面一直有事在发生。

**平台：手机优先。** 主要在手机上玩（竖屏为主）。界面先按 390×844 竖屏设计：大拇指能碰到的地方放操作，点击目标至少 44 像素，用拖动和点按，不依赖鼠标悬停和键盘；桌面是第二布局。试玩评审以手机画面为准。

## 核心玩法决定（2026-10-31 晚）

讨论中，尚未定稿。和下文冲突时以本节为准；下文被取代的段落已标注。

- **否决"事件推着走"的叙事卡牌游戏（游戏 A）。** 事件卡不再是核心玩法，只作为偶发的点缀（准则 4）。里程碑仍可存在，但不是推进进度的主要方式。
- **转向经营模拟（游戏 B）。** 一句话定位：**经营一个网球俱乐部的日程表，看它活起来。**
- **否决"总监走来走去"。** 总监不再靠玩家操控走位、跑腿、消耗精力去现场。
- **总监是一个可分配的劳动力。** 玩家把总监指派（assign）到某个地点做某件事，和员工一样。
- **员工：** 清洁工、网球教练、球童（种类待扩充）。
- **核心玩法 = 招募人才 + 把人放到该在的地方。**
- **成长曲线：** 初期人手很少，总监是主要劳动力，玩家要不停把他重新调到不同场地做不同的事；后期招到更多人，总监从"干活的人"变成"把人排好的人"，玩家把员工分配到各处。

- **指派对象是"地点上的岗位"。** 同一个地点有多个岗位，比如 1 号场可以修场，也可以上课。
- **随时拖动重派。** 人可以随时从一个岗位拖到另一个岗位。
- **岗位有进度，要有 UI 显示。** 中途把人拉走会有代价：比如上课上到一半把教练拉走，顾客不满，收入变少。
- **总监是没有情绪的员工。** 他不会闹情绪，能力随游戏慢慢成长。
- **没人管的地方会变差。** （和准则 6"不操作时数值基本不动"冲突，准则 6 需要改写。）
- **招人通过试训日或招聘日。**
- **开局人手：** 总监和 Dale 两个人。
- **员工维度：** 未定。
- **没有字面意义上的日程表。** 不做排班表画面；排班靠随时拖人隐性解决。
- **一次性岗位和持续岗位分开处理。** 一次性：除草、修理等；持续：上课等。两者的 UI 要能一眼区分（方案待定，见下方提案）。
- **Dale 开局不开除。** "开除 Dale"里程碑先从第一幕去掉，留作以后的剧情素材。

#### 提案（待确认）

**准则 6 改写：** 玩家不操作时，世界照样运转，局面慢慢回到"你布置的样子"：有人守的地方维持住，没人管的设施慢慢变旧。变化先在画面上看到，再反映到数字上。
- 设施（场地状况、清洁度）：没人维护会缓慢衰减，用得越多衰减越快；先出画面信号（落叶、杂草冒头、垃圾），再掉档。
- 流量（课程收入、满意度增量）：只在有人在岗时产生；没人就是零，不倒扣。
- 存量（会员数、声望）：不实时漂移，按一段时间内的平均状况结算。
- 检验：放一天，数字几乎不动，画面上看得到杂草冒头；放一周，没人管的场掉一档。

**一次性 vs 持续岗位的 UI：**
- 持续岗位是地点上的"位子"：场边固定的空位轮廓，拖人进去就坐上，头顶环形进度，转一圈出一次收益。空位一直显示，提醒没人。
- 一次性任务是长在问题本身上的"工单"：杂草上、裂缝上冒出带工具图标的标记和直条进度，拖人到标记上就开始干，可以多人一起，干完标记消失、画面改变。
- 中断：持续岗位被拉走，损失当前这一圈的收益和满意度；一次性任务被拉走，进度保留。

**隐性排班：** 不同时段来的人不同（早上退休会员、下午放学孩子、傍晚上班族），需求在场景里看得见；玩家跟着需求拖人，排班就隐含在拖动里。

## 三幕结构

每一幕加一层新系统，面对一个新的经营问题，参考 Two Point Hospital 的关卡设计。玩家在第一幕学会"场地和钱"，第二幕才面对"人"，第三幕面对"所有人同时有要求"。

|  | 第一幕 Hollow Creek | 第二幕 枫岭高中 | 第三幕 顶级中心 |
| --- | --- | --- | --- |
| 核心动词 | 救活 | 育人 | 办赛 |
| 新增系统 | 设施与现金 | 球员与赛季 | 利益方与大赛 |
| 主要压力 | "出售"倒计时（停车场那块牌子） | 赛季日历、学业资格 | 会员、赞助、媒体的期望 |
| 稀缺资源 | 钱、能用的场地 | 放学后的训练时间、球员体力 | 场地档期、总监注意力 |
| 标志玩法 | 四块场地对应四个修复项目 | 球员养成和阵容化学反应 | 多阶段筹办一场大赛 |
| Boss 事件 | 董事会表决，或对阵松冠俱乐部 | 州冠军决赛对西溪高中 | 自家赛事的决赛日 |
| 失败 | 俱乐部被卖掉 | 学校砍掉网球队 | 赞助撤资、会员出走 |

三条贯穿线把三幕连起来：

- **那个孩子（暂名）。** Dale 课上坐在地上发呆的孩子。第一幕你发现他有天赋，第二幕他进了枫岭成为王牌，第三幕他站上中心球场打决赛。他是继承系统的情感核心。
- **匹克球。** 第一幕它是吞场地的掠食者，第三幕它是赚钱的业务。玩家对它的态度前后呼应，也反映网球和匹克球的文化变迁。
- **Dale。** 第一幕被开除，之后可以在社区群里说你坏话，第三幕以匹克球教练的身份回来。具体取决于第一幕怎么开除他。

## 事件引擎

时间持续流动，状态量决定系统出什么事件卡，玩家的决策通过活动动画结算，结果再写回状态量。里程碑事件额外负责推进到下一幕。

> 图：事件驱动循环 · 6 步（图只在在线文档里，见 README 的链接）

### 时间模型

- 时间持续流动，支持暂停、1×、2×（沿用现有场景的控制条）。
- 重要事件出现时自动暂停，参考 Football Manager 和 Paradox 系游戏。
- 进度只由事件推动：一幕结束于里程碑事件，而不是某个天数。

### 四种事件来源

| 来源 | 触发方式 | 例子 |
| --- | --- | --- |
| 里程碑 | 固定剧情，推进场景 | 开除 Dale、州冠军决赛 |
| 阈值 | 状态量满足条件时触发 | 质量低于 D 且会员流失 → 家长投诉 |
| 日历 | 固定日期，玩家可以提前预见 | 比赛日、董事会、考试周 |
| 活动后果 | 活动结算后链式触发 | 比赛赢了 → 上校报 → 赞助商来电 |

### 倒计时

事件卡带倒计时，不处理就过期，过期执行默认后果（参考 Cultist Simulator、Frostpunk）。玩家同一时间处理不了所有事，取舍就是这样产生的。

### 事件导演

事件导演监测压力值：现金、未处理事件数、连败次数。压力高时给喘息和好消息，太平稳时扔一个危机，参考 Left 4 Dead 的 AI Director 和 RimWorld 的叙事者。它要画出 Jesse Schell 说的兴趣曲线。

### 总监注意力

> 已被"核心玩法决定（2026-10-31 晚）"取代：不再操控总监走位，改为指派。

总监小人要走到现场才能谈判、督导、安抚。总监在场时，教练不玩手机，球员练得更认真。玩家看哪里、走到哪里，本身就是决策。

### 因果日志

右侧的事件流水改成"因为……所以……"的账本，让延迟后果可以被读懂，玩家才能自己讲出故事（Tynan Sylvester 的"故事生成器"）。

### 状态量

| 状态量 | 含义 | 出现的幕 |
| --- | --- | --- |
| 资金 | 现金和每周收支 | 全部 |
| 声望 | 外界口碑，决定招生和谈判成功率 | 全部 |
| 项目质量 | A 到 F 的等级，沿用现有 HUD | 全部 |
| 士气 / 疲劳 / 技术 | 每个球员和教练各自一套 | 全部 |
| 出售倒计时 | 俱乐部被卖之前剩余的时间 | 第一幕 |
| 匹克球压力 | 匹克球对场地的需求和舆论 | 第一幕、第三幕 |
| 学业资格 | 球员的 GPA 是否达标 | 第二幕 |
| 学校支持 | 校长和家长委员会的态度 | 第二幕 |
| 利益方满意度 | 会员、学院、赛事、匹克球、赞助商各一条 | 第三幕 |

### 经营循环 v2（2026-10-31）

> 部分取代：其中"总监跑过去""总监的精力"两条已被"核心玩法决定（2026-10-31 晚）"否决；排日程、季末小结、天气季节等仍保留待议。

来自第一轮试玩和设计反馈（准则 4–6）。替代"事件推着走"的旧节奏：俱乐部变好主要靠你主动排日程、主动去做事，事件是偶发的。

- **时间：** 第一幕 6 周，夏末（第 1–3 周）到初秋（第 4–6 周），第 6 周末董事会表决。营业 8:00–20:00，没卡、总监也没在忙时时间加速，1× 下一天约 1 分钟。
- **季初排日程：** 点会所的公告板，排这一季的周日程：课程时段、场地分配（网球 / 分时段 / 匹克球）、活动（开放日、比赛、社交夜）。日程决定每天自己发生什么，也决定收入、会员和质量的基线。
- **季中经营：** 点场景里的设施和人，原地弹出 1–3 个动作；选了以后总监跑过去，做一段有趣的动画（修场地、看课、谈话、办活动）。
- **总监的精力：** 精力值 0–100。季初满格，总监跑着去、身后冒烟，事情做得快；精力越低走得越慢，做事越久。每个动作花精力，夜里恢复一点，换季回满。精力就是"总监注意力"的具体形式：一季里能亲自做的事有限。
- **偶发事件：** 每周一两张，都暂停。卡面讲清谁来找你、此刻的局面、每个选项会动哪些数、之后可能怎样。
- **季末小结：** 这一季因为……所以……，然后排下一季。
- **不操作时：** 数值停在日程和设施决定的水平，不自己漂移。世界照常运转：会员按日程来打球、上课、匹克球、泳池、乌鸦和狗。
- **天气和季节：** 天气由模拟决定（晴、阴、雨、大风），雨天红土场和露台活动受影响。季节让草和树叶变色、泳池在初秋关门、天黑提前。
- **待定：** 精力的具体数值；日程按天还是按半天排；季中能不能改日程、改一次的代价。

## 第一幕 · Hollow Creek：救活

目标：在"出售"倒计时结束前，把项目质量从 F 拉回 C，会员恢复到目标人数（数值待定），并取下停车场的出售牌。

开局状态沿用现有场景：F 级，主教练空缺，现金很少，气膜塌了，红土场长满杂草，泳池干涸。

这一幕的核心问题是死亡螺旋：质量低，会员流失，没钱，场地更烂。这是 Machinations 里的正反馈回路。玩家要找到第一根便宜的杠杆，把螺旋反转过来。

### 四块场地，四个项目

| 场地 | 现状 | 玩家可以做什么 | 代价与收益 |
| --- | --- | --- | --- |
| 1 号场 | 最后一块在用的网球场 | 修补裂缝、换网 | 便宜；质量上升 |
| 2 号场 | 租给匹克球 | 续租、收回或分时段 | 现金和网球身份互相拉扯 |
| 气膜场 | 气膜塌了 | 重新充气 | 贵；解锁雨天和冬季训练 |
| 红土场 | 杂草和倒下的树 | 发起社区劳动日 | 复用团建动画；社区声望上升 |

### 关键事件

- **开除 Dale（教学卡）。** 选项：当众开除、私下谈、再给一次机会。选择会留下标记，影响他之后的出场。
- **招新教练。** 三选一：便宜的热血新人、疲惫的老手、昂贵的前职业球员。这个人有资格被继承到下一幕。
- **免费试训日。** 复用招生活动；报名人少，来的人五花八门。
- **发现那个孩子。** 由训练或试训触发的里程碑事件。
- **匹克球租场请求。** 见"事件卡规格"里的示例卡。
- **开发商来访。** 出一大笔钱买地。这是诱惑型选择，接受就提前结束本幕并进入坏结局分支。
- **喜剧事件。** 乌鸦叼球、暴雨漏水、拔河输给匹克球队。

### Boss、失败与过渡

- **Boss：** 董事会表决。表决前有一场对阵松冠俱乐部的社区对抗赛，比赛结果影响票数。
- **失败：** 倒计时到期仍未达标，俱乐部被卖，重开本幕。
- **过渡：** 那个孩子被枫岭高中录取，枫岭同时向你发出总监邀请。离开前触发"谁跟我走"的继承事件。

## 第二幕 · 枫岭高中：育人

目标：在一个赛季内带队拿下州冠军，同时让学校继续支持网球队。

这一幕的骨架是赛季日历。比赛日是固定节点，玩家在比赛之间安排训练、招生和团建，节奏参考 Kairosoft 和 Football Manager。

### 学生身份带来的约束

- 只有放学后能练：每个上学日只有一段训练时间（与场景时钟 Wed 3:30 PM 对应）。
- 考试周：训练时间缩短，球员压力上升。
- 学业资格：GPA 不够的球员会被禁赛。
- 抢人抢场地：社团招新时要和篮球队、啦啦队竞争。
- 预算紧：沿用场景里的 $1,850。

### 球员养成

- 每名球员有技术、疲劳、士气和一到两个特质。特质参考 Darkest Dungeon 的怪癖，比如紧张型、大心脏、懒散天才。
- 训练效果受疲劳、天气、教练水平影响，直接复用活动库里的变量。
- 练得太狠会受伤。这是防止滚雪球的负反馈刹车。
- 球员之间有化学反应：新王牌和老队长会起冲突，团建可以缓和。

### 影响力档位

比赛是扩大影响力的主要方式。场景配置里已有四档标题，每升一档解锁新事件：

| 档位 | 标题 | 解锁的事件（建议） |
| --- | --- | --- |
| 1 | 全校都在讨论 | 更多新生报名、校长关注 |
| 2 | 上了校报头版 | 本地赞助、家长委员会介入 |
| 3 | 州报头条 | 大学球探、转学生、对手针对 |
| 4 | 全国热搜 | 顶级中心的邀请（通往第三幕） |

### Boss、失败与过渡

- **Boss：** 州冠军决赛，对阵西溪高中。那个孩子是这场比赛的王牌。
- **失败：** 校长的预算会议上，网球队被砍掉。
- **过渡：** 影响力到第 4 档后，顶级网球中心发出邀请。再次触发"谁跟我走"的继承事件。

## 第三幕 · 顶级网球中心：办赛

目标：成功举办一场大赛，并且让每个利益方的满意度都不跌破底线。

这一幕从稀缺变成过剩：钱不是问题，期望才是。场景开局就是 A 级、有候补名单、收入在涨，压力来自各方同时提要求。

### 利益方平衡

每个利益方有一条满意度，任何一条见底都会出事。这是 Reigns 式的多条平衡条。

| 利益方 | 想要什么 | 不满时会发生 |
| --- | --- | --- |
| 会员 | 独占场地、高端服务 | 投诉、退会、在会员群发难 |
| 青训学院 | 固定训练时段 | 好苗子被别家挖走 |
| 赛事 | 所有场地、人手和曝光 | 赛事延期或降级 |
| 匹克球 | 扩场、更好的时段 | 收入下降，舆论说你守旧 |
| 赞助商 | 曝光和明星 | 撤资 |

### 大赛事件链

1. **申办：** 和其他场馆竞争主办权，前两幕积累的声望在这里兑现。
2. **筹备：** 场地、票务、赞助、媒体四条线并行，每条都有自己的倒计时事件。
3. **赛事周：** 现场危机连续出现，比如下雨延误、明星退赛、热浪、VIP 抱怨喷雾不够凉。
4. **决赛日：** 那个孩子站上中心球场。

### 结局

决赛赢或输都可以是好结局；结局主要由三幕的选择决定，比如社区、学校、匹克球、Dale 这几条线最后的状态。结局分支的具体设计待定。

## 继承系统（框架，细节待定）

总监和玩家栽培的人员会继承到下一幕，钱和设施不会。玩家用心培养的东西必须保留；同时每一幕要重新面对稀缺，不能因为继承变得太简单。

### 继承什么

| 类别 | 继承 | 不继承 |
| --- | --- | --- |
| 总监 | 等级、特质、风格倾向、人脉 | 头衔和职权（每幕重新建立） |
| 人员 | 玩家选中的核心球员、教练、员工 | 未被选中的人员 |
| 关系 | 角色之间的关系和事件标记 | 无 |
| 资源 | 少量声望折算（比例待定） | 现金、设施、大部分会员 |

### 设计原则

- **继承本身是一个事件。** 每幕结尾触发"谁跟我走"：随行名额有限，玩家必须取舍。
- **被带走的人有自己的意愿。** 忠诚度低的人可能拒绝跟随，因此平时怎么待人会影响能带走谁。
- **留下的人继续存在。** 你留谁主持 Hollow Creek，决定了它之后的命运，也决定了它在后两幕里以什么事件出场。
- **能力换个环境会变味。** 社区里擅长带新手的教练，到高中适合带青训，到顶级中心适合管学院，同一个人在不同的幕承担不同的角色。
- **风格倾向会累积。** 总监的选择会积累到人情、成绩、商业三个方向，影响后面出现的事件和人员对你的态度。

### 待定细节

- [ ] 每幕的随行名额是多少
- [ ] 继承人员的数值是原样保留，还是按比例折算
- [ ] 高中球员的年龄跨度：第三幕时那个孩子是什么身份（大学生、职业新人）
- [ ] 总监是跳槽到三个地方，还是同一个机构在扩张
- [ ] 是否允许玩家重开某一幕并保留继承

## 事件卡规格

每张事件卡是一条数据记录，引擎按字段决定它何时出现、怎么结算。

| 字段 | 说明 | 例子 |
| --- | --- | --- |
| id | 唯一标识 | `hc_pickleball_court2` |
| 场景 | 哪一幕可以出现；可跨幕 | Hollow Creek |
| 来源 | 里程碑、阈值、日历、活动后果 | 阈值 |
| 前置条件 | 状态量和标记的组合 | 现金 < $500 且 2 号场空闲 |
| 权重 / 冷却 | 被抽中的概率、两次出现的最短间隔 | 权重 3，冷却 7 天 |
| 倒计时 | 游戏内时间，过期执行默认后果 | 2 天 |
| 总监亲临 | 是否需要总监走到某处才能选某个选项 | 选项 C 需要 |
| 选项 | 2 到 3 个，每个有消耗、效果、后续事件 | 见下方示例 |
| 默认后果 | 不处理时发生什么 | 执行选项 A，声望下降 |
| 写入标记 | 留给以后事件读取的记忆 | `pickleball_rival` |
| 演出 | 调用哪个活动动画 | 拔河、社区集市 |

### 设计检查清单

- 没有永远正确的选项（Sid Meier 的"有趣的选择"）。
- 至少一个选项让短期和长期利益冲突。
- 结果写进因果日志，玩家看得懂"因为……所以……"。
- 尽量用现有活动动画演出结果。

### 示例：匹克球俱乐部想租下 2 号场

倒计时 2 天。

- **A 租给他们：** 每周 +$300，网球可用场地 −1。老会员抱怨"这还是网球俱乐部吗"。
- **B 拒绝：** 当下没有变化；3 天后触发"匹克球在社区群吐槽"。
- **C 提议分时段：** 总监要亲自走过去谈，成功率看声望。成功则每周 +$150，并解锁"匹克球友谊赛"活动。
- **不处理：** 他们直接去找董事会，默认执行 A，而且声望下降。

## 参考与理论

| 参考游戏 | 借什么 | 用在哪里 |
| --- | --- | --- |
| Kairosoft（如 Pocket League Story） | 像素经营、事件推进、小数值的爽感 | 整体手感 |
| Two Point Hospital / Campus | 每关一个新约束、一个新目标 | 三幕结构 |
| Football Manager | 收件箱式事件、比赛日节奏 | 第二幕赛季 |
| Frostpunk | 倒计时危机、法令式抉择 | 事件倒计时 |
| Cultist Simulator | 即时制下的计时卡牌 | 非回合制的时间模型 |
| RimWorld | 叙事者控制节奏，游戏作为故事生成器 | 事件导演 |
| Reigns | 极简选择卡、多条平衡条 | 第三幕利益方 |
| Fallen London | storylet 与 quality 系统 | 事件数据结构 |
| Darkest Dungeon | 压力与怪癖 | 球员特质与疲劳 |

设计理论：

- **MDA 框架**（Hunicke、LeBlanc、Zubek）：先定每幕的美感目标，再倒推机制。
- **有趣的选择**（Sid Meier）：事件卡的检查标准。
- **反馈回路**（Adams 与 Dormans，《Game Mechanics: Advanced Game Design》）：第一幕的死亡螺旋、第二幕的受伤刹车。
- **兴趣曲线**（Jesse Schell，《The Art of Game Design》）：事件导演要画出的节奏。
- **Storylet / 基于状态的叙事**（Emily Short、Failbetter）：事件按状态挑选，而不是按顺序播放。
- **故事生成器**（Tynan Sylvester，《Designing Games》）：因果日志让玩家自己讲出故事。
- **不确定性**（Greg Costikyan，《Uncertainty in Games》）：天气、疲劳、教练水平带来的结果变化。
- **心流**（Csikszentmihalyi）：每幕的难度随玩家能力逐步上升。

## 垂直切片与待定问题

先做 Hollow Creek 前 15 分钟的可玩切片，验证"事件 + 倒计时 + 总监走位"这套核心手感，再铺开第二、三幕。切片大约需要 15 到 20 张事件卡，动画全部复用现有活动库。

切片流程：

1. 开除 Dale（教学卡）
2. 招新教练（三选一）
3. 修 1 号场
4. 免费试训日，发现那个孩子
5. 匹克球租场谈判
6. 社区对抗赛与董事会表决
7. "谁跟我走"（继承事件的雏形）

待定问题：

- [ ] 一个游戏日对应多少现实时间，倒计时用多长
- [ ] 事件导演是否开放为难度选项（稳健型、戏剧型、随机型）
- [ ] 那个孩子的名字和背景
- [ ] 继承系统的细节（见"继承系统"一节）

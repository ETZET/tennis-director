# 俱乐部的一天：人物模拟

2026-11-24 · 第一版；同日第 1 轮 critique 以后改了引擎（走路速度、午饭、人数、孩子、老伤、救生员、表演赛散场……，见各节）；2026-11-25 第 3 轮：匹克球拍架、关着的窗口、孩子的课不被拉走、教练课间、吃饭的座、Curtis 打匹克球。契约在 `apps/sandbox/src/clubsite/sim/types.ts`（冻结，改了先改本文）。人物是谁、属性、特质见 [people.md](people.md)。

## 零、一句话

俱乐部里的每一个人都由一个引擎算出来：**今天来不来、几点到、从哪进、先干什么后干什么、在哪儿等、几点吃饭、几点回家**。
画面只负责演：引擎说"Ortega 夫妇 8:05 从北停车场下车，8:10 在前台签到，8:20 到 9:50 在 2 号红土场双打，然后去喷泉广场喝柠檬水"，
画面就让两个人这么走、这么站、这么挥拍。

用户 2026-11-24 的原话："这些人是早上几点一块来的？中午他们就要去吃饭，晚上他们就会回家。"

## 一、为什么要有

现在（PR #34、#37 以后）场景里的人由每个场景的 `life.ts` 按自己的循环演（前台 72 秒一轮、匹克球 3 分一换），演员表只回答"这个位置今天是谁"。
所以人没有"一天"：早上和晚上一样多人，没有午饭高峰，没有人回家，同一个人在两个循环里各演各的。
这一层让人先"活"起来，**画面跟着引擎**；有引擎说了、画面没有的事（游泳、健身、吃饭……），再一样样补画面。

## 二、分层

```
clubsite/cast    人是谁（名单、属性、特质、每周来访）        纯
clubsite/sim     人今天在哪、干什么（本文）                  纯（clubsim-is-pure：只许 import cast 和 world.ts）
clubwalk/sim     演：一个人一具 Q 版人，沿导航走、摆姿势；时钟、加速、观察面板
valley/main.ts   调试面板里的"观察俱乐部的一天"
```

- 引擎每步 = 1 游戏分钟。`startDay` 排日程，`step` 推一分钟，`view` 给快照，`stepMany(cfg, s, n, input)` 快进 n 步（换天、跳时刻用：结果和连调 n 次 `step` 一模一样，中间的状态不交出去，所以表只复制一次，快一倍多）。状态能 JSON 往返；同样的种子、同样的输入 → 同样的一天（测试守着）。
- **走路速度 `WALK_M_PER_MIN = 12` 米 / 游戏分钟**（`index.ts` 导出，画面插值路上的人用同一个数）。真人是 78；观察默认 2 游戏分钟 / 真实秒，照真人的速度画面上一秒走 156 米、一帧就过去了。12 → 画面上 24 米 / 秒（像延时摄影），看得出"一伙人刚下车往前台走"。
  代价：停车场 → 餐车院子 ≈ 12–15 分钟、前台 → 更衣室 ≈ 13 分钟，日程按这个松：订场按"下车 → 签到 → 换衣服 → 走到场边"的路程算到的钟点（`bookCourt` 的 `leadIn`），客人多待一会儿。
- 画面每帧在两步之间插值（路上的人按 t0..t1 走导航路径），**动画不决定任何数**：走慢了、被挡了，引擎照样按时到。
- 地点按名字（`PlaceId`，例如 `clay.court2`、`food.taco`）引用；`places.ts` 里的 x/z 只用来估路程。站位（每个位置的坐标、朝向、姿势）在 `clubwalk/sim/spots.ts`。
- 契约第 1 轮的增补（都是可选字段，旧的读法不变）：`Place.pickup`（窗口边等餐的位置数，等餐的人 `spot = cap + k`）、`Intent.snack`（零食）、
  `Agent.day.ateAt` / `day.fill`、`Agent.missed`（今天记过一笔的"没干成"）、`Agent.car` / `Agent.stall` 和 `CarMode`（停车，见 4.1）、`Place.stalls`（停车场的车位数）；新地点 `courts.wall`（青训场围网外对着墙打，kind play、doing tennis、cap 2、只给孩子）。
  引擎多导出 `WALK_M_PER_MIN`、`travelMin`、`stepMany`、`handoverPosts` / `postStaffed`（岗位此刻算不算有人守，引擎和报告同一个判断）。
  第 3 轮的增补（可选字段）：`Agent.shut`（走到了才发现关着的窗口 `[地点, 几点]`，半小时里不再挑）；`DayReport.rack`（拍架边排着的分钟、其中有空场的）；`PlaceIndex.byNeeds`（岗位 → 要它有人才开的地方）。

## 三、一天的节奏（目标：像一座真的沙漠网球俱乐部）

Indian Wells，科切拉谷。冬天是旺季（候鸟），夏天中午 40 度以上。下面是**旺季平日**的样子，周末、夏天按第六节调。

| 时间 | 谁 | 在干什么 |
| --- | --- | --- |
| 5:30–6:45 | 员工 | 场地维护先到（拖红土、吹叶子），前台、咖啡吧开门准备；摊主 10 点后才来 |
| 6:30–8:30 | 早起的老会员、候鸟 | 趁凉快打第一场：红土、会员场、匹克球全满；咖啡吧排队 |
| 8:30–11:00 | 会员、客人 | 第二波：双打、上课的大人、健身房；喷泉广场坐着歇的人多起来 |
| 11:30–13:30 | 几乎所有在场的人 | **午饭**：餐车院子排队、找座；会所咖啡吧、二楼；员工轮流去吃 |
| 13:00–15:30 | 少 | **最热**：室外场空一半，人在泳池、躺椅、会所里、树荫下；一部分人回家午睡 |
| 15:30–17:00 | 孩子、家长 | 放学：青训课（教练 + 4–8 个孩子），家长坐场边；喷泉边玩水的孩子 |
| 17:00–20:00 | 下班的会员 | **晚场**：双打四人约好一起来；灯亮了；中心球场有时有表演赛 |
| 18:00–22:00 | 留下来的人 | 二楼酒吧、露台、餐车院子吃晚饭；21:00 以后陆续回家 |
| 22:00–22:30 | 员工 | 关门：最后一批客人走，员工收拾、下班 |

**一个会员的一天**举例：7:40 下车 → 前台签到（排队 3 分钟）→ 更衣室换鞋 → 8:00–9:30 红土双打（和约好的三个人）→ 喷泉广场喝水、聊天 20 分钟 → 回家。
另一个：11:50 到 → 餐车院子吃塔可 → 泳池躺椅 2 小时 → 17:30 晚场双打 → 二楼酒吧 → 20:40 回家。

## 四、引擎怎么算

### 4.1 谁今天来（`startDay`）

- **员工、摊主、教练**（role staff / vendor / coach，named 和顶岗的 regular）：每天上班，有班次（早班 5:30–14:00、晚班 13:30–22:30、摊主 10:00–21:00……），
  岗位就是他们在 `homes` 里的位置对应的 `post` 地点。班中**歇一次**（30 分钟，吃饭，在员工休息处、餐车院子或最近的长椅），八个半钟头以上的班后半段再歇 15 分钟；歇的时候岗位空着（摊位关）。
  - 两班交接放在 15 点（午后最清静的 14 点不叠两个人）；有名有姓的人按自己的钟点，前后只差一个钟头以内的自己多干一会儿（不留空档、不叫人来顶半小时）；岗位自己有开门时间的（送货的货梯 6–12）班不排出去。
  - **交接**：下一个上岗的人已经在场、3 分钟以内到岗，岗位就算有人（`handoverPosts`）；接班的到了，上一班一刻钟以内就完的先走。所以摊位、泳池不因为换班关一下。
  - **泳池**：救生员歇班时一个泳池助理（`staff:sim:clubpool:lifeguard:reliefN`，一次歇班一个）提前二十分钟到，收躺椅毛巾，顶完班再收拾一会儿走；营业时间里池子不关。
  - **餐车**：平日只开四五家（正餐车三家、别的一两家，按天的种子轮休），周末全开——人集中在开着的车前才排得起队；下雨、风沙、夏天平日只开三家，夏天周末五家。
  - **夏天**（中午 40 多度，第 2 轮）：中午不排一屋子人守空店——场地维护 5:00 到、11 点前收工；门童 6–11、17:15 以后；专卖、纪念品、穿线、小卖部中午关（早上 + 17 点以后两班）；
    二楼酒吧、后厨 16:30 才来，服务员 17:00；体能教练 6–12、理疗 7–13；红土裁判 6:30–10:30；餐车只留一家正餐车、一家卖冰的中午开，别的 16:45 才来；广场饮料车只开傍晚。
    青训教练夏天只上早上的私教课。中午在岗的是代客、咖啡吧、果昔吧、健身房前台、洗衣房、救生员和那两家车。
  - **下雨、风沙**：泳池、广场饮料车（露天）整天不开，救生员、摊主不来。
  - **Dale**（people.md："每天早上扫一遍中心球场的台阶，没人付钱"）：上班（红土裁判、周日带课）的日子开班前三刻钟先扫南、东、北三面看台；不上班的日子 6 点多也来扫，扫完在会所、场边待一上午。
  - **青训教练**：第一节课前半小时到；上午、傍晚给会员上私教课（会员订的，60 分钟，在发球机那块场，学员是生成的会员），下午带青训课；课和课之间收拾球筐（15–20 分钟）和场边歇着轮着来，午饭歇 40 分钟；最后一节课完了就走。
  - 看台卖水、跟着球员的教练只在有表演赛的晚上（或球员上午训练）在岗，平常不对着空看台站一天。
- **named 会员和家人**：按 `week.days` / `week.hours` 来；hours 是他们到和走的大致时间（± 15 分钟抖动，种子定）。
- **regular**：同上（每人一周 1–5 天）。
- **客人**：今天来的会员（人群层）平日 180–220、周末 190–230，客人平日 90–120、周末 140–180，再按时段补三拨不打球的（上午 7:45–10:15 喝咖啡、广场、健身、看练球 26–36 人；
  午后 13:15–15:45 泳池、躺椅、树荫、逛店 16–24 人；傍晚 17:00–19:30 下班来吃饭、喝一杯 24–34 人）。夏天减半（早上那拨不减）、下雨大减、风沙减三成。
  按目的分（people.md 第四节的表：打球、上课、看球、吃饭、游泳、"下班来喝一杯"……）。目标：平日 8–10 点、12 点九十人以上的客人，员工不超过在场的 35%，20 点还有三十人以上。
  生成的人用 cast 的 `makePerson`（id `guest:sim:<天>:<n>`）：**一天里不撞名**——英文全名不重，不和有名有姓的人同名（不出第二个 Carmen），中文名先试几次不重（名字池三百来个，人多了总会重）。
- **午饭**：来吃饭的 11:25–12:05 到（走到餐车院子十来分钟），上午来的会员六成五留下吃了午饭再走，饭点大家一起饿（11:40 起饿的线二十分钟里降 25），所以 11:40–12:30 是最挤的时候；
  吃完一半人不急着走（躺椅、树荫、会所里坐一会儿）。晚饭 17:45–19:45。
- **一伙人**：夫妻（ties 的 spouse）、一家人（家长 + 孩子）、约好的双打（ties 里搭档 / 对手凑成四个，凑不齐的由人群补）一起到、一起走。
  - **孩子（小孩、少年）不自己来、不开车**：没有熟的大人顺路捎的，生成一个陪他来的家长；来当球童的从落客点进。Tommy 跟着 Verónica 一伙（ties："顺路捎他来"），Sofía 上课的时候他在青训场围网外对着墙打（`courts.wall`）。
  - **老伤**（`oldinjury`）不上场：自己来的在场边看、喝一杯、坐着聊；跟着一伙人来的（Héctor 跟 Carmen、Al、Bernice），别人上场他在场边坐着看（同样的钟点，一起走），一伙里上场的照样最多四个。
    喜欢匹克球的老伤（Curtis："网球跑不动了，匹克球刚好"，`picklesAnyway`）打匹克球、不上网球场（第 3 轮：people.md 的匹克球迷一天只看不打）。
  - 一个人来打球的会员七成出门前就约好了人（同一项、到的时间差半小时以内、水平差 ≤ 0.5）；一整天都订不到场的两个、四个人多半改约匹克球。
- **怎么来**：开车（停北 / 南停车场，一部分走代客落客点）、走路（东边大门外）、家长送孩子（落客点）。出入口是 `entry` 地点。
  客人（不是会员）三成五叫车来（落客点放下，`drop`），会员一成五；看表演赛的四成叫车。坐公交来的（Mateo："放学坐一小时公交来"，`ridesBus`）从车道东头走进来。
- **停车**（`Agent.car`，一伙人一样，画面按它摆车 / 演下车）：
  | `car` | 怎么来 | 从哪儿出现 |
  | --- | --- | --- |
  | `lotN` / `lotS` | 自己开车，停北 / 南停车场，占一个车位（`Agent.stall`，0..13；一伙人一个，从到的那一分钟到开走） | 那个停车场 |
  | `valet` | VIP，或者到的时候两个停车场都满了：开到代客落客点把车交给泊车员，车开去场外（不占车位，画面从落客点往东开出画） | 代客落客点 |
  | `drop` | 别人开车送来放下（孩子、家长送、来当球童的少年） | 代客落客点 |
  | `walk` | 走路来；或者停车场满了、代客台这个钟头也接满了，车停在外面路边走进来 | 东头车道 |
  | `staff` | 员工、摊主、球员停员工区（不占客人的车位） | 南停车场那边走进来 |

  两个停车场一共 28 个车位（地点表 `stalls`：北 14、南 14）。排日程时定想停哪个（`carOf`），**车位在到的那一分钟分**（`park`）：自己想停的那个满了换另一个，都满了改成 `valet`、出入口改成代客落客点，记一笔"北停车场停满了，车交给代客泊车"。
  **代客台一个钟头最多接 12 辆**（`VALET_PER_HOUR`：一个泊车员把车开去场外再走回来，门童搭把手，五分钟一辆；VIP 不算在里头）；接满了的车停到外面路边（`car: 'walk'`，从车道东头走进来，记一笔"代客台也排不过来"）。
  第 2 轮（默认天气）：停满了交代客的一天 34（周一）/ 34（周三）/ 47（周六）伙（连 VIP 43 / 54 / 60），最忙的钟头 13 辆（第 1 轮 51 / 76 / 115 伙、一个钟头二三十辆）；路边停的 0 / 24 / 46 伙。
  画面的车位用 `Agent.stall`（引擎分的），代客的车不进场里的车位。
- **出入口站不下一伙人**（五个人在代客落客点下车，落客点只站得下 4 个）：等它空了，先下来的站进去，其余的在旁边站一分钟，跟着带头的一起走（第 1 轮以前这伙人一直到不了）。
- **几点来**：没人在想去的地方开门前到（会员、客人最早 6:30；冲着泳池来的 6:50 以后，冲着酒吧来的 10:50 以后……，`opensFor`）；夏天的早鸟也是 6:30 起。风沙、下雨天没人冲着泳池、躺椅、高尔夫来。

### 4.2 日程（`Intent[]`）

按身份、特质、喜好、时辰排一串想做的事，例如会员：签到 → 更衣 → 打球（喜欢红土的去红土）→ 喝水 / 歇 → （赶上午饭就吃饭）→ 回家。
赶上饭点就吃一顿（午饭、晚饭），**零食**（吉事果、冰棍、奶茶、果昔，`Intent.snack`）不算饭；**一顿正餐吃过两个钟头以内**再碰到吃饭的那一项改成零食（`day.ateAt`）。
特质改日程：`sporty` 打两场、`foodie` 一定吃饭、`oldinjury` 不打只看和聊、`earlybird` 早来早走、`nightowl` 只来晚场、`snowbird` 夏天不来、
`competitive` 找水平差不多的人、`mentor` 会去青训场边看。孩子跟着家长，孩子的 intent 是上课 / 玩水 / 吃冰棍。

### 4.3 每一分钟（`step`）

1. 到点的人从出入口出现（`arrive`），开始第一项。
2. 干完一项（`until` 到了）→ 挑下一项的地点：按 kinds 找**开着的、没满的、最近的、他喜欢的**；满了 → 有队就排队，没队就换一个地方，都满了跳过（`full`）。
3. 路上走：`travel` 的 `t1` = 出发 + 路程 / 走路速度（直线 × 1.35）。一伙人一起走（跟着 lead）。
4. 排队：队头被服务（有员工 / 总监 / 自助）→ 进去；等的分钟扣 `patience`（`patience` 属性折成分钟，急性子短、候鸟长），扣完就放弃（`gaveUp`，走开去干下一项，记一笔）。
5. 需求：饿、渴、累随时间涨（打球涨得快、热天渴得快）；超过阈值就插一项（渴了去饮料车 / 水站、饿了去吃、累了坐下）。中午饿是大家一起饿（按时辰涨），这就是午饭高峰。
6. 天热（中午、夏天）：室外打球的意愿降，往 `shade` 的地方去，一部分人提前回家。
7. 到 `leaveBy` 或日程空了 → 往自己的出入口走（`leave`），到了就不在俱乐部了。关门以后客人必须走完；员工收拾完下班。
   日程空了、离走还早（来了不到 40 分钟，或离说好的走还有半个多钟头）：先去会所、阴凉处坐坐（最多补两回，`day.fill`），**没人来了半小时就走**（下雨、关门这种说得出原因的除外）。
8. 想干没干成（满了、没开、队排满了）**同一个人同一件事一天只记一笔**（`Agent.missed`），不在事件流里刷屏；累了想坐没地方就站着缓一缓，不一分钟想一次。
9. 凑人打球：等得越久越不挑（每等 5 分钟能差的水平多 0.25）；三个一个人来的先拆出两个打单打；头一回等不到（没凑上、没空场、拍架边没轮上）先去喝点东西，半个钟头后再来（一天一回），
   一个人的去发球机（不占别人订的钟点）、两个四个的多半改打匹克球；拍架边多等十分钟（知道是轮换），**最多等 28 分钟**（第 2 轮：不在拍架边站四十分钟）。第二回还不行才真放弃。目标：放弃的 < 15%。
   场边一轮一轮地等（同一处、同一件事接着干）不再记"开始"，日程里不出连着三行"看球"；接着坐上一轮的长椅，不一轮换一张。场边等搭子、看得到的场此刻没人打：是"坐着等人"（rest / chat），不是看球。
   **匹克球拍架**（第 3 轮重写，critique 问题 2：两块场空着、五个人在拍架边跺脚二十分钟）：拍架边只在**两块场都有人打**的时候排；有空场、凑得出两三个人（一伙两个、两个一个人来的、一伙三个轮着下）就马上上，
   四个最好；拍架是轮换的，排到谁谁上，不挑水平；凑成三个（一伙两个 + 一个人）先上能打的两个，那一个接着排。一个人来的有空场就坐到场边长椅等个搭子，排着排着空出一块场、还是一个人的也坐过去。
   "等了多久"：场边坐着等的按耗掉的耐心算，拍架边排着的按排上那一刻算（排拍架时耐心抬了十分钟，按耐心差算刚排上是负数——第 3 轮的 bug）。
   拍架边排满了坐在旁边等的，跟排拍架一样抬十分钟耐心（只在头一轮抬一次）。太晒不打了（`heatSkip`）：之后一个多钟头里日程上同样的球也不打了（不歇二十分钟又回场边、再被晒走）。
10. **不打转**（第 2 轮，`Agent.visits`：最近四个钟头去过哪儿、几点）：同一处两小时里最多去两回（更衣室四小时），零食、饮料窗口一小时一回；开着的都是刚去过的，这一项就算了。
    场地、课、高尔夫的洞、岗位不算（一局一局轮着打）；两局之间在场边长椅歇（刚从它看的场上下来）、打完一局在饮水点接水也不算。
    "坐坐"挑到了窗口 = 买杯喝的坐下喝（点单 → 去桌边、长椅），不在窗口前站一下就算歇过（第 1 轮 Amara 一下午在果昔窗口排十趟就是这么来的）。
11. **饮水点**（第 2 轮）：打完一局、一节课，有点渴（渴 ≥ 15）的在场边 30 米以内的饮水点接一杯水（1–2 分钟）再去干下一件；干别的时候渴到 45、25 米以内有饮水点也顺路接一杯；渴到 65 才去窗口坐下来喝。
12. **后面有约好钟点的事**（表演赛、课、订的场）：眼前不必须的事做不完就缩短，来不及就不做；一个钟头以内有约的不插吃饭、歇着（第 2 轮：球员吃顿饭误了表演赛开打）。刚在窗口拿了吃的，来不及坐下就几口吃完。
13. **换衣服**只在运动、游泳的前后（打完球冲个澡；看球、坐着之前不换，第 2 轮：Carmen 一上午进三回更衣室）。

### 4.4 地点规则

- **场地**（court / pickle）：一伙人占一块场；双打 4 个人，单打 2 个人；一场 60–90 分钟（匹克球一局 12–18 分钟，拍架边排队换下一组）。
- **前台**（desk，`director: true`）：会员进门先签到。总监在前台（`SimInput.director === 'desk.counter'`）→ 一人 1 分钟；不在 → 队头等 4 分钟后自己按铃登记（3 分钟），队伍会排长。
  这是"有人守的地方维持住"（准则 5）在人身上的样子。
- **关着的窗口**（第 3 轮，critique 问题 5：Verónica 一家走到关着的冰棍车、"换一家"六分钟后又去排）：挑窗口时不挑走到之前就到点关门、或摊主走到之前就下岗歇班（十分钟里没人回来）的；
  走到了发现关着、十分钟里开不了：换一家，**半小时里不再挑它**（`Agent.shut`），指定了这家的点单不点了、坐下吃喝那一项重新挑窗口（不空着手去桌边"吃"）；一会儿就开的排着等，耐心撑到开的那一分钟再多两分钟。
  排着排着到点关门、摊主歇班十分钟里回不来：马上换一家（不对着拉下卷帘的车干等）。摊主到点歇班、窗口前还排着人、没人来接班：先把排着的卖完再走（最多多干 10 分钟，`sellOut`）。
- **摊位**（stall，`needs` = 摊主的岗位）：摊主在岗才开；一人在窗口前点单 2–4 分钟（地点的 `stay`），然后**站到窗口边等餐**（`Place.pickup` 个位置：
  还在这个地点的 occupants 里、doing 还是 `order`，`spot = cap + k`；饭 3–6 分钟、喝的 1–3 分钟，冰棍不用等），窗口让给下一个，拿到了才去找座。
  一伙人一个人点单，其余的排在他后面（队看起来更长）。找座先坐看得见的伞下桌、野餐桌，凉棚下的长桌后坐；看台、池边不是吃饭的地方。
  第 3 轮：端着饭**不坐**看台、场边长椅、家长长椅（有 `faces`、对着场的地方；对着孩子玩的草皮角、喷泉的可以），都坐满了就站在窗口边几口吃完。
- **座位**（seat / table / stand / lounger）：满了就不坐（不排队），换一张或站着。拿了吃的找不到座（下雨天凉棚下坐满了）：站在窗口边几口吃完，算吃过了。
- **下雨**：淋得到的地方关（`rainedOn`：室外的场、座、桌、池子，**伞下、帆下的长椅也算淋得到**）；有顶的是会所里头（二楼露台不算）、凉亭、拱廊、凉棚（`roofed`）。
- **泳池**（pool / lounger）：救生员在岗（或交接中）才能下水；真暂停了，游泳的人上来在池边坐着等，救生员回来接着游，不回家。
- **课**（lesson）：教练在场、到点开始（15:30、16:30……），孩子提前半小时到，家长坐场边 `stand`；一节课最多 8 个孩子（排日程时就分到有名额的那节），上一节还没下课先在门口等。
  孩子在课上，一伙里带头的家长干完一件、换地方、没抢到座、看腻了，都**不把孩子从课上拉走**（`busyOwn` / `keepsOwn`；第 3 轮前每天有 1–4 个孩子课上到一半被家长带走，家长坐满了长椅时甚至整节课没上）。
  教练课间（第 3 轮）：在青训场上捡球、摆标志盘，不站在教练位上对着空场"喂球"；上课前走回教练位。
- **看**（第 2 轮重写）：看台、场边长椅有 `faces`（看得到哪几块场：中心球场三面看台 → 表演赛 / 球员练球，红土长椅 → 两块红土，青训家长长椅 → 青训西场和围网外，
  匹克球长椅 → 两块匹克球场，喷泉池沿 → 喷泉边玩水，草皮角边 → 草皮角）。**看球只去 faces 上此刻有人在打、或 15 分钟以内开打的地方**
  （约好钟点的——家长等孩子上课、表演赛——看到那时候；`Tick.watchable`）；一处都没有就改成找个地方坐坐。没有 faces 的地方不"看球"，只是坐着歇、聊天；
  场边长椅上歇着的，场上有人打才算在看。看着的场没人打了、10 分钟以内也没人来：每分钟四分之一的人起身（表演赛散场也是这样一拨一拨走）。
  家长看自己孩子的课：只挑看得到孩子那块场的长椅（青训家长长椅三个座，坐满了就在离那块场最近的地方坐着等，不去看喷泉、别的场）。草皮角边（`food.lawn.watch`）只给带孩子的大人（role parent），在那儿是"看孩子玩"。
  表演赛的观众开打前二十来分钟才去看台坐（早到的先吃喝）。
- **表演赛**：观众 17:25–18:25 陆续到（早到的一半先去餐车院子吃晚饭），18:30 开打；散场分几拨：一成多提前走，大半打完前后十几分钟走，四分之一留下来吃点、去酒吧，21 点前后走。
  在场的会员三成五去看（不是人人都去），平日观众 55–85、周末 110–150。

## 五、演（clubwalk/sim）

- 一个"观察"开关（valley 调试面板、`?sim=1`）：打开后场景演出里的人全部藏起来（道具照旧），换成引擎的人。
- 离镜头近的（取景范围外扩一圈）才给一具 Q 版人（池子，按 cast 的 look 换装）；远的只在小地图上是个点。
- 在路上的人沿导航路径走（起点、终点是两个地点的站位），到了站到第 `spot` 个站位，按 `doing` 摆姿势：
  打球 = ready / 正反手轮流（一块场上的人对着打）、坐 = sit、喝 = sip、排队 = 站着朝队头、干活 = 岗位的活（pour、skim、drag……）、游泳 / 健身先用最接近的姿势（**画面缺口记进 gaps**）。
- 时钟和天光同步：引擎的分钟就是 daylight 的时刻（看得到中午最亮、傍晚开灯）。
- 观察面板：时间、加速（慢 0.2× · 1× · 2× · 5× · 15× · 60× 游戏分钟 / 真实秒，**默认 2×**：一天七八分钟放完，路上的人按 `WALK_M_PER_MIN` 走，画面上 24 米 / 秒）、跳到某个时刻（7:00、12:00、16:00、19:00）、此刻在场人数（按区域）、
  "跟着一个人"（镜头跟着他，旁边一行写他今天的日程和现在在干什么）、最近的事件流。

## 六、变化

- 周几：周末客人多、家庭多、上午更满；周一维护日上午人少。
- 季节：旺季（11–4 月）候鸟在、全天满；夏天（6–9 月）早上 6 点就满、10 点以后空，傍晚才回来，中午几乎只有泳池和会所（12:30–15:15 补一拨 16–22 个冲着泳池、健身房来的）。
  夏天中午**员工也少**（见 4.1"夏天"）：中午在场的员工 8–12 个，客人 20–35 个。球员夏天天一亮练、吃了午饭回家（有表演赛的周六下午晚点来）。
  **夏天的期望**（报告"员工占比"）：11–18 点员工 ≤ 在场的 55%，别的钟点 ≤ 35%；13–16 点泳池、会所里的客人 ≥ 室外别处的三倍、泳池 ≥ 5 人。
- 天气：下雨 / 风沙 → 室外场空，人在会所里；有人干脆不来。

## 六点五、验收（每轮 critique 用）

1. **不变式**（测试）：同一时刻一个人只在一处；地点人数 ≤ cap；关门后客人走完；员工的班覆盖营业时间；确定性（同种子两次一样）；JSON 往返。
2. **节奏**（报告 `pnpm simday`）：每小时在场人数曲线有早高峰、午饭高峰、午后低谷、晚场高峰；午饭时段餐车院子 ≥ 60% 的人在吃；
   中午室外场占用 < 早上的一半；21:00 以后人数单调下降；每个 named 会员按 week 来。
3. **说得通**（抽 10 个人的一天，人读一遍）：先后顺序合理（不在签到前打球、不在泳池之后直接去打红土不换衣服……），等待和放弃有原因。
4. **看得见**（截图：7:30、12:30、14:30、16:00、18:30、21:30，手机竖屏）：画面上的人数、位置和报告一致；没有人站在墙里、水里、桌子上；
   没有人在路中间凭空出现 / 消失；姿势和在干什么对得上。缺画面的活列进 gaps。
5. **性能**：引擎一天（~1000 步）< 1 秒；`startDay` < 40 ms（热的 10–12 ms）、每步平均 < 0.3 ms（第 2 轮：周一 0.15、周三 0.20、周六 0.27–0.28、夏天 0.06）；快进用 `stepMany`（≈ 0.17 ms / 步）；画面加速 60× 时每帧引擎 < 4 ms，手机上帧率不掉档。
6. **第 1 轮加的检查**（`pnpm simday` 的节奏检查里，测试守着旺季一周）：平日员工 ≤ 在场的 35%（8–20 点每小时）；平日 11:50–12:30 三家以上餐车排着 ≥ 4 人；20 点还有 25 人以上的客人；
   老伤的不上场；孩子不自己来；不撞名；凑人打球放弃 < 15%；没人来了半小时就走；一顿饭只吃一次；泳池营业时间不关。
7. **第 2 轮加的检查**（测试守着旺季一周 + 夏天、雨、风沙）：
   - **员工占比**按天气写明要求（晴天旺季 ≤ 35%；夏天 11–18 点 ≤ 55%、别的钟点 ≤ 35%；雨、风沙 ≤ 60%，客人不到 10 个的钟点不看）——第 1 轮的检查在夏天、雨天直接打 ✓（87%、57% 也 ✓），是错的。
   - 今天不适用的检查打"—"（`Check.na`），不打 ✓。员工守岗按**今天排的班**算（夏天中午关的店、轮休的车不算没守住，`shiftSpans`）。
   - **人不打转**（`findLoops`）：同一处两小时三回、零食窗口一小时两回都算错。
   - **看球看有人打的**：看球的人·分钟里，看的场前 10 分钟到后 20 分钟都没人打的 < 3%（第 1 轮 19%）。
   - **饮水点有人用**（晴天旺季）：一天 ≥ 40 杯、七处里至少五处有人接过。
8. **第 3 轮加的检查**：
   - **拍架边不对着空场排**：拍架边有人排着的分钟里，有一块匹克球场空着（开着、场上没人、没人正走过去）的 < 5%（第 3 轮前：周一 86%、周三 56%、周六 53%；现在旺季一周都是 0%）。
     报告里另记"排着 ≥ 2 人又有空场"的分钟（`DayReport.rack`）。
   - 人不打转：场边的长椅、草坪（没写 faces 的，比如匹克球的球员草坪）前后一处是同一片的场，也算两局之间歇着。

## 七、还没做（以后）

- 好感、心情接到经历上（等太久、没被接待 → 记一笔）；人群的"耐心"已经在，接到经营数要等 M-0。
- 总监的活（拖场、换水桶、递毛巾）现在照旧由场景演出管；接到引擎是下一步（例如水站空了 → 渴的人皱眉走过）。

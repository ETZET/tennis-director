## 对照准则

1. 不做菜单：守住了。
2. 要有取舍：新手第 52 天"全额还"被锁只剩一项；老手第 53 天两项都锁；"展期结束"只有一项、筹码写"±"；"首批客人"收费那项几乎没理由选。
3. 后果留痕：做到了（发球机、Dale 当裁判）；结局没有回顾这一局。
4. 卡偶发而且有分量：开局太密、后期空着；"起风了"重复 4–5 次。
5. 招人排人：是核心；习惯和工单打架。
6. 放置时回到布置的样子：有人守柜台的场地也会掉到 0（柜台磨损 + 风）；会员一次掉 16 太陡。

## 最伤体验的五个问题和建议

1. **开局悄悄崩盘**（准则 6、4）：新手第 2–23 天两人守柜台，柜台磨损加风沙把两处场地磨到 0，第 3 周结算会员 16 → 0，期间没有一张卡。建议：有人在岗时柜台磨损减半或算轻度维护；设施第一次掉到 30 以下来一张 Dale 卡（"我去扫一下？"，代价是他离岗）；一周里会员最多掉一半。
2. **终点太贵，钱看不清楚**（准则 2，张力）：中心球场一条链 $14000；岗位不给收入数字。建议：岗位说明写"约 $X/轮"；重建拆两期或整体降到约 $6000；后期的钱要有去处（表演赛四期筹备正好接住）。
3. **后期空档、卡重复**（准则 4）：第 85–112 天 0 张卡；"起风了"原样来 4–5 次。建议：优先补第 12–16 周（GM-3 / GM-10）；"起风了"每季最多一次或按季节三个变体。
4. **贷款卡把人锁死**（准则 2）：两项都锁只能干等；扣款不写金额。建议：每张卡至少留一项付得起的；扣款写具体金额；借款时写清"到期还不上会怎样"。
5. **习惯抢走做工单的人**（准则 5）：修会所做到 38% 时 8:00 两人自己回柜台；工单做完人变空闲不回原岗。建议：派去工单的人做完以前不被习惯拉走（或拖放时提示"8:00 他会回柜台"）；做完回到上一个岗位。（对应人-13）

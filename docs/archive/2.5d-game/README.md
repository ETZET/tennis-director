# 归档：2.5D 时期的整套游戏（2026-11-12）

2.5D 时期的 16 周修复主线和派工（把人和总监拖到岗位、工单上）2026-11-09 作废，2026-11-12 把围着它搭的整套代码从构建里拿出来放在这里。
游戏流程在重新设计（`docs/design/game-design.md`「游戏流程：重新设计中」、`docs/design/backlog.md` 的 M-0），定了以后重写模拟。

**只作参考：** 不参与构建、类型检查、lint、测试，谁也不能引用（`pnpm check:deps` 的 `no-archive`）。要用里面的想法，就在新代码里重写。

| 路径 | 原来是 |
| --- | --- |
| `packages/sim/` | `@td/sim`：纯函数式模拟（时钟、命令、系统顺序、派工 `staff.ts`、走路、事件引擎和导演、白名单效果、场地可用度、每日结算、星级、赛事、选路、地块、结局、存档迁移、机器人），存档版本 15 |
| `packages/content/` | `@td/content`：YAML 内容（地图 `acts/indian_wells.yaml`、27 张卡、岗位、工单、17 个人、特质、中英文案）、Zod schema、编译器、Vite 热重载插件 |
| `packages/ui/` | `@td/ui`：Preact 界面（场边转播 HUD、事件卡、结算卡、员工条、地点说明、调试面板） |
| `apps/game/` | `@td/game`：没有画面的游戏（实时 → 游戏分钟、命令队列、HUD 投影、自动存档、试玩桥 `window.__td`） |
| `apps/sim-cli/` | 命令行无头跑局：机器人报告、可玩性报告、确定性闸口、平衡区间测试 |
| `tools/playtest/` | 试玩桥：无头 Chromium 里一步一步玩构建好的游戏 |
| `docs/content-guide.md` | 不写代码加卡的写法 |
| `docs/people.md` | 人物设计：《八十亿分之一》等研究、四类作用、特质、招聘日 |
| `docs/people-sim.md` | 人物模拟方案（原 ADR 0028）：行为词典、17 个人的故事、一天、性子和牵连 |
| `docs/research-main-line.md` | 经营游戏怎么搭主线、建造感、掌控感、多样性（通用研究，M-0 可以参考） |

值得重写时参考的做法：种子随机和命令日志重放（确定性）、事件卡和导演的节奏、白名单效果 + 内容编译校验、存档逐级迁移、场地可用度的五种脏乱、每日结算卡、因果日志、机器人跑局守平衡区间。

# 2026-11-04 人物设计方向：5 个 demo

制作人反馈：现在的人（8×14）太卡通、像素太少，样貌和特征表现不出来。做了五个方向，都放进真实的 Palm Oasis 场景里和现有的人并排比。共用简报 `brief.md`，每个方向的规格、成本、风险在 `a.md`–`e.md`。

| 方向 | 页面 | 规格 | 一句话 |
| --- | --- | --- | --- |
| A 写实比例 | `apps/sandbox/chars-a.html` | 成人 16×32，约 5 头身 | 镜头近一倍（k 7.8、1× 像素）时和场景同密度，脸、眼镜、护膝都在 |
| B 小而全 | `chars-b.html` | 成人 12×24，约 3.2 头身 | 最务实：默认镜头近一档（k 5.2）即可 |
| C 双层（制作人选定，v2） | `chars-c.html` | 场景 10×18 + 48×48 肖像、5 种表情 | 地图上说话只有气泡（名牌、标志色、人物自己演情绪），肖像只在花名册里出现 |
| D 体型先行 | `chars-d.html` | 16 种身体模板，22–29 高 | 剪影就认得出；每人自己的走路和小动作 |
| E 高清像素 | `chars-e.html` | 成人 24×40，5 级色阶、轮廓光 | 单看最好看，但和经营视角冲突（镜头要近 4–6 倍），不建议当主画法 |

总览：`apps/sandbox/chars.html`。本地 `pnpm dev` 后打开 `/chars.html`。

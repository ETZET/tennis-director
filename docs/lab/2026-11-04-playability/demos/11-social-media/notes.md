# 11 社交媒体：评分和口碑

**一句话：** 总监举着一部像素手机，评论一张张弹出来（头像表情、星星、照片缩略图、一句话），拖到图标上处理；回得好评分翻星、粉丝跳涨，回砸了表情风暴、报纸头条；评分和粉丝直接变成门口进不进人。

## 怎么玩

1. 上半屏是俱乐部（Dale 带小孩、狗在溜达、门口有人来），下半屏是总监手里的手机。新评论来时手机震一下，一个气泡从园区飞进手机。
2. **拖评论卡**到下面四个图标：💬回复 / 🎁体验课 $15 / 🚩举报 / 🗑️无视。左滑 = 无视，右滑 = 回复。卡下面有倒计时条，超时就算没回。
3. 回复再选一个语气贴纸：**道歉+券 $20 / 真诚解释 / 怼回去 / 卖萌**。
4. 左上 📷：拖取景框框住俱乐部的一块拍照发帖（一天一次）。早上框住一号场有小孩，傍晚有日落，框住狗加分；二号场的沙、脏泳池会被群嘲。
5. 右上 💰：$60 买 6 条五星水军，评分立刻涨；之后博主来时可能扒出来。
6. 4 天 × 55 秒 ≈ 4 分钟。结束给评分、粉丝、现金和称号（网红总监 / 公关灾难 / 水军头子 / 火眼金睛 / 赔笑总监 / 口碑总监 / 流量总监 / 嘴快总监 / 佛系总监）。

`?fast=8` 加速，`?seed=42` 固定随机。

## 在测的假设

- **20–40 秒（北极星第一条）：** 每 8–10 秒一张卡，每张都要"看人下菜碟"：是会员、游客、博主、托儿还是喷子？抱怨是真问题（沙子、脏泳池、前台慢、贵）还是瞎说（太热、太远）？读头像和照片就能判断，不用读长文字。
- **3–5 分钟（第二条）：** 博主（12k 粉丝，评分算 3 条）是固定的大事件：第 2 天来一次差评，第 4 天回访。回得好"爆了🔥"粉丝 +1000~2000；怼翻车"搞砸了"粉丝 −40% 加报纸头条。连抓两个托儿也会上头条。
- **一局（第三条）：** 称号按玩法风格出：一路道歉送券的是"赔笑总监"，敢怼的要么"网红"要么"公关灾难"，刷水军的不管被不被扒都是"水军头子"。

## 反馈清单

- 新评论：手机震动 + 嗡嗡声 + 一个像素气泡从园区飞进手机，卡片从上面滑入；博主来时飘"博主来了！12k 粉丝"。
- 拖卡：卡跟手走，经过图标时图标抬起、"嗒"一声；左滑/右滑出现小图标提示。
- 结果：星星一颗颗翻牌（带"叮"），头像表情换（笑、怒、哭、震惊、得意），结果气泡（绿/红/金/红底白字），爱心或 💢 粒子；卡片飞上去（好）、掉下去（坏）、滑走（无视）。
- 爆红：金色卡底 + "爆了！🔥" + 爱心和星星爆开 + 号角音 + 热度火苗条满格并抖动 + 粉丝数滚动。
- 翻车：屏幕抖 + 低沉音 + 40 个 💢 + "搞砸了…" + "沙漠日报"头条拍下来。
- HUD：大号像素评分数字 + 半星；跨过半星时星星翻转。粉丝数滚动，花钱飘红字。
- 园区：门口的人举手机看评分，冒 ♥ 进门（+$8 金币声）或 💢 掉头（"评分太低，走了"）。
- 拍照：取景框外变暗，手机里实时放大取景；快门白闪；点赞数往上滚、评论头像出现、一句评论气泡。

## 如果选中，怎么接进现在的游戏

- **手机是 HUD 里的一个东西**（准则 1：直接点 HUD）。评论不是新系统，而是现有"服务率、设施档位、员工在岗"的**读数**：二号场掉档 → 关于沙子的差评变多；泳池没人管 → "绿得像汤"。玩家会因为一条差评去把 Rosa 拖到二号场——口碑把排人和事件连起来。
- **评分 = 声望的可视化。** 现在声望按周平均服务率结算（准则 6）；可以让每周日结算时，本周的评论（含玩家回复改过的星）决定声望变化，而不是实时漂移。
- **博主、La Quinta 托儿、报纸头条**做成事件卡（`events/indian_wells/`），按准则 4 偶发、有分量；平时的小评论是低分量的"小卡"，可以按会员数限流（一天 3–5 张）。
- **回复要占总监时间**：总监拿着手机就不在岗位上（总监是劳动力），这是天然的取舍；也可以招一个"社媒运营"员工（Lily 双语夜猫子很合适）自动回、但只会一种语气。
- **拍照**接在现有的设施画面层上：取景判断直接读 `Site` 的锚点（`court_1`、`pool`），设施状态档位决定好看不好看；日落用现有的 `daylight.ts`。
- 因果日志：每条"翻车/爆红/被扒"写进日志，结局称号读这些标记。

## 和玩法准则的冲突

- **准则 4（事件偶发、有分量）**：这个 demo 每 8–10 秒一张卡，偏"流水线"。正式版要把普通评论降成低分量的快速判断（一天几张），只让博主/托儿/水军被扒走事件卡。
- **准则 6（会员、声望不实时漂移）**：demo 里评分实时变、门口转化实时变。正式版应改成"评论实时出现，周日结算声望"。
- **准则 2（取舍）**：基本守住了，没有全面最优的按钮；但"无视喷子"接近免费最优——这是故意的（教玩家别理喷子），需要的话可以让无视喷子有小概率"喷子带节奏"。
- 准则 1 不冲突：动作都是回应来找你的评论，或者直接拖 HUD 里的东西。

## 已知不足 / 第二轮可以加什么

- 结果是随机概率，玩家不容易知道"为什么这次怼成功了"。第二轮给每个评论者加一个可读的小标签（脾气条、粉丝数），让成功率有线索。
- 评论只有一种节奏；可以加"连评"（喷子带一群小号一起来）、"会员私信"（不公开，但会退会）。
- 发帖只看框住了什么，没有构图手感；可以加"等狗走进框"的时机、滤镜贴纸。
- 托儿的破绽（墨镜、草地场照片、成对出现）需要玩家自己发现，说明里有提示；首局可能看不出来。
- 和园区的连接还是单向的（评分 → 来人）；第二轮可以让玩家看到差评后直接点二号场派人扫沙，第二天评论变好。
- 数值没调：现金偏紧，水军被扒的概率可能太高。

# 11 社交媒体 · 第二轮

入口 `apps/sandbox/demo-social.html`（`pnpm dev` 后 `/demo-social.html`），代码在 `apps/sandbox/src/demos/social/`。
`?fast=N` 加速，`?seed=N` 固定随机，`?auto=1` 自动玩到结束（`full.mjs` 用它跑通一局），`?mute` 静音。
截图：`apps/sandbox/public/shots/social-1.png`（开始）、`social-2.png`（卡拖到"回复"上松手、语气贴纸弹出，`play.mjs`）。

## 制作人反馈"太糊了看不清"之后

- 场景按整数倍放大：`pixelSize: 2`（每个缓冲像素 2 CSS 像素，3 倍屏上 6 个设备像素），容器宽高取偶数，`image-rendering: pixelated`；手机里的字符画也都是整数倍（头像 4 倍、星星 3 倍、照片 2 倍、取景预览 4 倍）。
- 人物在屏幕上是原来的 2 倍（约 28 CSS 像素高）。镜头对着东半边热闹的地方：大门、匹克球场（积沙；原来的红土场太远，沙子问题挪到这里）、喷泉、青训场（小孩）、中心球场（日落）；狗在广场附近转。单指可以拖地图看别处，不缩放；拍照时地图锁住。
- 当前的评论卡放大并居中（322×226）：大头像、3 倍星星、152×96 的现场照片（认得出是哪块场地、谁站在那儿）、20px 的一句话；收件箱小头像在它上面，四个图标在下面。
- 写评论的人离地点太远时不再横穿整个园子，直接换一个就在那儿的人写（第一张卡大约 6 秒到）。

## 改了什么

**画面：上半屏换成真的 Palm Oasis**（`@td/iso` 的 `INDIAN_WELLS`，镜头见上一节）。
- 场里的人都是 `Person`：访客从停车场走到大门，掏手机看评分（头顶飘 `3.4`），冒 ♥ 进门（+$8）或冒怒气掉头（"评分低，走了"）；早上青训场 Dale 带三个小孩，中心球场两个人在打，一只狗沿广场和草坪闲逛，Rosa 在会所门口待命。
- **评论从人身上长出来**：写评论的人走到他要抱怨的地方 → 掏手机、头顶"…" → 冒出一张像素评论小卡（金星好评 / 红星差评）→ 小卡沿弧线飞进手机收件箱。托儿、喷子场里没这个人，小卡从岛外飞进来。
- 卡片在手机最前面时，写它的那个人头顶挂金色名牌（▼ Linda），卡和场景是连着的。
- 设施状态走 `Site.createOverlays`：匹克球场开局是被沙埋的档、喷泉是掉档的浑水；点场景里的牌子（游戏 `.tg` 的样子 + 竖线）花 $25 派 Rosa 走过去扫（耙子手势 + 扬尘 + 进度条），扫完设施换成修好的画面，之后关于沙的差评不再出现，已经在收件箱里的沙子差评回一句"已经修好了"就能改观。

**像素手机**：外壳是 195×235 的像素缓冲放大 2 倍，两只像素手（换色字符画，拇指搭在屏边）。
- 评论卡：头像是用写评论那个人的 `Person` 外观（肤色、发色、发型、上衣）换色的 12×12 字符画脸，回复后换表情；字符画星星；**照片缩略图就是渲染器画面的裁剪**（照的是他抱怨的地方：沙场就是那块被沙埋的匹克球场）；托儿的照片是字符画草地场（我们没有草地场）。一行字、三个小标签：身份、脾气（图标）、在场里 / 场外。
- 四个像素图标：回复（再弹出四张语气贴纸：道歉券 $15 / 真诚 / 怼回去 / 卖萌）、体验课 $20、举报、无视。右滑＝回复，左滑＝无视。

**📷 拍照**：在场景上拖取景框（点空白处框直接跳过去），手机里是取景框里的实时渲染画面（2 倍放大），下面实时列出框里有什么、各值几分（日落场 +4、狗狗 +4、小朋友 +3、喷泉 +2 / 脏喷泉 −4、沙场 −5、人气），合计决定点赞和涨粉。每天一次。

**修第一轮的弱点**
- 结果读得懂：结果基本是确定的，由卡上看得见的东西决定（身份、脾气、照片里的问题是真是假、修没修好），只有"怼喷子"故意是赌。每次处理后手机里出一条原因条：`博主喜欢真诚 → +300粉`、`爱实惠，券真香 → +3★ +15粉`、`场里没这人 → 删除 +60粉`、`没修就请来 → +1条一星`。
- 不再是流水线：一天 5–6 张（约 12–15 秒一张），收件箱最多 3 张，排着的卡在顶栏是小头像 + 耐心条，点一下换到前面（先回博主还是先回会员是个决定）；耐心 30 秒，等不到回复就是"等不到回复 → +1条一星"。
- 门口的效果两处都看得见：现场每个人进 / 走都飘字；每天收工一张小结：门口进几个走几个、评分变化和对应的进门率、粉丝变化和"明天多来 N 人"、收支、修好了什么。

保留：水军（双击确认 $60，+6 条五星；博主来时可能扒出来 → 报纸头条、水军全删、+6 一星、粉丝 −40%）、博主（第 2 天来骂最脏的地方，第 4 天回访：沙修好了、没翻车就是好评）、热度火苗（爆红灌满，热度高门口来人翻倍）、沙漠日报头条、称号。

## 手感和 UI

- 按下卡：0 延迟抬起（放大、倾斜、金边、拿起音、`buzz(8)`），卡跟手不缓动；拖到图标附近（带 10–18px 吸附范围）卡缩小浮到图标上方、图标抬起变金、"嗒"一声 + 轻震；松手卡吸进图标再弹回、换脸、翻星（每颗一声"叮"），结果条 + 原因条，卡往上飞（好）/ 往下掉（坏）/ 侧滑（没变化）。拖到别处松手弹回原位。
- 左右滑时卡两边出现无视 / 回复的像素图标提示。
- 镜头只能单指平移（不缩放）；拖卡在手机里，不和镜头抢；拍照模式下镜头锁住，只拖取景框。
- HUD 和游戏一套：海军蓝方角面板、奶油字、TD Digits 数字、Silkscreen 小标签、2px 硬投影；按钮全部 ≥ 44px 有按压态；文字每行 ≤ 14 字，规则放在"?"里。
- 帧率：静态层由 iso 缓存，动态只有十几个人、狗、粒子；手机里的实时预览只在拍照模式画。

## 一局多久

4 天 × 70 秒 + 每天小结 ≈ 5 分钟。

## 还差什么

- 喷泉清好以后照片加分，但除了喷泉和沙场，其他抱怨（前台慢、贵、太热、太远）在场景里没有对应的"修"，只能靠回复。
- 头像是自己画的 12×12 脸（照着 `Person` 的换色），不是精灵表的原帧放大；发型只分了几类。
- 自动玩的策略拍不到 7 分以上的照片（需要日落 + 狗同框），手动可以；没有专门测过数值平衡，现金偏紧的问题比第一轮好（修沙场有回报）。
- 取景框不能出状态条下沿，中心球场靠上，要先拖地图再拍。
- 拖开地图以后，如果抱怨的地方在屏幕外，评论照片是空的（照片取的是当前画面）。
- 卡上的"脾气"是直接写出来的，可以再藏一点（例如只在会员第二次评论时出现）。

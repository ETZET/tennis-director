# 07 挑战赛：滑动击球

**一句话**：La Quinta 的总监 Chad「月亮球」下战书，你在竖屏球场上靠"上滑 + 松手时机"亲自打一场抢七，看台上的会员当场为你签约或者倒戈。

## 怎么玩

- 选一张**战前准备卡**（Dale 指导 / 能量饮料 / 让观众起哄），然后开打：抢七，先到 7 分、领先 2 分（10 分封顶）。
- 你的人**自动跑位**。球飞来时接球点出现一个**缩小的圈**，圈缩到最小、变金色的瞬间**松手**：完美 / 好球 / 早了 / 晚了。早于窗口太多 = 挥空。
- **上滑**：方向 = 落点，滑得越长越深（太长出界）；按住时有一条瞄准虚线，落点绿 = 在界内，红 ✕ = 出界。
- 滑出**弧线**：向左弯 = 上旋（落得早，能打更狠），向右弯 = 切削（低、慢、对手难受）。
- **发球**：球抛到最高点时上滑，球要落进斜对面的发球区；一发失误还有二发。
- 打完 6 分**换边休息**，再选一次（Dale 再讲两句 / 冲看台挥拳 / 垃圾话 / 什么都不做）。

一局大约 2.5–3.5 分钟（比赛约 130 秒游戏时间 + 两次选卡 + 结算）。

## 在测的假设

- **20–40 秒**：每一拍都是一个小赌注（压线还是保守、发力还是求稳），每 6 分有一次总监式的取舍（换边卡）。
- **3–5 分钟**：完美扣杀（顿帧 + 震屏 + 全场人浪）、赛点下网、ACE，一场至少出一个。
- **一局**：结尾按打法给称号（节拍器 / 扣杀狂人 / 表演型 / 暴力美学 / 差一口气 / 手比心快……），准备卡和换边卡决定"你是靠谁赢的"。

## 取舍表

| 决定 | 换来 | 付出 |
| --- | --- | --- |
| 滑得长（深球） | 对手压力大、更容易失误 | 超过底线就 OUT |
| 角度大 | 对手跑不到 → 制胜分 | 出边线 |
| 上旋 | 球落得早，可以滑得更长不出界；对手 +4% 失误 | 同样长度下更浅，要多滑一点 |
| 切削 | 低、慢、对手 +4% 失误 | 球浅，Chad 会抽你空当 |
| 打浅（短球） | 安全 | Chad 78% 会直接抽击你的空当 |
| 战前：Dale 指导 | 完美/好球窗口变宽；完美时 Dale 喊"就现在" | Dale 明天累趴少一节课 −$80 |
| 战前：能量饮料 | 力量 +12%、球速 +15%，对手 +8% 失误 | 落点散布 ×1.3，瞄准线会抖；−$12 |
| 战前：观众起哄 | 关键分（任一方到 5 分）Chad 失误 +7%；赢了奖励 ×1.5 | 输了口碑损失 ×2 |
| 换边：再听 Dale | 完美窗口再宽一点；调动 Chad 后他失误翻倍 | 明天再 −$40 |
| 换边：冲看台挥拳 | 赢了会员再 +3 | 输了口碑再 −4 |
| 换边：垃圾话 | Chad 失误 +5% | Chad 抽击变多；口碑 −2 |
| 换边：喝口水 | 什么都不变 | 什么都不付 |
| 总监下场本身 | 赢了：声望 + 当场签约的会员 + 冷饮 $50 | 前台一下午没人 −$60；输了口碑和会员都掉 |

机器人测（`?bench=300&sigma=…`，sigma 是松手时机的标准差）：时机误差 0.10 s 胜率约 78%，0.13 s 约 60%，0.16 s 约 30%。第一次玩的人大概落在 0.13–0.18 之间，所以能赢，但不是每次都赢。Dale 卡在机器人里最强（机器人只会输在时机上）；真人有瞄准线，饮料卡会好一些。

## 反馈清单

- 松手：完美 → 顿帧 90 ms + 白闪 + 金色粒子 + "完美!" + 叮咚音效 + 金色球拖尾；好球 / 早了 / 晚了各有弹字和不同的击球声。
- 扣杀（Chad 挑出短高球时提示"可以扣杀!"、圈变红）：顿帧 130 ms + 震屏 + 大字"扣杀!!" + 低音轰响。
- 上旋 / 切削：蓝字"上旋↻ / 切削↺"。
- 落地：每一跳都有尘土粒子和弹地声；出界 → 红色大字"OUT!" + 两声裁判哔 + 轻震；压线 → 绿字"压线!"；下网 → "下网!" + 闷响。
- 一分结束：比分数字跳动；自家看台跳起来、冒 ♥ / ! / ♪ 气泡、欢呼噪声；输分时垂头、冒 … / 汗 / 怒气泡、叹气音效；对面 La Quinta 的红帽子球迷反着来。
- 连赢 3 分 / 扣杀得分 / 赛点：全场人浪（看台按顺序起立）。"你的赛点!" / "Chad 赛点!" 提示。
- Chad 冒话："天上有什么好看的？" / "……运气。"；垃圾话以后变成"你说谁退休？！"；够不着球时冒"!!"。
- 结束：胜利音阶 + 满屏彩纸；结算卡列出声望、会员、每一笔钱、称号和一句评价。

## 如果选中，怎么接进游戏

- **事件卡触发**：La Quinta 的挑战信是一张偶发的卡（第二幕以后、声望过某个线、或者 Chad 那条剧情线）。接受就打这一场，拒绝就是"怂了"（小幅口碑 −，Chad 后续卡更嚣张）。
- **总监是劳动力**：比赛占掉总监一个下午（游戏时间几小时），总监原来的岗位空着，按现有"没人在岗收入为零"规则自然少收，不用另写 −$60。Dale 指导就是把 Dale 从课程岗位上拉走，明天他带"累"状态。
- **场地**：在 `court_1`（或者后来修好的中心场）打；场地状况影响球的弹跳（磨损的场地落点散布更大），把"修场地"和"打比赛"连起来。看台人数 = 当前会员数的一部分，修了看台就坐得更满。
- **周日结算**：赢球的声望走现有声望变量；"看台上当场签约"的会员可以作为下一周结算时额外的会员流入（不必当场跳）。
- **因果日志**：记"你 7:5 赢了 Chad（扣杀 2 次）"，后续卡引用（Chad 复仇战、La Quinta 挖人、本地报纸报道）。
- sim 只算结果：每一拍的输入（方向、长度、时机误差、旋转）是命令，比分由模拟的种子随机数算；画面只演出。

## 和玩法准则的冲突（按制作人要求不为准则削弱玩法，这里只记下）

- 准则 1（不做菜单式操作）：不冲突，是直接操作场景里的东西。
- 准则 4（事件偶发、有分量）：要防止它变成每天必打的流水线，只能作为偶发事件卡出现。
- 准则 6（会员、声望按周结算、不实时漂移）：结算卡里会员和声望是当场变的，正式做时可以挪到周日结算里兑现。
- 这是一个需要专心的动作小游戏，打的时候世界其余部分基本是暂停的（准则 6"不操作时世界照样运转"的反面）。

## 已知不足 / 第二轮

- 只有一个对手性格。第二轮可以加大炮发球手、底线机器、网前型，每个对应不同的 La Quinta 剧情。
- 网前截击和放小球只有 Chad 会打；可以加"下滑 = 放小球"、"向前双击 = 上网"。
- 人物精灵很小（8×14），挥拍只有两帧；扣杀和完美球可以加专门的姿势。
- 瞄准线可能让瞄准太容易（难度主要在时机）。可以做成"只显示方向不显示落点"的高难度，或者把瞄准线做成 Dale 指导卡的专属好处。
- 时机窗口是按游戏时间算的，触屏延迟和帧率会影响手感，需要真机校准（可能要整体往后挪 30–50 ms）。
- 测试用参数：`?auto`（机器人自动打）、`?fast=8`（加速）、`?bench=300&sigma=0.13`（不出画面跑 300 局，在控制台打出胜率）、`?seed=123`。

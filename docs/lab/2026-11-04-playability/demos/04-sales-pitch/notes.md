# 04 推销台：看人下菜碟

**一句话**：总监站前台，一位位客人进门。看穿戴猜底细，出话术卡，再拖价格条讨价还价。撒谎来钱快，但会被记住。

## 怎么玩

1. 客人进门，屏幕中间是一个放大的像素人（32×64 逻辑像素）。下面一行"你注意到"写着线索：金表、旧球鞋、带着孩子、晒伤、La Quinta 传单、墨镜加小本子……
2. 每位客人发 4 张话术卡，最多出 3 张。卡上标着 实话 / 夸张 / 谎话 / 促销 / 送 / 恭维。出卡后兴趣条和怀疑条立刻跳动，客人变脸、冒表情和台词。怀疑到 100 就摔门走，留一星。
3. 开价：从 年卡 $900 / 月卡 $90 / 私教课包 $360 / 球拍 $160 里选一样。选错了他会说"我要这个干嘛"。再拖价格条（0.5×–3× 标价），拖的时候他的脸色跟着变，精明的人会板着脸 😶。
4. 报高了他还价，你可以接受、再推一把（最多 2 次，越推越恼）或者不卖。报低了当场成交，同时告诉你"他本来愿意出 $X，你少赚了 $Y"。
5. 耐心条一直在掉，拖久了客人自己走。
6. 7 位客人以后打烊结算：营收、诚信、平均星级，再来一段"一周后……"：谎话被拆穿、退款、转介绍、《沙漠太阳报》的报道。最后给一个头衔。

一局 7 位客人，每位大约 25–40 秒，加上结算一共 3.5–5 分钟。`?fast=1` 把时间调快 6 倍，`?seed=N` 固定一局。

## 在测的假设

- **20–40 秒**：每位客人有三个连在一起的决定：出哪张卡、卖什么、报多少。每个都要先读人再下手，读错会马上看到代价。
- **3–5 分钟**："赚到了"是把高尔夫土豪 Chad 的年卡卖到 $2,700（金色闪光、撒金币、"宰到了！"），他还给五星。"搞砸了"是对伪装成普通客人的记者 Marisol 撒谎，她低头在小本子上记一笔。怀疑爆表时她摔门走，离开后揭晓身份，跳出报纸头版「Palm Oasis 前台：张口就来」。
- **一局**：头衔按营收和诚信分（金牌销售 / 沙漠奸商（很有钱） / 老实巴交的总监 / 两头落空的推销员 / 上了头版的沙漠骗子）。"一周后"那一段把这局的风格算回钱上。

## 取舍表

| 决定 | 换来 | 付出 |
| --- | --- | --- |
| 谎话卡（只剩两个名额、Dale 打过温网） | 兴趣涨得最多，对哪种需求的人都管用 | 怀疑大涨，精明的人涨得更多；诚信 −12；一周后按精明度有概率被拆穿，变一星，会籍退一半钱；对记者撒谎会上报纸 |
| 夸张卡（名人也在这打） | 对想要面子、想社交的人兴趣涨得多 | 怀疑涨一些，诚信 −6，一周后被拆穿的概率小一点 |
| 实话卡（孩子的未来、比 La Quinta 划算、派对、雪山、老实说……） | 怀疑不涨或者下降，诚信涨；成交后可能有转介绍 | 要读对人才有用：没孩子的人听"孩子的未来"会皱眉，没拿传单的人听"La Quinta"一脸茫然 |
| 老实说…… | 怀疑 −28，精明的人兴趣反而大涨 | 对好糊弄的人几乎不加兴趣，白用一张卡 |
| 限时八折 | 对只想便宜的人兴趣大涨，也不怎么加怀疑 | 报价封顶八折价，对土豪等于白扔钱（Chad："我看起来像缺钱的吗？"） |
| 免费体验课 | 稳涨兴趣，还降怀疑 | 当场花 $30（Dale 的时间） |
| 恭维 | 对想要面子的人很灵 | 精明的人会起疑 |
| 少出卡、直接开价 | 省耐心，不冒险 | 兴趣低，他心里的价位也低 |
| 卖什么 | 卖对路的商品，他心里的价位高 | 年卡标价高，但只合某些人的需求；换商品会花耐心 |
| 报高 / 再推一把 | 宰得到就是大钱 | 每次被还价都加怀疑、降价位；推两次他就走；卖到标价 1.6 倍以上，一周后可能退一半 |
| 报低 | 稳成交 | 结果卡直接告诉你少赚了多少 |

## 反馈清单

- 出卡：卡片飞向客人，"哔"一声；兴趣、怀疑飘字（绿 / 红），条形弹跳；客人变脸（开心、狐疑挑眉、皱眉、发怒变红），冒表情和台词。怀疑大涨时屏幕抖一下，配低沉音；兴趣大涨时金色闪光。
- 怀疑 ≥ 70：怀疑条闪红；客人默认挂着挑眉脸。
- 对记者说了谎话或夸张：她的小本子上有笔在动，提示行写"（她低头在小本子上写了几个字。）"，配写字声。
- 选商品：客人立刻表态（😃 / 🤔 / 😕 加一句台词）。
- 拖价格：每跳一档"嘀"一声，旁边的表情和像素脸实时变化（土豪一直 😎，精明的人 😶）。
- 还价：气泡给出还价，客人 😤 或 🤨，报得离谱时屏幕抖。
- 成交：收银机亮灯，撒金币，飘 +$ 字，响钱声；榨到他心里价位 90% 以上时金闪、长音阶、"宰到了！"。
- 摔门：红闪，屏幕连抖三下，关门声，"★ 差评"，结果卡上写一星留言。
- 每位客人走后揭晓他其实的需求、预算和精明度，让玩家校准自己的读人眼光。记者走后弹出报纸。
- 结算："一周后"的事件一条条滑进来，红绿金额，配头衔和一句评价。

## 如果选中，怎么接进现在的游戏

- 接在**前台岗位**上：有人在前台时，客人照常按服务率自动成交。总监亲自站前台时，偶尔有"重要客人"（土豪、记者、团体、比价客）冒气泡排队，点一下进推销台。一天两三位，不是每个客人都要谈，保持"偶发、有分量"。
- 总监是劳动力：站前台推销的这段时间，总监不在别的岗位、工单上。
- 结果进**周日结算**：成交直接进营收和会员数；谎话进一个"待拆穿"池，周日按精明度结算差评、退会、退款；记者的报道变成一张事件卡，影响声望和下周客流。
- 话术卡从剧情和设施里来：修好红土场才解锁"比 La Quinta 划算"，招到 Jess 才解锁"免费体验课"。谎话卡一直都在，是最顺手的工具，所以设施建设有了直接的销售意义。
- 人物态度：Dale 会对"Dale 打过温网"有反应（好感下降，或者一张后续卡"你能别再这么说了吗"）。

## 和玩法准则的冲突（制作人说这轮不受准则限制，只记一下）

- 准则 6：收入取决于讨价还价，不再只是"有人在岗 × 基数"；客人当场流失、当场写差评，不等周末结算。
- 准则 4：做成每天都有的流水线就会腻。接进游戏时要限量（一天两三位关键客人）。
- 准则 1：推销台是一个新的全屏操作层；不过入口是"来找你的人"，算是回应事件。

## 已知不足 / 第二轮可以加什么

- 线索都是明牌，没有假线索。可以加"金表是假的"、"穿得朴素其实是石油大亨"这类反转。
- 卡组固定 11 张，没有成长。可以让卡升级、靠招人和修设施解锁，再加"同一句话对同一个人说两遍会翻车"。
- 记者的线索（墨镜加小本子）偏明显。可以让她换装，或者一局里藏两位里随机一位。
- 价格条的读脸有随机偏差，但玩几局能摸出规律。第二轮可以加一个"读心"技能：花耐心换一条提示。
- 像素脸只有 16×32 格，表情幅度有限，戴遮阳帽的土豪脸有点挤。可以单独画一张更大的半身头像。
- 用知道底价的机器人测过（`playthrough.mjs` 随机乱打，另有一个读底价的脚本没放进来）：说实话加读准人，营收大约 $5–7k；靠撒谎当天营收差不多，但一周后被拆穿加上记者头版，净营收掉到 $3.5–4k。不读底价的真人玩家，撒谎的诱惑应该更大。数值还没认真调。

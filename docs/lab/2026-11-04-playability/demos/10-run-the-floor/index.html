👆 点地方，总监就跑过去；跑到冒泡的客人身边就处理。最多能连排 3 个目标（金色数字）。

🎾🥤 要球、要水得先点球筐 / 饮料柜拿东西（一次拿 2 份）。同一种活儿连着做 = 连击，小费翻倍。

👴 点底下的 Dale 再点任务，交给他——他慢，用多了会闹脾气。

⏳ 气泡外圈是耐心，耗光了客人骂着走，掉口碑。三轮：早高峰 / 中午酷热 / 傍晚高峰。

设计说明 · Demo 10

在测什么：如果玩家直接操纵总监（Diner Dash 式点哪跑哪），每 20–40 秒的"想做的决定"会不会自然冒出来——先去哪、拿什么、要不要串连击、这个活儿自己干还是甩给 Dale。

取舍：总监一次只能在一个地方。亲自干：快、能连击，但别处在掉耐心。交给 Dale：同时处理两件事，但他慢一半、不吃连击，连着派活会闹脾气停工。VIP 小费最多但必须你亲自带看，带看的几秒里全场没人管。

队列：最多排 3 个目标，规划路线本身就是乐趣；点总监自己可以清空队列。

升级：每轮结束花小费买一样（跑鞋 / 第二个饮料柜 / 给 Dale 加薪），花掉的钱不算成绩。

会碰的准则：准则 5、6——总监从"被指派的劳动力"变成玩家直接操纵，节奏从放置变成手忙脚乱。

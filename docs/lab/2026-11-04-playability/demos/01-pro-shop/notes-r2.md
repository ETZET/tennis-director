# 01 球具店 · 第二轮

地址：`apps/sandbox/demo-shop.html`（`pnpm dev` 后打开；`?fast=N` 加速，`?seed=N` 固定天气，`?mute` 静音）。
代码：`apps/sandbox/src/demos/shop/`（`main.ts` 玩法和界面、`scene.ts` 店内画面、`art.ts` 字符画、`data.ts` 数值和布局）。
截图：`apps/sandbox/public/shots/shop-1.png`（开始）、`shop-2.png`（营业中改价）。脚本：`shot-play.mjs`（截图）、`full.mjs`（从头玩到结束）。

## 改了什么

**画面（返工：制作人说等距小岛"太糊、看不清"，改成铺满全屏的 3/4 正俯视）**
- 不再用 IsoView 画店内。`scene.ts` 自己画一张 130 逻辑像素宽的低分辨率画布（每米 16 像素），铺满顶栏和拇指区之间（390 宽手机上 130×177）；
  CSS 放大整数倍（390 宽 = 3 倍），备份缓冲 = 逻辑 × 3 × round(devicePixelRatio)，最近邻、关平滑，3× 手机上每个逻辑像素正好 9 个物理像素。
- 布局：北墙是一条墙面（柜台上方一扇看沙漠的窗、门洞和 PRO SHOP 招牌、门会开合），门两边两格★货架、东北角冰柜（玻璃门、三层）、中间中岛（绿地毯）、西南东南两个里角，前面一截矮墙。按 z 排序画，人走到货架后面会被挡住下半身。
- 商品改成 8–12 像素的字符画（水瓶、网球、能量饮料、防晒霜、遮阳帽、握把胶、球拍），1 倍画在货架层板上（3 CSS 像素一格）；托盘、拖动、改价面板用同一套。
- 客人还是 @td/iso 的 `Person`（走路、动作队列、取帧、换色、发型叠图），只是每帧取它当前的精灵帧，**2 倍**画在这张画布上（16×28 逻辑像素 ≈ 48×84 CSS），脸和表情一眼看得清。外观按类型：老人白发遮阳帽长裤、妈妈马尾粉衣拿手机、球迷帽子拿拍、游客草帽花衬衫。
- 头顶表情是 ICON_ART 1 倍（33 CSS 像素）；说的话是 DOM 气泡；价签是 DOM 小牌（照游戏 `.tg`），直接贴在货架顶面上。
- 窗外和门外用 `daylightAt` 的天色、山色、太阳；热浪抖线、大风风线和风滚草、散场人头、旅游大巴照旧；傍晚压暗、两盏灯下留亮。粒子（金光、彩纸、蒸汽、扬尘、水花）是自己的逻辑像素粒子。

**手感**
- 拖货：按下 0 延迟（卡片抬起、`pick` 音、`buzz(8)`），幽灵在手指上方 64 px（不被手指挡住），每帧直接写 transform。所有能放的格在地上画白虚框；吸附到最近的货架（70 px 内）时，格子画金色立体框、价签放大发光、幽灵变黄并写"上架 −$6 / 补货 / 捆绑 水+球"；放不了的变红并写原因（"冰柜只放饮料""钱不够""这货今天没了"）。松手：幽灵飞进货架 → 货弹跳、扬尘、`drop` 音、−$ 飘字；无效松手弹回卡片、卡片抖、错误音、状态行说原因。
- 价签（照游戏 `.tg`：海军蓝小牌、奶油边、细竖线指到货架）：点一下打开改价面板；按住拖走是挪货（空格挪过去、同货合并、不同货两格对调）。
- 改价面板在拇指区：72×64 的 −/+（按住 0.34 秒后连发，越按越快），中间大价钱 + 档位（划算/正常/偏贵/宰人，跨档时弹一下并震动），每件赚多少，0–3 倍市价的色带和指针，横向拖条（每 18 px 一档，刻度跟手滑动）。最下面一排是四类客人此刻的预测反应（表情 + "抢着买/会买/犹豫/嫌贵/骂人"）。
- 镜头固定，拖动不会误平移；所有按钮 ≥ 44 px，有按压态。

**UI**
- 顶部一条：现金（钱色、跳动、飞钱落进来）、口碑条（掉的时候闪红框）、时间 + 天气像素图 + 气温。
- 底部一块面板，托盘和改价二选一，同一屏只有它和偶尔的事件卡。状态行只写一行"为什么"：`老人嫌贵：矿泉水 $6（市价 $2）`、`妈妈：能量饮料划算！买 3 件`。
- 事件卡是底部弹出：像素半身像 + 名字 + 处境两行 + 三个选项，每个选项右边写"+ 换来 / − 付出"。

**修掉第一轮最弱的地方：平淡的晴天。** 现在每天中午都有一件事，而且先有人走进店里来找你、走到柜台前才出卡：
- 晴天：旅游大巴（窗外开进来）。导游 Marco 要回扣：$25 → 10 个游客 / 送一顶架上的帽子 → 6 个 / 不给 → 2 个，车开走。
- 热浪：Dale（第一轮的水价 ×3 / 冰水桶 / 照常）。
- 大风：校队教练订 12 罐球：八折马上成交、口碑 +4 / 原价可能只买一半 / 说"最后几罐"卖 $9 只买 4 罐、口碑 −3。
- 比赛日：Jess 报信散场：门口特价车（90 分钟全场八折、客流 ×2、价签挂 −20%）/ 全场涨三成 / 照常。

保留：限量（托盘里的「限量!」拖上货架）、捆绑（货拖到另一种货上）、13:00 下午补货车、沙漠日报（转着掉下来）、四天后的称号。

## 一局多久

4 天 × 54 秒营业（×2 快进可减半）+ 每天备货和日结，约 4–5 分钟。`full.mjs` 用 `?fast=8` 跑通过整局：照市价卖 ≈ +$1040、口碑 92（沙漠精明掌柜）；全场大涨价 ≈ 亏本、口碑 0（又黑又亏、上报纸）。

## 最满意的手感

拖货时吸附的那一下：货架亮起金框、价签放大、幽灵上写着"捆绑 水+球 −$6"，松手货飞进去在层板上弹一下——放之前就知道会发生什么、要花多少。其次是改价面板最下面那排四张脸：往上拖一格，老人那张先从"会买"变成"嫌贵"。

## 还差什么

- 3/4 视角下北墙货架会被站在前面的客人挡住一部分货（价签在上面，不影响读价）。窄货架（门口右格、角落）一层只摆得下一件大货。
- 客人之间不避让，有时几个人叠在门口的★货架前；没有排队结账。
- 气泡和价签偶尔叠在一起（门口两格太近）。
- 预测脸用的是"平均一个客人"，没有算限量 / 冰柜以外的随机（看了不买的概率）。
- 数值只跑了两种机器人打法；"挑时机宰"的区间没重跑。
- 没有真实的会所外景：门外只是一块天和沙地。

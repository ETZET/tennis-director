# 06 场地养护：扫沙、滚压、画线

**一句话**：总监亲手把 Palm Oasis 埋在沙里的球场修出来：扫沙、压裂缝、描白线、挂网，第一批客人按时到门口，什么时候开场由你定。

## 怎么玩

1. 三块场地（1号场硬地 → 2号场红土 → 中心场贵宾硬地），每块大约 60–80 秒，加上一段 7 秒左右的"第一场"演出和评分卡。整局 4–5 分钟。
2. 下方工具带点选工具，在场地上拖：
   - **扫把**：手指推沙子，像推雪一样堆在前面，推出围栏才算干净；扫过杂草几次能连根拔掉。
   - **压路机**：在裂缝、鼓包上来回压。沙没扫干净时压不实。
   - **画线车 / 贴胶带**：画点在手指上方（有准星）；沿旧线残影描，离线 2–3 像素以内会吸到线上，再远就是歪线，**擦不掉**，扣线条分。沙上画的线是脏的，扫沙会把它一起扫掉。
   - **洒水**（只有红土）：太干压不动，积水再压会压出泥坑；沙漠里水几秒就干。
   - **挂网**：按住往上拉，侧视图里网绳收紧，在张力计绿区松手；拉过头绳会断。
3. 开场按钮上一直显示"现在开 = 几档 · 每小时多少钱 · 评分"。
4. 客人到了以后在门口等，耐心条从绿变红，头上的表情一路变到 💢。耐心耗尽时弹一张卡：现在开 / 免单再等 15 秒 / 让他们走。
5. 开场后客人上场打几个回合：没压平的地方坏弹跳，沙子多的地方打滑，线歪了吵"出界/压线"，网松了球挂网。然后出评分卡：平整/线条/干净/球网 → 档位 → 订金 → 星级和一句评价。
6. 结束画面：首日订金、口碑、本周预计场租、总计，一个总监称号。

## 在测的假设

- **20–40 秒**：一个工具一段 10–20 秒的手上活，每段都有"还要不要再磨一下"的犹豫，因为开场按钮的档位就在眼前跳。
- **3–5 分钟**：一局里至少一次"赚到了"（升到 S/A 档的号角、完美张力、准点 S 档拿满订金）和一次"搞砸了"（阵风把沙吹回来盖住刚画的线、绳子拉断、客人走掉、比赛里压线吵架）。
- **一局**：赶工型和精修型总监的成绩单完全不一样，称号直接点出来（快手 / 强迫症 / 神仙 / 放鸽子 / 务实 / 糊弄）。

## 取舍表

| 决定 | 换来 | 付出 |
| --- | --- | --- |
| 早开场（赶工） | 订金全拿，准点 +0.5★ | 档位低：D 档 $10/h，以后每小时都卖得便宜；比赛里当场出丑 |
| 晚开场（精修） | S/A 档 $45–60/h，长期场租高 | 订金按等待时间打折，星级掉，最坏客人走掉 |
| 耐心耗尽：现在就开场 | 拿一半订金，不再耗时间 | 口碑 −1★ 左右，场地按现状评分 |
| 耐心耗尽：免单再等 15 秒 | 多 15 秒干活，口碑只掉一点 | 订金 $0；15 秒后还不开，他们照样走 |
| 耐心耗尽：让他们走 | 再给你 15 秒，没人催 | 订金 $0，口碑 −1.5★，最后只有路人按 1 小时付钱 |
| 先扫后压 vs 先压后扫 | 先压能马上看到裂缝消失 | 沙上压，效率只有四分之一 |
| 先画线 vs 先扫干净 | 画线分涨得快 | 沙上的线是脏的不算分；阵风会盖住线 |
| 红土多洒水 | 压得快 | 积水再压会变成泥坑，平整反而下降 |
| 网拉紧一点 | 张力分高 | 拉过 100% 绳子断，重来 |

长期账：口碑（平均星级）决定每块场每周有多少小时被订（6 + 4×星级），乘以各场的档位价。所以"一块场 S 档但口碑崩"和"三块场 B 档但都准点"是两种都说得通的打法。

## 如果选中，怎么接进现在的游戏

- **接在修复工单上**：现在的场地修复工单（`data/orders/` 里修 court 的那几张）完成后，如果总监本人在场，可以"亲手收尾"：进这个小游戏，评分决定这块场的档位（场地状态之外再加一个"品相"值），而不是工单完成就满档。员工做同一张工单只会拿到中档（Rosa 扫沙快、Gus 画线直但慢，各有偏向）。
- **总监是劳动力**：小游戏期间总监就在这块场上，别处的岗位缺一个人——和现在"把总监拖到工单上"是同一件事，只是这次玩家亲手干。时间按小游戏实际用时折算成游戏分钟。
- **第一单客人**：改成一张事件卡的后续（"第一批订场的人周六上午到"），客人等待和走掉走现有的因果日志。
- **周日结算**：档位进场租价，评价星级作为这一周的服务率加成；不实时漂移会员，符合准则 6。
- **复用**：阵风接沙尘天气；状况下降（`wear.ts` 的画面信号）以后可以再进一次小游戏"重新画线"，不必每次都做。

## 已知不足 / 第二轮可以加什么

- 描线的吸附宽度（2–3 像素）是拍脑袋定的，手机上可能偏难，需要真机手感测试；可能要加"按住起点，沿线一拉就是直线，手抖才歪"的模式。
- 扫沙很爽，但沙子总量大时最后的边角收尾有点磨；可以加"吹风机"一类的高级工具（花钱买时间）。
- 没有员工帮手：第二轮可以让 Rosa 跟着扫（拖她进来，她自己扫一片，但扫得不干净）。
- 红土的"刷土"只做成了洒水 + 压实，没有拖网刷平的手感。
- 比赛演出很短，只是演缺陷；可以把评价写进因果日志、出现在之后的卡里。
- 数值随手定：长期场租权重比订金高，熟练玩家会偏向精修。
- `?fast=1` 把倒计时和耐心加速 4 倍（测试用），`?seed=N` 固定随机。`run.mjs` 用测试钩子一口气跑完三块场（精修准点 / 放走客人 / 赶工），停在结束画面（`shot-end.png`）。

## 第二轮二改（制作人："太糊了 根本看不清"）

- **镜头框紧：** 六个岗位挪到俱乐部西半边挨在一起（前台在会所门口草坪、穿线在会所门口、泳池、会员场 outer_1、青训 P1、红土 outer_23 西头、休息在中心球场西头的阴凉），镜头只框这一片，铺满急事条和拇指面板之间。
- **人放大一倍：** `pixelSize: 2`（1 个缓冲像素 = 2 CSS 像素）+ k=4：人约 28 CSS 像素高（原来 14），拎在手上的替身约 56。画布宽高取偶数 CSS 像素，整数放大，3× 手机上每个像素正好 6 个物理像素，不糊。
- **可以平移：** 按在空地上单指平移（范围只比这一片大一点，不缩放）；按到人、从员工条拿人、拿着人的时候镜头锁死，拖人绝不平移。
- **牌子不叠：** 每帧从屏幕靠下的牌子开始摆，撞上已经摆好的就往上挪，竖线拉长并斜着指回地面；"走 N 分"挂在起点脚下。
- 大门在画面外了：大巴不演车，只演一队游客从长廊东头走到会所门口排队。

## 和第一轮比

**画面：真游戏。** 不再手画俯视小图：用 `@td/iso` 建真的 Palm Oasis（二改后只框西半边，见上）（`INDIAN_WELLS`，设施是中期：中心球场在搭脚手架、匹克球场刚挖开，其余修好）。五个人是 `Person` 精灵，长相照游戏 `scene.ts` 的 LOOKS（Dale 帽子胡子、Rosa 马尾、Ben 黄衫、Jess 青衫、Gus 红帽）。人沿真实步道走（路网照 `layout.ts` 的节点和边，加了到每个岗位的支路），位置由模型按分钟算，画面只跟着。天色随一天从早到傍晚变。

**岗位：每个岗位演不一样的活（第一轮最弱的地方）。**

| 岗位（地点） | 干活的样子 |
| --- | --- |
| 前台（会所门口） | 拿写字板，对排队的客人挥手、说话 |
| 会员场（outer_1） | 拿耙子沿底线来回耙；积沙时扬沙 |
| 穿线（会所门口） | 拿拍子比划、闪光 |
| 青训（练习场 P1） | 活动库的 `feed`：有课时孩子从场外走进来，他在网前喂球；教学越好演得越好（Gus 去会打瞌睡） |
| 红土（outer_23） | 拖着耙沿场地绕圈拉线，扬红土 |
| 泳池 | 吹哨、指点，池里水花多少跟需求走；没人游就扇风 |
| 导游（大巴时才有） | 举旗挥手 |
| 休息（看台阴凉） | 看手机、喝水；罢工的人垂头冒火 |

每个岗位门口站着等的客人（需求越高人越多），没人管时头上冒 `!`，有人管时偶尔冒心。

**手感：**

- 按下 0 延迟：头像卡抬起、上扬音、`buzz(8)`，场景里马上出现**放大一倍的替身**挂在手指上方 60 px，按手指横向速度摆、双手举着；原地留一个半透明的影子（还在干活）；地上有替身的影子。
- 拖着：所有岗位牌换成 `★ / $/h / 表情`，按星级描边（绿 / 金 / 珊瑚）。手指靠近一块（58 px 内）就**吸附**：替身跳到岗位上方，地上一圈金色菱形一呼一吸，金色虚线画出真实步道路线，起点挂"走 N 分"；"嗒"一声 + `buzz(4)`；讨厌的岗位替身当场冒一句台词。
- **不再挡牌子**：替身在手指上方，被吸附的那块牌子挂到替身头顶；原因、白干、换下谁都在拇指区的固定面板里（面板一直在，不跟手）。
- 松手：替身从空中掉到岗位上缩回原大小，"咚" + 扬尘 + 轻震屏 + 牌子闪一下，留一个淡影子；真人沿路走过去，路上一直画着剩下的路线。拖到空地 / 拖回员工条：替身弹一下化成烟，人不动。
- 拖人永远不会平移画面（空地上可以单指平移）。

**UI：** 和游戏 HUD 一套：顶上一条（天 / 时钟进度、钱、声望、A/B、静音、?），急事在顶栏下一条（珊瑚左边 + 倒计时条），岗位牌照游戏 `.tg/.hub`（海军蓝方角、头像环形进度、需求格、细竖线指到地面、缺人时珊瑚描边脉冲），底部是拇指区面板 + 员工条（照游戏员工条：方块头像缩写、在干什么、心情条、角上的像素表情）。字都是一行短句，规则在"?"里。

## 第一轮弱点的修法

- **搭档太好凑**：搭档只在头 4 圈 ×1.25，之后两人"聊上了"×0.9（头上冒音符、连线变蓝），要拆开重排才会重新算；搭档只认真实地图上相邻的岗位（泳池—穿线、泳池—会员场、前台—穿线、会员场—青训、青训—红土）。机器人一局搭档加成 4–16 次（第一轮 50+）。
- **大巴只是偶尔紧张**：现在大巴要两个人——前台 + 临时冒出来的"导游"岗位（虚线牌），覆盖率按两人平均算；游客从长廊排队走到会所门口。服务好的只有 Ben（85）和 Jess（60），一定要从别处拉人，常常拆掉泳池或青训。
- **拿着的人挡住牌子**：见上面手感。
- **声望涨太快**：红土养护只有 ★★ 以上的人才涨声望。

## 一局

三天，每天约 72 秒（真实），一局 4 分钟左右。用 `fullrun.mjs` 在 `?fast=8` 下从头玩到结束画面，不卡、不报错。

## 最满意的手感细节

拎起正在泳池干活的 Jess 往红土上一靠：替身"吸"过去、地上金线从泳池绕过两排球场、头顶的牌子写着 ★☆☆ $1，面板里同时出现"搭档 Dale ×1.25 · 4 圈"和"泳池救生白干 78%（−$11）"——一眼看到这一下换来什么、付出什么。

## 还差什么

- 画面只是俱乐部西半边；大巴车本身看不到，只看到游客。
- 拿着人时牌子变宽，避让会把上面几块推高，竖线变长、斜着指。
- 场景里的对话气泡在新的像素尺寸下偏大，偶尔压到牌子。
- 旧手感 = 游戏现在的方块头像 + 环形进度；数值和新手感完全一样，结束画面写两种手感各用了多久。
- 心情、罢工、白干、急事的数值照第一轮，没有重新平衡；机器人局收入 $1800–2300，没跑大样本。

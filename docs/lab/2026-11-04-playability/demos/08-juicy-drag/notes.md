# 08 · 拖人 2.0：匹配度和反馈

**一句话：** 动词还是"把人拖到岗位上"，但拿起来有手感，松手前每个岗位都亮出 ★匹配度和预计 $/小时；放对了有搭档连击，放错了人当场抱怨，心情掉光就甩手罢工。顶栏能一键切成"旧手感"对比。

## 怎么玩

1. 按住底下的头像（或场上的人）往上拖：人被拎起来晃，头上冒出他对这个岗位的看法；6 个岗位全部亮色（绿 ★★★ / 黄 ★★ / 红 ★），每个上面写着 `+$X/h` 和表情。
2. 手指停在某个岗位上，信息栏写清楚为什么：能力、喜不喜欢、和谁搭档或犯冲、走过去几分钟，以及**把他从现在的岗位拉走会白干多少**、谁会被换下来。
3. 松手：咚一声，扬起尘土，他沿虚线走过去；到了冒星级和一句台词，开始转圈，每干完一圈飘一次钱和声望。
4. 需求按时段变（前台、会员场早晚忙，泳池中午忙，青训下午才有课），人比岗位少，一天要重排两三次。拖回休息区可以回心情，那段时间不出钱。
5. 每天一件急事（顺序随机）：🚌 旅游大巴（前台需求 ×5，3 小时）、🌪 场地积沙（会员场停摆直到扫干净）、🎾 冠军会员急要拍线（90 分钟内）。
6. 三天（每天约 72 秒，`?fast=3` 加速），结束给出收入、覆盖率、团队心情、搭档次数、白干的圈、罢工次数和一个称号。

## 在测的假设

北极星第 1 条（每 20–40 秒有一个**想做、会犹豫**的决定）：现在的拖人之所以无聊，不是因为它是拖动，而是因为拖之前不用想、拖之后没感觉。加上"匹配度 × 喜好 × 搭档 × 心情"和松手前预览，同一个动作就变成一次小计算；加上白干、抱怨、罢工，就有了第 2 条的"搞砸了"。A/B 开关用来验证：**反馈本身**能不能让同一套数值更好玩。

## 反馈清单

| 操作 | 新手感 | 旧手感 |
| --- | --- | --- |
| 拿起 | 上扬音；人被拎起，按手指速度做钟摆晃动、蹬腿；头上冒 ?；场上原位变成半透明虚影；地面投影；头像卡抬起 | 手指下一个灰色字母圆片 |
| 拖着移动 | 6 个岗位全部按星级上色、闪烁；每个岗位上有 ★ + `$X/h` + 表情 + "讨厌这活 / 没需求 / 换下某某"；停住的岗位放大；经过时"嗒"一声；人头上的表情跟着换（♥ / 😠 / 汗）；讨厌的岗位当场冒一句台词；虚线路径加"🚶 42 分钟"；信息栏写原因和"白干 63%（−$9）" | 信息栏只写"松手：把 X 派到 Y" |
| 松手 | 咚 + 噪声、尘土、轻微震屏、目标岗位闪一下；走路时虚线一直显示 | 无 |
| 打断别人 | 环形进度变红碎裂、红色火花、"白干 57% −$11"、下降音、台词"干一半了…" | 环形进度归零 |
| 到岗 | 弹出 ★★★/★☆☆、台词、表情；和搭档之间金色火花 + "搭档！"，和冤家之间"怎么又是你" | 无 |
| 每一圈 | 绿色 +$（大单金色加大）、+⭐、钱和声望数字弹跳、金币音；搭档的金色虚线和 ♥ 一直挂着，每圈飘"搭档 ×1.25"；冤家之间红色锯齿和 💢 | 环形进度转完一圈 |
| 放错 / 心情低 | 生气表情、抱怨台词、汗滴、心情条变红；罢工时大字"💢 甩手不干了"、震屏、卡片抖动，再拖他会被拒 | 人自己走回休息区，卡片写"罢工" |
| 没人管 | 客人头上闪"!"，每小时"没人管 −2⭐" | 只有声望数字掉 |
| 急事 | 警报音、闪白、震屏、顶部红条闪烁倒计时、岗位牌闪红；搞定时变绿 + 胜利音 + 大字 | 顶部红条和信息栏文字（不然没法玩） |

两种手感的数值和规则完全一样（同一个 `payRate`），切换只改看得见的东西。结束画面写出这一局两种手感各用了多少时间，并给两个"再来一局"按钮。

## 如果选中，怎么接进游戏

- **预览接在 `project.ts`：** 手上拿着人时，对每个可见岗位算 `stars + $/h + 理由`，地点牌显示星级和数字。模拟里已经有能力、特质和收入公式，缺的是"喜欢/讨厌的岗位"和"人际关系"两张表，放进 `content/data/staff` 的 YAML（`likes_posts`、`dislikes_posts`、`friends`、`foes`）。
- **搭档：** Palm Oasis 的锚点按步道邻接定义（`deck` 和 `court_1` 相邻等），sim 在每圈结算时看邻接锚点上的人，效果白名单加一个 `pair_bonus`。
- **心情真正影响干活：** people.md 写的"士气暂时还不影响干活"在这里打开：士气进收入倍数，低于阈值触发"罢工"领域事件，演出层用 `perform.ts` 配甩手走人的动画。
- **总监：** 总监没有情绪，在这套系统里是"万能但平庸、不会罢工"的填空人，预览照样显示他的 ★。
- **周日结算：** 搭档次数、罢工次数、白干的圈进周报；会员和声望可以照旧按周平均服务率，也可以像 demo 一样即时掉（见下面的冲突）。
- **急事：** 就是现有事件卡的"突发需求"版本，旅游大巴、积沙、急单拍线可以直接写成卡，效果是给某个岗位加一段临时需求。
- **旧手感开关：** 只在原型里用来对比，不进游戏。

## 和玩法准则的冲突

（制作人说这个 demo 不用管准则，只简单记一下。）

- **准则 6：** demo 里没人管的岗位每小时直接扣声望，不是按周平均服务率结算；罢工让局面主动变坏，而不是"慢慢回到你布置的样子"。
- **准则 5：** 拖人仍然是核心动作，不冲突；但心情和罢工让玩家必须隔一阵就回来处理，比"放置"更忙。
- **准则 4：** 一天一件急事，按 72 秒一天算，比"隔一阵才来一张卡"密很多。
- **准则 1：** 点头像、点岗位会在信息栏显示说明，不算菜单。

## 已知不足 / 第二轮

- 数值随手定的：搭档太好凑（两对朋友正好能摆成相邻），一局下来搭档常常 50 次以上；声望涨得太容易。可以让关系随事件变化（一起扛过大巴就成了朋友，被换下的人记仇）。
- 预览信息很多，手机上手指和拎起的人会挡住被选中的那块牌子（那块牌子已经往下挪了，详情在信息栏）。可以考虑只显示前三名。
- 人物只有站、走、干活、被拎四种姿势，干活动画对所有岗位都差不多，只换了小工具。
- 没有"习惯"（ADR 0014）：每天开始人留在原位，不会自己去下一个班。
- 第二轮可以加：拖着一个人碰另一个人就交换；双击岗位叫"最合适的人"（会不会太省事？）；特质随干的活成长（Jess 带了 10 圈青训就"上瘾"）。
- 音效默认开，切到旧手感时全部静音（旧手感 = 现在游戏的手感）。

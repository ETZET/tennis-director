# 02 会籍设计：超卖的艺术

**一句话**：自己设计最多 3 张会员卡，钉在门口公告板上，看四种客人挑卡或走人；再快进 6 周，看卖出去的卡怎么把晚上 17–20 点的 3 片场挤爆。

## 怎么玩

1. 开局一张金卡。月费、场时：在数字上左右拖动，或者点左半边/右半边加减；点印章切换"含/不含晚高峰"；点最下面那行小字切换条款（无 / 自动续费 / 退会需提前 3 个月 / 雨天不退款 / 赠送毛巾）。点"空白卡"再加一张（最多 3 张）。
2. 卡片上方四个头像实时显示每类客人会买哪张、或者为什么走（"⚠看小字会走"＝爱读条款的人会被吓跑）；下面的黑条预估开业人数、周收入和晚高峰拥挤度（开业 → 第 6 周）。
3. 开门迎客：22 位客人头顶带着需求图标（☀️白天怕贵、🌙只要晚上、👶周末带娃、🔥多打肯花钱）走到公告板前，买卡（+$/月 飞字、爱心）或者走人（理由气泡）。
4. 每周约 25 秒（可 2×/4×）：白天、晚高峰的人走上场，订不到的人去候场区排队冒 💢；下面的柱状图按天画出白天/晚高峰负载和"场满"线。不满意的人举着"退会"牌走出大门；被"提前 3 个月"条款留住的人走到门口被合同拦回去。
5. 每周日一个决定：处理一件事（上班族联名投诉、记者来电、发烧友包场、老人团购、对街开健身房），**或者**改一张卡（这时事件按"不理"结算）。
6. 6 周后结算：总收入、付费会员、口碑、晚高峰平均拥挤度和一个称号（超卖之王 / 霸王条款总监 / 金牌总监 / 良心总监 / 薄利多销 / 发烧友教父 / 佛系 / 精打细算）。

测试参数：`?fast=1` 时间 ×8；`?auto=1` 自动跑一局（好人策略），`?auto=greedy` 自动跑贪心策略；`?seed=N` 固定种子。

## 在测的假设

- **20–40 秒**：每周日的"改一张卡还是处理事件"是二选一，改卡本身也有犹豫（涨价会赶走一部分老会员，去掉晚高峰会让上班族当场退会）。设计阶段的每次拖动都立刻改变四个头像的选择和晚高峰预估——"再涨 $10 会不会把上班族赶走"这种手感。
- **3–5 分钟**：开业的入会潮（金色闪光、周收入大字）是"赚到了"；第 3–4 周晚高峰超过 130%、一天好几个人举牌退会、记者来电后上《沙漠日报》（屏幕抖、红闪、口碑 −18）是"搞砸了"。
- **一局**：称号来自你怎么卖卡。贪心策略（便宜的含晚高峰大卡 + 提前 3 个月退会）在自动测试里稳定得到"霸王条款总监"，口碑掉到 0；细分策略（贵的晚高峰卡 + 便宜白天卡）得到"良心/金牌/薄利多销"。

## 取舍表

| 决定 | 换来 | 付出 |
| --- | --- | --- |
| 月费高 | 每个会员多赚 | 怕贵的老人、一部分上班族直接走；涨价时现有会员可能当场退会 |
| 月费低 | 入会多、满意度高 | 每人赚得少；人多了晚上更挤 |
| 场时多 | 发烧友肯付高价，家长和上班族也满意 | 发烧友真的会把场时用完，挤占晚高峰 |
| 场时少 | 场子不挤 | 客人嫌"场时太少"不买，或者每周掉满意度 |
| 盖"含晚高峰" | 上班族（人数最多、愿意付钱）才会买 | 晚上只有 6 个位子；卖多了就有人白跑、退会、联名投诉 |
| 不含晚高峰 | 晚上留给付高价的那张卡 | 上班族一个都不买；发烧友打折 |
| 自动续费 | 想退的人有 65% "忘了退"，继续付几天钱 | 他们发现后口碑 −2.5；可能招来记者 |
| 退会需提前 3 个月 | 想走的人走不了，一直付钱（会员数虚高） | 爱读条款的老人/家长直接不买；被困的人每周拖口碑；记者 → 上报纸 |
| 雨天不退款 | 雷雨天不用退款 | 这些会员雷雨天满意度 −5 |
| 赠送毛巾 | 满意度 +3/周、口碑 +1.5/周、家长更爱买 | 每人 $3/周 |
| 加装夜灯（事件） | 晚高峰容量 6 → 9，永久 | 一次 $600 |
| 免一周会费（事件） | 上班族满意 +25 | 少收一周钱，场子照样挤 |
| 发烧友包场 | +$400 | 下周六晚上所有会员没场，大批人白跑 |
| 老人团购 | +8 个会员，填满白天空场 | 六折拉低价格，其他会员满意 −5 |
| 删条款放人 / 塞公关费 / 无可奉告 | 口碑 +5 / 压下去 / 免费 | 被困的人马上退会 / −$300 / 65% 上报纸 |
| 改卡 vs 处理事件 | 改卡能修根本问题 | 这周的事件按"不理"结算（通常最差） |

## 反馈清单

- 拖价钱/场时：每格一声"嘀"（音高随数值变），数字弹跳；四个头像的选择变化时头像弹一下；黑条预估实时更新，红/黄/绿变色。
- 点印章：盖章动画（放大砸下）+ 闷响。点小字：条款颜色（坑＝红、礼物＝绿）+ 飞字说明后果。
- 锁卡：改卡阶段碰第二张卡会左右抖 + 提示"这周只能改一张卡"。
- 客人买卡：爱心、绿色气泡（"晚上见！"）、+$/月 飞字、金币声；走人：💢/😐、红色气泡说理由、低音。
- 开业结束：金色闪光、"N 人入会 / 周收入"横幅、胜利和弦。
- 晚高峰：天色变暗、球场灯亮；订不到的人排进候场区头顶 💢，冒"又没场！""我交了钱的！"气泡，"N 人没订到"红字；≥3 人时屏幕抖。
- 每天结束：会所上方 +$ 飞字；雷雨天下雨、"⛈ 雷雨停场"、红字"雨天退款"或"雨天也不退钱？"气泡。
- 退会：举"退会"牌走出大门，−$/月 红字；被合同困住：走到门口牌子变成"合同：提前3个月"、"还要再交3个月？！"、盖章声，再垂头（💤）走回去；自动续费的人几天后回来骂"怎么又扣我钱？！"。
- 周结算：口碑 ± 飞字；记者事件上报纸：报纸旋转飞入、红闪、抖屏。
- HUD 四个数（会员数、周收入、晚高峰、口碑）每次变化都弹跳，晚高峰和口碑带红黄绿条。

## 如果选中，怎么接进游戏

- 公告板放在 Indian Wells 地图的大门/前台旁边，是一个场景物件；点它打开卡片特写（不是菜单，是"走过去改公告"）。前台岗位有人时才卖卡（总监站前台也行），没人在岗就没有新会员——和"收入只在有人在岗时产生"能拼。
- 现有"会员数"拆成按卡、按人群的会员；周日结算改成按卡算月费 / 4、按晚高峰服务率算满意和退会（现在本来就是"按一周的平均服务率结算"，只是多了一个由玩家定的需求端）。
- 晚高峰容量 = 开放的球场数 × 在岗的场地维护/前台；修好一片场、装夜灯是现有设施修复的直接收益，"超卖"把修设施和卖卡连起来。
- 事件卡（投诉、记者、包场、团购）直接写成 `events/` 里的 YAML，条件读"晚高峰负载""被困会员数"等新的计算变量；小字条款的后果进因果日志。
- 人群可以和现有人物（Dale 认识的老人团、Jess 带来的发烧友）挂钩。

## 和玩法准则的冲突（按制作人要求不为准则削弱玩法，只记录）

- 准则 1：卡片编辑是一个专门的编辑界面，虽然是"点公告板 → 直接拖卡上的数字"，但仍是一个管理面板。
- 准则 6：月费/条款一改，会员当场退会；收入取决于定价而不只是"有人在岗"；会员在一周内实时退会，不只在周日结算。
- 准则 5：这个 demo 里没有拖人；容量是固定的 3 片场。

## 已知不足 / 第二轮可以加

- 一周里玩家没事可做（25 秒纯观看，可加速）。第二轮可以加周中的小动作：点候场区排队的人送饮料安抚、临时把一片场改成只给某张卡、总监亲自去前台推销（接 04）。
- 周末白天和家长的拥挤画得不如晚高峰清楚；没有"周末"开关，家长的需求只体现在场时上。
- 数值随手定：好人策略收入约 $3,000–3,500，贪心策略约 $2,000–2,700 且口碑归零——"坑人赚快钱"在 6 周里不够诱人，长局里才会显出来；可以让被困会员的钱更多、或让记者来得更晚。
- 每张卡没有"名额上限"（限量 20 张）这种直接控超卖的手段，第二轮可以加一个"限量"印章。
- 客人的个体差异只有支付意愿和读不读小字；可以加口碑传播（朋友跟着来）。

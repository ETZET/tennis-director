# 03 订场板：动态定价和超售

**一句话：** 当三天前台。电话一个个打进来，你决定接不接、放哪片场、要不要超订到一个爱爽约的客人头上；赌局在那个钟点开奖，场上当场演出来：双倍收钱，或者两拨人吵起来。

## 怎么玩

- 上半屏是 4 片场（1 硬地、2 硬地带灯、3 红土、4 红土带灯），订了的钟点一到，人从门口走进来打球。
- 下半屏是订场板：行是场地，列是钟点（7–21 点），整块板随时间往左走。每列顶上一个**价格牌**：点一下按 低 $15 → 中 $25 → 高 $40 → 抢 $60 轮换，上下拖也能改。列头的 ▮ 表示这个价格下大概有多少人想来。
- 来电卡在最下面：**右滑接**（自动放进第一片空场）、**左滑拒**，或者**把卡往上拖到格子上**选场地。拖到已经订出去的格子就是**超订**。
- 卡上有客人类型和"爽约史 ⭐"，格子里的订单也显示爽约史的小方块，方便挑一个最可能放鸽子的人来超订。
- 夜场（19 点以后）只有带灯的两片场能订，每片每小时 $8 灯费。
- 一天约 64 秒，3 天（周四、周五、周六，天气每局随机：晴、热浪、大风各一天；周六晚上人特别多）。`?fast=4` 加速，`?auto=1` 机器人自己玩，`?seed=123` 固定种子。

## 在测的假设

"奸商"的乐趣（支柱 A）可以来自**时段**这件东西：价格牌是慢决定（一天调几次），来电是快决定（每 2–4 秒一张），超订是一张押在未来的赌注，几十秒后在场上开奖。

- 20–40 秒：每张来电都要想一下"接 / 拒 / 放哪 / 超不超"，傍晚高峰前还要决定涨不涨价。
- 3–5 分钟：开奖时刻。一拨人爽约 → 金色"双倍收钱！"、闪屏、和弦音；两拨人都来 → 灰尘云、💢、震屏、"吵起来了！"、一拨人"退钱！"走掉、赔 $15、差评。
- 一局：结束按超订次数、赌赢/吵架比例、会员满意、差评、净赚给称号（航空公司式总监、吵架制造机总监、黄牛总监、差评收割机总监、老好人总监、精算师总监、躺平总监、稳当总监）。

## 取舍表

| 决定 | 换来 | 付出 |
| --- | --- | --- |
| 价格牌定高 / 抢 | 每单多赚（$40 / $60） | 来电少（高峰少得少，平时几乎没人来）；高峰全卖高价给散客 → 会员满意 −6 |
| 价格牌定低 | 来电多；热浪的中午只有低价才有人来 | 每单只有 $15；电话太多会占线、挂断 |
| 接会员 | 会员满意 +2（高峰），几乎不爽约 | 只付会员价 $20，占掉一片本可以卖 $40–60 的高峰场 |
| 拒会员 / 让会员等到挂 | 把场留给出价高的人 | 会员满意 −6 / −4 |
| 接大学生 | 白天冷场时有人来 | 只肯付 $10–15；夜场还要贴 $8 灯费，可能倒贴 |
| 超订 | 有人爽约就双倍（另一份照收订金） | 两拨都来：赔 $15、差评 +1（网红在场 +3）、会员被挤走 −10；差评让以后的来电变少 |
| 网红 | 来了打完球发好帖，差评 −1 | 爽约多；被超订挤走就发帖骂你（差评 +3） |
| 夜场 | 高峰延续到 19–20 点，需求最大 | 只有两片场能打，每片每小时 $8 灯费 |

没有"永远对"的选项：超订到会员头上最稳但赢面小，超订到大学生头上赢面大但他们付得少；高价减少来电、也减少能拿来超订的订单。

## 如果选中，怎么接进现在的游戏

- **设施和岗位：** 订场板就是前台（Ben、Lily 的岗位）的"手感版"。前台有人在岗时电话才接得进来；没人在岗时电话自动按默认规则处理（只接空场、不超订），保住准则 6 的"不操作时世界照样运转"。总监站前台时才能超订和改价（总监是劳动力：站前台就不在别处）。
- **场地：** 订场板的行就是已修好的场地；场地状况档位影响需求（旧场只有低价才有人订）。灯是一项设施：修好灯塔才开放夜场行，灯费进经营账。
- **会员和结算：** 卡里的会员满意在周日结算时进"一周平均服务率"；差评作为声望的负项。超订吵架、网红发帖可以挂成后续事件卡（"本地点评网站找上门""会员联名信"），进因果日志。
- **事件卡：** 天气（热浪、大风）和"周六晚高峰"本身就是现有的天气 / 周期系统；可以出一张"航空公司的朋友教你超订"的卡来解锁超订（选择留下痕迹）。
- **数值：** 价格档、爽约率、客人类型放进 content YAML（`data/customers/`），sim 里用种子随机决定谁爽约；画面只演。

## 和玩法准则的冲突

- **准则 6（收入只在有人在岗时产生、会员不实时漂移）：** 这里收入取决于价格和订单，会员满意当场跳动。接进游戏时要改成"满意度的变化先记账，周日结算时生效"，或者写 ADR 放宽。
- **准则 1（不做菜单式操作）：** 订场板是一个常驻的格子界面，接近"日程表画面"。它是对事件（来电）的回应和直接拖放，不是"面板 → 子菜单"，但仍然很像 ADR 0012 想避免的排班表。最好做成点前台时才拉起的半屏，平时让前台员工自动处理。
- **准则 4（事件偶发、有分量）：** 来电是流水线式的高频小决定，和"偶发、有分量"相反。接进游戏时应该只在高峰（或者总监站前台时）出现，平时自动。

## 已知不足 / 第二轮可以加什么

- 节奏偏忙：傍晚每 2 秒一张卡，第一天可能手忙脚乱；可以让第一天只开 2 片场，或者加一个"让前台按规则自动接"的开关作为取舍（省事但不超订）。
- 价格牌是一个钟点一个价，没有按场地（红土 / 夜场）分开定价；红土和硬地只是画面区别。第二轮可以让红土在大风天没人要、硬地在热浪天烫脚。
- 爽约只看客人类型 + 天气；可以加"电话确认"动作（花前台时间降低爽约率）、订金比例（订金高 → 来电少但爽约照收更多）。
- 吵架只是一段固定演出，可以加分支："送一张免费券"（多花钱少差评）或者"让他们一起打双打"（会员好感）。
- 没有回头客：今天被你宰过的散客明天不会更少来。第二轮可以加"熟客记得你"的长期后果。
- 机器人（`?auto=1`）的打法很保守，三天净赚约 $1100–1300；真人敢超订能到 $1500+。

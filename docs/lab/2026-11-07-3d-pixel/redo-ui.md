## 界面规则（第 6 轮结束时的样子）

1. **只占三个角，画面中间不放字和框。** 左上日钟 + 日期，右上钱，右下（拇指区）图标按钮。场景里只允许：人头上的心情泡（小图标，同一时间一个）、
   互动点头上的小箭头（总监已经能干活时不画）。量：画面中间 60% 区域里的"字和框"像素 = 0（静止帧和真玩帧都要量）。**这一条六轮里一直稳定达标。**
2. **字分两种，不要中间态。** 固定的数字（钱、DAY 1）用 5×7 点阵字，和图标同一个纹素网格；浮动的话（上方一行、点日钟冒的一行、按钮名、地点名、开局提示）
   用平滑的系统字 + 1 px 墨色细描边（同参考的浮动中文）。不要把系统字按阈值切成"伪像素"（第 2、3 轮试过，汉字发碎、和图标不在一个网格）。
   第 6 轮评判仍然说"三套字"，要的是 12 px 点阵中文位图字体 —— 仓库里没有，要另外引一个字体（见"还差什么"）。
3. **图标画法。** 像素格子画形状，自动加 1 纹素墨色描边、可选 1 纹素奶油贴纸边、往下 1 纹素深影（`sprite.ts`）。名册、地图带贴纸边；
   动作键 = 墨 55% 实心小盘 + 1 纹素奶油细环 + 只带墨描边的图标 + 计数小键帽。全界面的奶油底板只剩按钮名小牌子（长按 / 第一次出现）。
4. **颜色和场景一家，不抢焦点。** 全部取 `clubsite/render/palette.ts` 的 PAL（`colors.ts`），描边是铁艺暗档靛黑。画面的焦点色是总监的草帽（≈ #ffcd81），
   界面里没有比它艳的暖色：日钟进度淡奶油、太阳干草亮档、金币干草地亮 / 中档（`PALE_SUN`、`COIN_KEYS`）。图标点缀用低饱和的中档。
5. **手机优先。** 界面纹素 2 CSS 像素（`hudScale()`；第 4 轮评判嫌横屏 3 倍太重，第 6 轮又嫌横屏太小 —— 留成函数）。所有按钮 ≥ 48 px（图标 + 透明外框），
   心情泡点击区 ≥ 44 px。只用 Pointer Events（点、按住、长按），桌面键盘照旧（clubsite/play 的）。
6. **不做菜单。** 按钮直接是动作；点日钟只在"DAY 1"下浮一行"[太阳] 周一"，1.8 秒消失。调时刻、调天气的面板是调试工具，只在调试里（`?debug=1`，或 3 秒内连点日钟 5 下）。
7. **字只在需要时出现。** 动作键、名册、地图没有字；活第一次出现、或长按按钮时，按钮正上方的奶油小牌子亮 1.5 秒。开局的操作提示 5 秒或第一次碰画面就淡掉。
8. **说话的人要连得上。** 点心情泡 / 点人：上方一行 = 小人头（这个人的发色、肤色、衣服色）+ 名字 + 他自己的一句话，2.4 秒；点过的泡收起（已读）。
   再点他一次（或点那行字）= 开人物卡片。
9. **换场景用圆形转场。** 收拢到总监身上 → 全黑（右下三个点一个个亮）→ 展开；进出会所剖面、坐电梯换层都走它。

## 组件和接法（`apps/sandbox/src/clubsite/hud/`）

| 文件 | 做什么 |
| --- | --- |
| `index.ts` | `mountPixelHud({ play, canvas, day, money, buttons, who, params })` → `{ frame(), iris, peek(p), pop(text, icon, sec, who), place(name), setDebug(on) }`；`actionIcon(label)` / `pickIcon(label)`：活的中文名 → 图标；`hudScale()` |
| `clock.ts` | `drawClock({ hour, look, weather })` → 38×39 纹素 RGBA：四条色带的天、太阳沿弧走、月亮 + 三颗星、按天气的云 / 雨 / 风沙、外环 = 营业时段 6–22 点（`OPEN` / `CLOSE`） |
| `iris.ts` | `createIris({ center, cell, ms }).run(async () => { 换场景 })` → Promise；`busy()`、`pose(phase, k)`（截图定格）。只依赖 DOM，可以单独用（地图代理的 clubvista 在用） |
| `icons.ts` | 按钮图标（≤ 18×18）、心情字形（9×9）+ 心情泡、天气小图标（11×9）；字符格子，颜色键见 `colors.ts` |
| `sprite.ts` | 字符格子 → canvas：自动描边、奶油贴纸边、投影；`spriteCanvas(s, key, outline, ring)`、`blit` |
| `font.ts` | `textCanvas(text)`：5×7 点阵字（钱、DAY 1）；`{ px }` 是阈值切的系统字（已经不用在界面上，留着给画廊） |
| `mood.ts` | `moodOf(台词)` → 心情字形（扳手、心、水滴、杯子、网球、沙漏、青筋、音符、zzz、? 、!；分不出类 = "…"，不出泡）；有单测 |
| `i18n.ts` | 玩家看得见的字（星期、提示、按钮名、天气）中英两份，`?lang=en` |
| `style.ts` | 样式；`body.pxh-on` 藏掉旧的文字界面，`body.pxh-debug` 放出调试牌 |

### 规则（第 4 轮结束时）

1. **半屏卡。** 点开以后的东西都是一张从底部升起的奶油纸卡（`clubsite/hud/sheet.ts` 的 `createSheet`）：1 纹素墨边 + 下面一纹素深影（同 HUD 的奶油牌子）。
   竖屏占底部，横屏是右下角 360 宽的窄卡（不压画面中间）。点卡外面 / 往下滑 = 收起；右上探出一张"关"的小纸条（≥ 44 px，整个在卡顶外面）。
2. **字只有两种。** 名字（中文叫法，英文界面用名）+ 他自己的一句话（平滑系统字，墨色）；数字一律 5×7 点阵（同 HUD 的钱）。第二层另有 ≤ 3 个性子词。
3. **人物卡第一层**（`clubwalk/cast/pxcard.ts`）：探出卡顶的 32×32 像素肖像、名字、5 颗心（好感）、心情脸 + 短条、一句话；
   一天的时间带（太阳 → 月亮，营业 7–22 点；他在的钟点填他的招牌色；"现在"是 3 纹素宽的草帽色针，上面一个小图 = 他在干什么；人就在场时现在这一段一定填色）；
   底下固定 6 个槽的凸起小按钮（聊几句、请喝一杯、打一局、听听意见、送礼物、发消息），图标 + 一种代价（花钱的写 HUD 那枚金币 + 数，不花钱的写小钟 + 分钟），
   这个人做不了的留一个凹下去的空槽 —— 位置永远不动。按了按钮卡顶上方浮一行动作名（同参考的一行浮字），一句话换成他的回话，好感变了心旁边一颗心闪三下。
4. **不当面**：只有两个大按钮 —— 走过去（脚印）、发条消息（信封，见过面才有）。卡开着时人走开了，按互动 = 先走过去，到了卡片重新打开、接着做。
5. **第二层**（卡顶中间的小箭头纸条）：一周 7 个小太阳（来的日子亮、不来的空心、今天下面草帽色底座；每天都在的人不画）、性子 ≤ 3 个词、
   最突出的 3 项属性（图标 + 长条，绿 / 橙 / 红三档）、牵连的小头像（角标：家人房子、搭档球拍、师徒星、较劲闪电、好感心、其他两个扣着的环；点了换成他）。
   没说过话 = 一个大问号 + "聊聊才知道"。
6. **卡讲的是画面里的谁。** 人物卡开着时，这个人头顶一个草帽色、奶油描边的箭头（HUD 新的 `focus(anchor, dy)`）；上方那行话的名字和卡上一样。打开卡时上方那行字收起（卡上有这句话）。
7. **名册 = "今天的人"看板**（`clubwalk/cast/pxboard.ts`）：不是表。今天来的人按地点分簇，每簇一行：打头一个地点小图（车 = 停车场、铃 = 前台、
   匹克球拍、喷泉、奖杯 = 中心球场、球拍 = 会员场、红球 = 红土场、房子 = 会所、水滴 = 泳池、旗 = 高尔夫、杯子 = 美食广场），后面是这儿的人的像素头像
   （肖像裁头、浅纸底），多的收成 "+N"（点了这一簇展开）。离总监近的簇在前。心情很差的人头像底下一道红线。没有页签、搜索、表头字。点头像 = 开他的人物卡。
   旧名册顶上的"下一天"（demo 按钮）没搬过来：调试里 `window.__cast.nextDay()`。
8. **防幽灵点击。** 手机上点 HUD 名册键，抬手时名册打开，系统补来的 click 会落在新卡片上（修前就是这样直接开了第一个人的卡）。卡里的点按只认
   "在卡里按下、又在同一个东西上抬起"（`sheet.ts` 的 `tap()`）。

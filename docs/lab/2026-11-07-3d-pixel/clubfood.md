### stage 3 · 演出（`life.ts`）和总监的活（`play.ts`）

- **导航**（`navspec.ts`）：客人和总监共用一份 NavSpec；**塔可车里是一块 0.85 米高的平台 + 后门外一段坡**（总监那份能进，客人那份整辆挡着）。`stepUp 0.45`（坡 0.95 米升 0.85，A* 每格高差要 ≤ stepUp / 2）。咖啡车和塔可车之间的缝空着 = 去车背后补货的小道。客人用同一张 NavMap 的 A* 寻路。
- **客人**：50 来个人（白模里摆好的接着演：排队的接着排、坐着的接着吃、端托盘的接着找座 + 16 个备用）。从长廊东西、西步道、会所拱廊、球员通道东头进来 → 挑一家（队短的、孩子先去冰棍 / 吉事果，高峰时塔可 × 3.2）→ 先走到队尾再排进去 → 摊主出餐（`feed` / 倒饮料 `pour`，塔可 8 秒一份）→ 端着托盘（`push` 姿势，托盘跟着两手中间）或拿着杯子找座（凉棚下优先、≥ 2 只脏托盘的桌子不坐）→ 吃（`sip`）18～36 秒 → 八成去回收站扔垃圾、把托盘放回回收台，两成把脏托盘留在桌上 → 从最近的口出去。
- **午饭高峰**：每 170 秒一轮（45～125 秒；开局那一波客人吃完才来）。塔可车队伍到 8 个；≥ 5 → 摊主头上"人手不够！"、车篷上竖起排队牌。
- **拟八哥** 4 只：飞去桌上的脏托盘（开局野餐桌上那盘薯条）、满了的桶盖啄；有人走近 1.3 米 → 飞上凉棚梁，4～14 秒后再来；坐着吃饭的人旁边有鸟会喊"去！去！"。
- **孩子**：草皮角扔沙包（`serve` 低手扔，沙包沿抛物线落进洞 / 板上 / 草上，三成五进洞），扔完四只另一个孩子去捡、换人扔；叠叠乐每 14～24 秒被推倒一次（`topple`），家长过去码好。
- **球员出场**：每 50～80 秒两个人从会所拱廊沿球员通道走到中心球场的球员拱门，长桌上的人转头看（`lookAt`）。
- **总监的活**（玩法模式；看戏模式下 `directorDemo` 按"脏托盘 ≥ 2 → 桶 ≥ 0.85 → 存货 < 0.35 → 高峰帮忙"自己做一遍）：
  1. **倒垃圾**：回收站按"换垃圾袋"（最满的那只清空，袋子到手）→ 拎到会所厨房后门按"扔掉垃圾"。开局回收站旁边就有一袋。
  2. **收托盘**：走到有脏托盘的位子按"收托盘"（一次一只，最多叠 4 只端着走）→ 回收台"放回回收台"。
  3. **补货**：补货堆旁的手推车"拿起" → 补货堆"装货"（两箱）→ 推到缺货那辆车后面"给 X 补货"（存货满、关了的窗重新开）。
  4. **帮忙出餐**：高峰时从塔可车后门的铁台阶上去，站到窗口后面按住"出餐"（出餐快一倍；松手 / 下车就停）。
  - 顶栏：满意（脏托盘、满桶、卖光的车、长队、桌上的鸟往下拉，慢慢跟）、卖出、脏托盘、垃圾桶最满的那只、缺货、手上的托盘。
  - 取舍：总监在这里收桌子、倒垃圾、上车出餐的时候，球场那边的活没人做（clubdesk / clubplaza 同一个取舍）。
- 脚本自测（`/private/tmp/claude-501/clubfood/tools/playtest.js`）：拿袋子 → 扔掉、收托盘 → 放回、拿手推车 → 装货 → 给咖啡车补货（0.85 → 1.00）、进塔可车 → 出餐（helping = true）都过。

5. **客人走路的时间多**：院子 33 米深、入口都在南边，一个客人一轮里一半时间在走；高峰以外每家的队伍常常只有 0～2 人。高峰时塔可车 7～8 人。

7. 每只托盘 4～5 个网格，桌上十几只 + 人手上的 ≈ 60 个 draw call；吃紧的话按材质做 InstancedMesh。
8. 串灯 / 凉棚 `setLit` 做好了，傍晚的时间轴和地上的光斑没做（归 M-C 夜场）。

## 玩法计划（stage 3；这一轮只定数据，`layout.ts`）

照玩法准则：不加菜单，总监的活都是"点场景里的东西 / 拖人到岗位"，选择有取舍、有后果。

**总监的活**：
1. **倒垃圾（白模里定格的那一刻）**：三只桶慢慢满（客流 × 时间；`setFill`）。满了盖子顶起、地上开始掉东西 → 拟八哥来翻、吃饭的人皱眉（满意度往下掉，收盘时结算）。点回收站 → 总监走到 `bins` → `lift` 拎出袋子、换新袋（3 秒）→ 扛着走 `director-bins` 路线到厨房后门 `kitchenDoor` 扔掉（路上这段时间别处没人管）。
2. **收托盘 / 擦桌子**：吃完的人走了，桌上留一只脏托盘（`food-tray`），一张桌子 ≥ 2 只 → 新来的人不坐那张。点脏托盘 → 总监去回收台 `trayReturn` 拿收餐盆 → 沿 `director-bus` 一张张收（`pickup` 每只 0.5 秒）、`wipe` 擦一下 → 送回回收台。野餐桌上没收的薯条会招来拟八哥（一群 3～5 只，人走近 1.5 米飞到凉棚顶、10 秒后回来）。
3. **补货**：每辆车有存货（`setStock`），卖一份少一点；低于 0.3 窗口上的图标变灰、摊主探出窗口招手。点那辆车 → 总监去补货堆 `supply` 装手推车（`push` 姿势推着走）→ 沿北墙后的缝 `director-restock` 卸到车后门 `restock*`。冰、杯子、面粉、煤气四种货不分（白模只定一种"补货"）。
4. **高峰帮忙**：午饭（游戏里 11:30～13:30）塔可车的队伍 ≥ 5 人 → 窗口上冒一个"人手不够"的气泡。总监拖到车里（`helpTaco`，从后门上去）→ 出餐快一倍、队伍变短、这段时间收入多一点；代价是别的地方（回收站、桌子、外面的球场）没人管。也可以拖一个员工上去（雇人）。
- **取舍**（玩法准则 2）：总监在这里收桌子、倒垃圾，球场那边的活（吹沙、划线）没人做；不来，鸟和垃圾把客人赶走、餐车的分成（收入）下来。

**院子里的生活（不用操控，循环）**：
- 客人：从长廊（`fromProm`）或会所拱廊进来 → 挑一辆车排队（队短的、或者自己爱吃的；孩子先拉家长去冰棍车）→ 点餐（`orderTaco` 等，2 秒）→ 窗口边等（3～6 秒）→ `carry` 端着托盘找座（凉棚下 → 野餐桌 → 站着吃）→ 坐 30～60 秒（`eat`、`sip`，偶尔 `clap`）→ 还托盘（大部分人）或把托盘留在桌上（一部分人 = 总监的活）→ 走。
- 孩子：草皮角扔沙包（`throw`，沙包沿抛物线 0.8 秒，进洞 / 落板 / 落地三种）、推叠叠乐（倒了 = 一堆木块，家长去扶）。
- 摊主：窗口里来回、`serveWin` 递餐；披萨窑一直冒烟（风大时烟歪）。
- 鸟：拟八哥 2～4 只在院子里走走停停，盯着没人的托盘；落在回收站桶盖、凉棚顶。
- 球员出场（和 clubstadium 联动）：比赛前 10 分钟两个球员 + 裁判 + 球童从会所拱廊出来，沿 `players` 路线走到球员拱门；吃饭的人转头看（`lookAt`）。
- 串灯：傍晚亮（stage 3 的时间轴）。

**能走的地方**（`WALKABLE`）：院子（`FOOD_COURT`）+ 拱廊前小院（`ARCADE_YARD`，减钟楼脚印），减掉车、拖车、小推车、凉棚柱、桌子、野餐桌、回收站、补货堆的脚印；车背后那条缝能走（补货的路）；塔可车能上（帮忙）；往外：长廊往东 = clubstadium / clubplaza，球员通道往东 = 中心球场，西步道往南 = 泳池、会员场。
**站位**（`SPOTS`）：`bins`、`trayReturn`、`supply`、`kitchenDoor`、`restockCoffee/Taco/Pizza`、`helpTaco`、`tableA/B/C`、`picnic`；客人 `orderCoffee/Taco/Pizza`、`fromProm`、`lawn`；球员 `arcade`、`gate`；鸟 `birdTable`、`birdBin`。
**路线**（`ROUTES`）：`director-restock`、`director-bus`、`director-bins`、`guest`、`players`。

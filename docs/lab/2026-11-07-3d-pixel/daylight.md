# 时间和天气（2026-11-13）

之前每个场景都定死在一个时刻（太阳 el 44 / az 8，配色 6 午后金光）。现在 `apps/sandbox/src/clubsite/daylight/` 给所有俱乐部场景一个时钟和天气：
太阳绕着走，人、树、围网的影子跟着变长变短、换方向；天黑换月亮、开球场灯；天气有晴、多云、阴、雨、风沙，默认自动变。

截图（clubwalk 球场中间，390×844）：`shots/daylight/clubwalk-a0630 … f2200.png`（6:36、9:00、12:00、16:30、18:06、22:00）、
`clubwalk-g-cloudy.png`、`clubwalk-h-overcast.png`（14 点）。雨、风沙的截图叠了雨丝 / 沙雾，颜色数过了 refcheck 的 1000 色线，只留在本地。

## 怎么做的

| 层 | 文件 | 做什么 |
| --- | --- | --- |
| 光的表 | `daylight/sky.ts`（纯函数，有单测） | 时刻 + 天气 → 太阳方向、直射强度、三档颜色乘子、天色、轮廓色、云量、雨、风沙、星星、灯、饱和度 |
| 自动天气 | `daylight/weather.ts` | 3 小时一段，按种子哈希抽（晴 52%、多云 26%、阴 8%、雨 6%、风沙 8%），段首 0.4 小时渐变；第一天 15 点前固定晴 |
| 写进画面 | `daylight/index.ts` `mountDaylight` | 每帧：太阳位置（投影跟着转）、`SharedUniforms.day`、天空色带、轮廓色、风、云速、`pipe.atmo`；每 2 秒扫一次场景里的灯 |
| 面板 | `daylight/hud.ts` | 左上角"12:00 晴"牌子 → 拖时刻、四个时段、天气、时间快慢（按钮 ≥ 44 px） |
| 材质 | `render/toon.ts` | 三档各乘各的颜色（自发光的不乘）；投影按 4×4 有序抖动淡出淡入；太阳低时着色光往上抬；`uCloudCut` 云量；灯光圈；饱和度 |
| 合成 | `render/pipeline.ts` `atmo` | 雨丝（1 纹素宽、按风斜）、溅起的亮点、风沙（低频斑块 3 档 + 横飘沙线）、星星；都按纹素画、跟世界锚定 |
| 灯 | `assets/court-light.ts` | `userData.night = { setOn, pool() }`：天黑自动开灯面，灯光圈跟着灯头朝向 |

### 美术约定

- **太阳不走真实的南天**：东边（画面右）升起 → 画面正后方 → 西边落下，影子永远落向镜头这一侧（pixel-scene 第 1 条"太阳在画面后方"）。早上影子往左下、傍晚往右下。
- **12 点 = 原来的样子**：el 46 / az 4.7（原来 44 / 8），颜色乘子 10:30～14:00 全是 1。clubpickle 量的：原来 lum 144 · S 0.43 · 强边缘 0.033，现在 12 点 145 · 0.43 · 0.033。
- **投影最低 12°**：真太阳贴地平线时影子能拉满屏，读不清；影子最长 ≈ 4.7 倍高。
- **着色的光最低 30°**：太阳低时顶面还是亮档（不然清晨整个地面掉到中档，像阴影）；投影照真太阳拉长。
- **三档分开乘**：日落亮面橙、中档淡紫、影子深紫；夜里三档压到 0.2～0.5 偏靛蓝、饱和度 × 0.78。不是整体乘一个数（规范：阴影不是本色乘系数）。
- **阴、雨天没投影**：亮档全压到中档（同云影的做法，纹理还在），投影淡掉。
- **过渡用有序抖动**：太阳换月亮、晴转阴那一小段，投影按 Bayer 4×4 稀掉，不是柔边。
- **灯光圈**：圈心 55% 升到亮档、外圈至少中档，硬边 + 一纹素棋盘抖动；颜色比白天暗一点、偏暖（0.76, 0.72, 0.56），读得出是夜里的灯。

## 接入（场景 main.ts）

```ts
import { mountDaylight } from '../clubsite/daylight';
const day = galleryId ? null : mountDaylight({ scene, pipe, sun, uniforms, params, scheme, sky: SKY, hud: pxEl });
// 固定步长里：day?.step(DT)；每帧 pipe.render 之前：day?.frame()
```

太阳默认放在 `sun.target` 沿方向 80 米；阴影相机跟着人走、按纹素对齐的（clubwalk）传 `placeSun`；镜头会转的（clubmap2）在 `placeSun` 里按 yaw 转。
已接：clubwalk、clubmap2 和 12 个小景（clay、courts、desk、food、front、golf、house、park、pickle、plaza、pool、stadium）。画廊不接（素材在中性光下看）。

URL：`hour`（默认 12）、`weather=auto|clear|cloudy|overcast|rain|dust`（默认 auto）、`tspeed`（游戏秒 / 真实秒，默认 120 = 半分钟一小时；0 停）、`wseed`、`day=0`（关掉）。带 `sunel` / `sunaz` 时太阳不动、只换颜色。时钟跟模拟步长走（`pause=1`、`warm=` 照样确定）。

## 还没做

- 会所室内、窗户、路灯夜里不亮（只有球场灯有 `userData.night`）；要亮的东西给它加 `night = { setOn, pool }` 就行。
- 雨天地面没有积水反光；风沙不吹动地上的沙。
- 天气还没接进模拟（客人多少、场地状态）：等模拟重写（M-B）时由模拟决定天气，画面只读。

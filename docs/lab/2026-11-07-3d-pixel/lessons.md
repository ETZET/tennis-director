## 影响从大到小

1. **每种材质手挑三档颜色，暗档换色相（青/靛），不是亮档乘系数。** 这是最大的一项。草地亮 `#87cf61` → 暗 `#3e8778`（蓝绿），路 `#838ac0` → `#4b5085`，崖壁三档都在靛紫 `#424780` 附近，树冠亮档偏黄 `#b4e266`、暗档偏青 `#3e8270`。同一场景只把暗档改成"亮档 × 0.55"（`light=flat`）或连续 Lambert（`light=lambert`），画面立刻发灰发泥、阴影成了脏橄榄绿（`shots/cmp-light-flat.png`、`shots/cmp-before-after.png` 上半）。
   - 做法：自己写 `ShaderMaterial`（`lights: true`，借 three 的 `shadowmap_pars_*` chunk 取阴影），光照只算一个数 `l = dot(N, L) + 噪声`，按两个阈值挑三档颜色。不要半球光/环境光（它们把暗档往灰里拉）。
   - `THREE.ColorManagement.enabled = false` + 输出 `LinearSRGBColorSpace`，调色板是什么颜色屏幕上就是什么颜色，取色、对色才有意义。
2. **太阳放在画面后方偏低（仰角 38°）。**（**第二轮更正**：照树影实测太阳在东北偏上、仰角约 68°，大片青色其实是云影，见下面「细节打磨的经验」。） 所有朝镜头的竖直面（崖壁、房子正面、石头前脸）自动落进暗档，崖下、树下有大块投影落向镜头 → 画面被分成"亮草地 / 青色阴影 / 靛色崖壁"三大块，这是参考图构图的骨架。太阳高（58°，`?sun=0.15,1.6,-1`）时投影太短，画面一片亮绿（`shots/sheet-res-cam.png`）。
3. **纹素大小和俯角：2 px/纹素、45°。** `px=1` 太细，像普通低多边形渲染；`px=3` 太粗，草帽、浮漂这类小东西糊掉。俯角 30° 时池塘被压扁、看不到地面纹理；60° 时崖壁几乎看不见，层次没了。
4. **投影：PCF 大半径再取阈值，阈值按笔触抖。** `PCFShadowMap`、`radius 4`、2048 贴图盖 60 米（阴影贴图纹素约为画面纹素的一半），在材质里 `step(0.5 + fur, pcf)`，`fur` 是按纹素取的竖向笔触哈希（x 每纹素、y 每 2 纹素）× 0.8。得到的影子是**圆滑的块**（不是阴影贴图的锯齿）+ **草一样的毛边**，和参考图一致。`shadow=basic` 锯齿、`shadow=soft`（不取阈值）有渐变，都不像像素画。
5. **树冠 = 几大团球，球面法线 + 偏上的"假光" + 竖向笔触噪声。** 每棵树 6～7 团（中心一大团、一圈 4 团、顶上两团），每团的法线从团心往外（不是面法线），所以每团都有清楚的亮顶、中腰、暗底；明暗用的光向正上方偏 40%（`lightUp 0.4`，影子仍按真太阳），否则朝镜头的一面全黑；档位阈值加 `hash(floor(world / 纹素 × (1, 1/3, 1)))` 的噪声（幅度 0.4）→ 亮暗交界是一条条竖着的"毛"，就是参考图那种树叶质感。不需要叶片卡片。
6. **描边按方向分：上沿提亮、其余压暗偏靛。** 深度不连续时：只有上方邻居更远（物体的上轮廓）→ 往白提一点；左右下更远 → 本色 × (0.5, 0.55, 0.78)。上沿提亮只给"物件"（材质的 edge 强度写进法线 RT 的 alpha，> 0.2 才提亮），地面的远边照样压暗。法线凸边高光也按材质强度：石头 1.0、楼梯 1.2、房子 0.6～0.8、地面和路 0.03（参考图草地崖顶没有白线，冬天靠雪边自己出来）。
   - 深度阈值按平地的纹素深度差设：45°、1/16 米时平地每纹素差 `mpt·cot(俯角) = 0.0625 m`，取 `depthLo 0.15 / depthHi 0.3`（约 2.5×、5×）。太低地面会出线，太高睡莲、灌木团之间分不开。
   - `edges=off` 时灌木、树冠各团糊成一片；`edges=uniform`（全压暗，desert3d 的做法）上沿发黑、物体发脏（`shots/sheet-edges-shadow.png`）。
7. **水面：底色 + 三档云倒影 + 弱反射 + 一纹素白色虚线泡沫。**
   - 云：滚动 fbm，阈值前加按纹素的抖动（±0.04），分 `cloud / cloud2 / 深` 三档 → 参考图那种块状、边缘颗粒化的云影，覆盖率 25～30%（太多水面发灰）。
   - 平面反射（镜像正交相机渲到同尺寸低分辨率目标，按世界坐标投影采样）只混 30%，并先向水色偏 60%。反射强了水面发灰；参考图里只看得到芦苇倒影和墙脚一条暗边。
   - 泡沫：CPU 烘一张到岸距离场（池岸、石头、桩子），距离 < 1.1 纹素且按世界坐标做虚线 → 白色虚线，正好贴着墙脚、石头脚。
   - 睡莲、花不受投影（参考图里睡莲永远是亮绿），鱼是水面 shader 里的解析形状（淡灰蓝 75%）。
8. **地面细节要少。** 参考图的亮草地几乎是纯色；草叶短划只在少数斑块和阴影里（≤ 6%），小花成簇（1 纹素红/白花头 + 2 纹素深绿茎）。一开始按每纹素 3～9% 撒短划，画面很"噪"，不像。
9. **崖壁**：竖直墙，uv = (沿墙长度, 离墙顶深度)，按纹素量化的 Voronoi 石缝 + 顶上按纹素随机长度垂下来的草边（冬天换雪边）。轮廓用 Catmull-Rom 平滑后的折线，顶面 `ShapeGeometry`，池塘是挖洞。

## 季节（`?season=`）

- 夏、春、秋、冬全是**换调色板**（`season.ts`），几何体不变；秋天换树冠/草/睡莲色阶，春天水偏紫、整体 × (0.9, 0.92, 0.98)、饱和度 0.85，加雨丝和涟漪。
- 冬天：法线朝上（`N.y + fbm 噪声 > 0.55`）的面换成雪的三档（`#b0bdf1 / #c9d2f2 / #e2e8f2`，阴影是长春花蓝）；树干只在 `N.y > 0.8` 处盖雪；墙顶草边换成雪边；70% 的树光秃秃（加几根枝杈）；水面按 `fbm + 离岸 + 北侧偏置` 阈值结冰，冰分三档并带白色冰缘；雪花、雨丝在合成 pass 里按纹素画，跟世界锚定（平移时不粘屏幕）。

## 没用 / 效果差的

- **后期色阶量化 + 有序抖动**（`post=6`）：把手挑的颜色打乱，画面脏，不如直接用调色板。
- **连续光照或"等比变暗"的三档**：见第 1 条。
- **BasicShadowMap / 不取阈值的软阴影**：见第 4 条。
- **强反射**（55%）：水面变灰、到处是树的倒影。
- **满地撒草叶**：见第 8 条。
- **面法线的二十面体树冠**：每个三角面一个颜色，像低多边形而不是一团叶子（必须换成球面法线）。

## desert3d 的管线该怎么改（具体建议）

1. `toon.ts`：`MeshToonMaterial` + 灰度渐变（70/150/255 乘本色）换成**每材质三色调色板**的 `ShaderMaterial`（可以直接拿 `pond3d/ramp.ts`），暗档手挑、偏冷色相；去掉半球光；关颜色管理、线性输出。
2. 阴影：`BasicShadowMap` → `PCFShadowMap` + `radius 3～4` + 材质里取阈值 + 竖向笔触抖动（`uFur 0.8`）；阴影贴图纹素 ≤ 画面纹素的一半。
3. 太阳：放到画面后方（远离镜头的一侧）、仰角 35～40°，让朝镜头的面统一落暗档、投影落向镜头。（第二轮更正：参考图实为东北偏上约 68°，朝镜头的面照样是暗档；大片暗面用云影补。）
4. 相机：俯角 45°、每纹素 2 CSS 像素；yaw 0 让崖壁、台阶成水平带（参考图"规整"感的来源），想保留 25° 斜角也行，但调色板和描边的结论不变。desert3d 现在 `pitch 38°`、`zoom 0.2 m/纹素`——在 0.2 时人只有 9 纹素，细节到不了参考图的密度，建议 0.08～0.1（参考图换算是 1/16）。
5. `pipeline.ts` 描边：区分上沿（提亮）和其余（压暗偏靛），每个材质把描边/凸边强度写进法线 RT 的 alpha；`depthLo/Hi` 按 `mpt·cot(俯角)` 的 2.5×/5× 设（zoom 变了要跟着变）。
6. 树、灌木：球面法线的几大团 + `lightUp 0.4` + 竖向笔触噪声阈值（见第 5 条）；不要面法线。
7. 地面细节减量：纯色为主，斑块和短划只在少数地方。
8. 水（如果以后有）：用 pond3d 的 `water.ts`；手机上可以去掉平面反射（`refl=0` 几乎看不出差别，省 40% 的 draw call）。

## 性能

- 1280×720（内部 642×362）：每帧所有 pass 合计 **237 次 draw call、11.7 万三角形**（颜色、反射、法线、阴影四个 pass 各约 60 次）；关反射 145 次 / 7.1 万。
- `?bench=30`（每帧 readPixels 等 GPU 做完）在开发机的无头 Chrome 上 2～5 ms/帧（抖动大，只能看相对值）；390×844 竖屏约 2 ms。
- 几何体按材质合并（树冠、灌木、芦苇各一个网格），没有用 InstancedMesh；风摆用顶点属性 `aSway`，阴影深度材质同步摆。

## 沙漠场景失败复盘

2026-11-07 · desert3d（五个代理各做一个部件）被评为"毛坯"：饱和度 0.29（参考 0.47）、强边缘密度 0.096（参考 0.045，2 倍）、亮度直方图平的。
重做成 desert3d-v2（`apps/sandbox/desert3d-v2.html`，代码 `src/desert3d-v2/`）：先定构图和调色板，再按规格画资产（`ASSETS.md`）。
只放地形 + 平涂球场 + 灰色占位时：竖屏饱和度 0.49、强边缘 0.048、亮度两个峰（亮沙 ≈ 第 7 档 30%、球场 ≈ 第 5 档 34%、暗带 ≈ 第 2～4 档 27%）。

1. **先构图，后资产。** 五个人各自把自己的部件做满，拼起来没有主角、没有层次：矩形里套矩形、满地程序化撒点。构图是一张手画的草图：一个主角（球场）、三条暗带（朝镜头的台地崖壁）分层、一条路把视线从角落引到主角、两三团高的框（左上、左下）、其余故意空着。先用灰块摆出来，截图觉得对了再画资产。
2. **暗带是免费的构图工具。** 太阳在画面后方时，所有朝镜头的竖直面自动落暗档，下面一层还有一条投影 → 每一级台地 = 一条"靛色墙 + 紫色影"的横带。地形分 3～4 层（高差 1～2 米），画面的明暗骨架就有了；平地上再怎么加细节都给不了这种结构。注意：只有朝南（朝镜头）的边才出带，侧边在 yaw 0 下是看不见的一条线，所以轮廓要弯、要有朝南的段。
3. **高的东西的投影会盖住主角。** 8 米的棕榈在 35° 太阳下投 11 米的影，正好压在球场上一大块。摆树时先看投影落在哪（太阳方位决定朝左下还是右下）；把太阳放到画面后方略偏东，左上的框的影子就落到左边去了。
4. **调色板定饱和度和明暗，不是后期。** 每种材质手挑三档，大面积的亮档 HSV 饱和度 0.45～0.6、亮度 170～200；暗档换色相、饱和度不掉（沙的影子是紫红 #8a5f96，崖壁是靛紫 #5a3f86）。颜色集中在一张表里（`palette.ts`），资产只能从表里拿 → 五个人画出来也是一个调子。
5. **影子的色相不能和别的东西撞。** 第一版沙影用了淡紫，步道也是淡紫石板 → 路和影子分不开，路失去引导作用。改成：影子紫红、路是比沙更亮更冷的钙质土（#f6e0b4）。检查方法：眯眼看，每种"东西"（沙、影、路、墙、水、球场）是不是一种独立的颜色。
6. **噪点 = 细线 + 小点。** v1 的强边缘一半来自 1 纹素的东西：铁丝网、细杆、细裂缝、满地碎石和草叶。规则：可见部分 ≥ 3 纹素，否则不画；网用一条暗带表示，不画网眼；裂缝 2～3 条、2 纹素粗。占位阶段强边缘就该 ≤ 0.04，资产加完不超过 0.055。
7. **细节放在主角上，平地留白。** 参考图的亮草地几乎是纯色；细节集中在池岸、栈桥、人、树冠。沙地不要撒东西，资产成簇放在构图标出的位置。
8. **立面不要接收投影。** 崖壁、台阶接收投影时，阴影贴图的毛边在竖直面和窄踏面上变成一片麻点（v2 的台阶第一版就是这样）。关掉以后崖壁是干净的暗带、台阶是干净的亮暗条纹。
9. **给资产一个隔离的画廊。** `?asset=<id>`：一块小沙台、最终缩放、旁边一个 1.8 米的比例尺、下面同一画面放大 3 倍（像素一个不差）。在构图里看太小、在普通 3D 视图里看又太细，这两个窗口刚好。

## 细节打磨的经验（第二轮，2026-11-07）

方法：参考图转 PNG，和渲染图同一块裁出来并排、最近邻放大 3～4 倍（`tools/crop.mjs`），按 4×3 网格 + 每个物件单独一块逐块对；取色用 `tools/pick.mjs`（7×7 窗口里按 5 位量化取**众数**，JPEG 噪点下平均值会偏灰）。截图 `tools/shot.mjs`（1280×720、dpr 1）。三联图 `shots/detail-*.png` 是「参考 | 第一轮 | 现在」。

### 每样东西怎么做的

### 通用规则

1. **先对位置再对细节。** 描错 10 像素比材质差显眼得多（房子、栈桥、台阶、北边台地第一轮都偏了 10～30 像素）。台地按"墙顶边"在参考图上描，物件的地面高度用"点落在哪个台面多边形里"自动取（`groundAt`），树和灌木就不会漂在错的台面上。
2. **先量光，再调色。** 用"树冠中心 → 影子中心"的屏幕偏移反推太阳方向（偏移 (dx·32, dz·22.6) 像素/米，除以树冠高度）。第一轮把参考图的大片青色当成低太阳的长影，北边台地全进影子；实际是高太阳 + 软边云影。
3. **道具按纹素定尺寸。** 最细的东西 ≥ 1.1 纹素（0.07～0.08 米），否则 45° 下时有时无；所有"线"（板缝、石缝、草叶、木纹、箍）都设计成整 1 纹素；要水平的线按屏幕行 `(y − z)·cos45/纹素` 取整，世界坐标的 z 线在屏幕上间距是 0.707 纹素，会断。
4. **描边强度跟物件的棱的密度反着调。** 棱多、面小的东西（台阶、面法线石头、多面体）edge ≤ 0.6；大而圆的（睡莲、帽檐）靠上沿提亮出那条亮边。
5. **色板从参考图取众数；道具的主面不一定跟太阳。** 房顶两坡一明一暗、箱子正面亮、花的杯子粉，都用材质自己的 `light` 方向（只影响分档、不影响投影）让主面落在参考图那一档；变体色用 `mix(本档, alt, k)` 而不是固定色，这样亮面、背光面都对。
6. **手摆 vs 程序。** 构图级的大形状（云影、云倒影、冬天开水、北岸亮带、团影）手摆或由场景数据驱动；小纹理（石缝、草叶、叶簇、水斑）程序化。纯 fbm 的大形状永远对不上参考图，而且换个种子就变。
7. **噪声一律按纹素中心取**（`floor(world / 纹素)`），不要在连续坐标上加逐片元抖动——那就是第一轮水面、冰面的颗粒感来源。

## 组装经验（desert3d-v2，2026-11-07）

19 个资产由 8 个代理各自从零画（画廊 `?asset=<id>` 里隔离迭代），再由一个人组装、打磨、加演出。终稿：竖屏饱和度 0.50、强边缘 0.050；横屏 0.50 / 0.051（参考 0.47 / 0.045）；亮度两团（第 2～4 档崖壁/影子 ≈ 23%，第 5～7 档球场/沙 ≈ 60%+）。

1. **太阳高一点，影子小一点。** 35° 的太阳下，8 米的棕榈投 11 米影，正好盖住半个球场；台地的影子带也太宽，画面一大半是紫色。抬到 50°、方位偏东 22°（影子落向左下），朝镜头的崖壁仍然是暗档（l = −0.57），但影子面积减半。
2. **大块平地要有"中间层"，但要手摆。** 参考图草地上那层稀疏的草团、小花、碎石，用 25 个手摆的簇（崖脚影子带、植物脚下、步道转弯、铺面四角的杂草、球场裂缝里）+ 几块只比沙深一点的沙斑来做；再加 0.25 的移动云影（把亮沙推到中档的一大块软形状）。比满地撒点好得多，强边缘几乎不涨。
3. **框要进画面。** 放在北台上的 8 米棕榈，叶冠在竖屏上方之外 —— 框没框住。算一下叶冠的屏幕高度 `v = (地面高 + 树高)·cos45 − z·sin45`，把框的树往镜头挪到叶冠刚好压进画面角上。
4. **阴影里别放小植物。** 小灌木放在大树或台地的投影里，整团落到中/暗档，凸边白线一圈圈地亮 → 一颗颗"深绿卷心菜"。挪出影子，或者干脆不放。
5. **金色的东西在沙上会消失。** 干草、风滚草、仙人球、扫帚头和亮沙的亮度差 < 10 就没了：干草亮档提到比沙亮 25（#f6dc84），并保证它们的暗档（紫）露出来。草帽同理靠帽檐下的影子出来。
6. **小暗圆块 = 油渍/洞。** 场上的剥落（深色圆块）和人的影子、洞分不开；裂缝要"缝 + 下沿一纹素亮边"（翘起的漆皮迎光），读起来才是裂缝。
7. **强边缘大户是白线。** 白线和青蓝场地的亮度差 > 60，每条竖线每行算两次；球场一项就占了预算的 2/3。其他东西要省：路缘石调到和外场绿差 < 60、描边压暗降到 0.48。
8. **演出要短而可读。** 第一组人从步道走到场上要 35 秒，分间扫地要 20 秒 —— 没人看得下去。第一组直接从台阶顶出来、总监在迎风一侧的网柱旁等、扫最近的那堆（`dirtiest(min, near)` 按距离打折）、扫帚每 0.1 秒扫 5 厘米并来回挪 0.85 米：一分 + 一次扫地 ≈ 15 秒，扫过的地方露出一条干净的场地。风把沙吹回去的速度要远小于扫的速度（每秒约 0.006 米³ vs 0.5 米³），否则扫了等于没扫。
9. **尘土要比沙亮。** 尘团用和沙同色就是一块"实心的橙色团"；换成更浅更冷的钙质土色（路的颜色）才读成扬起的尘。

### 资产代理的经验（摘要）

- 小道具、竖直的薄片（帆布、网、扇叶、人）`noShadowReceive`：阴影贴图的毛边落在小面上就是麻点。
- 朝镜头的面（人的脸和胸、仙人掌正面、帽子）：`lightUp` 0.5～0.65 + 把档位阈值往下挪（`bands` 约 [−0.45, 0.3]），否则太阳在后方时正面全黑。
- 多团的、面法线的东西 `convex` ≤ 0.3：每条团缝/棱都出白线，整团发碎。
- 位置和尺寸按整纹素取（偏移、线宽、板缝），否则 45° 下时有时无。
- 平的地面图案（球场漆、裂缝、线）按"屏幕纹素格"画：x 每格 1 纹素，z 每格 1 屏幕行（纹素 / cos45），每条边都整纹素、不闪。
- 金色/沙色的东西要和沙拉开亮度（见上第 5 条），或者靠暗档、描边把轮廓拉出来。

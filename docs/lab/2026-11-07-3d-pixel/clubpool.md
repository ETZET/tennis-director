# clubpool · 泳池（白模阶段）

会所南边的泳池，棕榈泉度假风。地图上是 `POOL`（x −57…−43、z 3…13，14 × 10 米）+ 一圈池畔 `POOL_DECK`（x −61…−39、z −1…18）：石板池畔、池沿、三顶帐篷、一排躺椅。
这一版：**池畔抬高 0.45 米做成一块平台**（三级台阶上去，朝镜头的南沿 + 矮围栏是画面下面那条暗带），青绿的池水是主角；北边两顶条纹帐篷夹着救生员高椅，南边一排躺椅（四对）和三把蓝白伞，西边两对躺椅一把伞，东边毛巾车、回收筐、淋浴。池里有人游泳、站在浅水里聊天、孩子套着游泳圈在浅水台阶边，一只火烈鸟浮床漂着；池边有人坐着泡脚，一只拟八哥在池沿喝水。总监在北池沿捞漂在水上的蒲葵叶。围栏外：北边一条石板小路上去到会所，西南角一间泵房，南边一块晒太阳的草坪。

- **视线**：右边东门进来的会员（横屏）→ 南边一排躺椅 → 池里游泳的人、火烈鸟浮床 → 北池沿的总监 → 救生员高椅 → 北门 → 小路 → 会所。

### 每个资产的要点

**#1 lounger**——白色金属 / 树脂框（两条边框 + 四条腿）+ 一张整块的垫子（座 1.3 米 + 靠背 0.7 米）。v0 靠背立起 50°、垫子露着；v1 放平、上面铺一条毛巾；v2 立起、毛巾 + 地上一只包。45° 俯视下靠背立 45° 时正好侧对镜头 —— 垫子的颜色主要在座面上（朝天，亮档）。`userData.setBack(角度)`、`setTowel(on)`（客人走了留下的毛巾 = 总监的活）。

**#3 lifeguard-chair**——经典的白木高椅：四条斜腿往外撇、南面一架梯子（三根横档）、座 1.8 米、靠背、扶手，顶上一把小方伞（往北斜，影子落回座上）；一只红色救生浮标挂在扶手上（画面里那一点红 = 认得出是救生员椅）。人坐上去用 `setSeat(1.8, 1.45)`（同裁判椅）。

**#4 cabana**——地图上的三顶帐篷留两顶，放在北边池畔的东西两头（竖屏的左右边缘 = 框）：四根柱、北 / 东 / 西三面帆布（东西两面卷起一半）、四坡帆布顶（宽的蓝白条）、里面一张双人垫子（`accCushion`）。南面敞开朝池子：里面坐着的人看得到。

**#7 pool-fence / #8 pool-gate**——泳池按规矩要围起来（1.2 米），但不能挡住池畔：灰泥矮墙 0.45 + 铁艺栏板画成**一条暗带**（规则：几十条 1 纹素的细杆 = 噪点），顶上一条扶手、每 3 米一根灰泥柱。门是自闭的铁门（略开一条缝）+ 两根门柱（柱顶一只球形灯）+ 一块图标规则牌。

**#11 pool-float**——火烈鸟浮床是池里唯一的一块粉，也是一个小故事（风把它吹到池边、孩子抢着上去）。

**#13 pump-house**——总监"加氯 / 洗滤网"的地方：一间土坯小房（和西墙一家）、平顶、门朝东对着工作门，门口一只过滤罐、两只氯桶。

## 玩法计划（stage 3；这一轮只定数据，`layout.ts`）

照玩法准则：不加菜单，总监的活都是"点场景里的东西 / 走过去做"，选择有取舍、有后果。

**总监的活**：
1. **捞叶子（白模里定格的那一刻）**：风一吹，蒲葵叶、虫子落进池里（`palm-litter` 漂在水面上，慢慢漂向下风的池角）。点水面上的叶子 → 总监拿捞网沿池边捞（`director-skim` 绕池一圈，站位 `skimN / skimE / skimW`）。不捞：叶子越积越多，游泳的人皱眉、躲到别的角（满意度往下掉，收盘结算）。
2. **加氯 / 洗滤网**：池水有一个"清"的值，按游泳的人数慢慢掉；先出画面信号（水从青变得发绿发浑、池底看不清），再掉档（有人上岸走了）。点泵房 → 总监走工作门进泵房（`director-pump`）加一桶氯、洗滤网（几秒）→ 水慢慢变回青。
3. **收毛巾 / 补毛巾**：客人走了躺椅上留下毛巾（`lounger` 的 `setTowel`）→ 总监沿南边一排收进回收筐（`director-towels`）；毛巾车空了（`setStock`）→ 从会所搬一摞来（会所的活，跟 clubhouse）。
4. **顶班**：救生员要休息（头上冒气泡）→ 总监爬上高椅顶一会儿（`guard`）。这段时间别处（球场、餐车）没人管 = 取舍；不顶 = 救生员走开、池里的人被叫上岸（泳池这段时间零收入）。
5. **摆椅子 / 收伞**：傍晚风大，伞没收会被吹翻（`setOpen`）；躺椅被拖乱了。

- **取舍**（玩法准则 2）：泳池是会员满意度的大头之一（家庭、度假客），但不直接收钱；总监在这里捞叶子、顶班，球场那边（吹沙、补线）就没人做。

**泳池的生活（不用操控，循环）**：会员从东门（打完球）或北门（会所换好衣服）进来 → 东边毛巾车拿毛巾 → 冲个淋浴 → 挑一张躺椅（有伞的先满）→ 躺 60～120 秒（`lounge`，偶尔 `sip`、翻身）→ 下水（浅水台阶或梯子）游几个来回（`swim`）→ 上岸擦干 → 走（毛巾一半还回收筐，一半留在躺椅上）。孩子在浅水台阶边玩游泳圈、抢火烈鸟浮床；救生员偶尔吹哨（孩子跑）；拟八哥落在池沿喝水，人走近飞走。

**站位**（`SPOTS`）：入口 `fromClub` / `fromWestPath` / `service`，`northGate`、`eastGate`、`skimN/E/W`、`guard`、`guardFoot`、`towels`、`hamper`、`pump`、`showerN/E`、`loungerW/E`、`stepsIn`、`ladder`。
**路线**（`ROUTES`）：`member-in`、`club-in`、`director-skim`、`director-towels`、`director-pump`。

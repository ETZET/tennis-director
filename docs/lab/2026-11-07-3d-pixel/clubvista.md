用户看了《垂钓手记》的溪流地图视频（参考帧只在本地 `~/workspace/tennis-director-refs/fishing-notes-stream/`），
想让俱乐部的地图也做到"画面干净、地图好"。这一页按参考的地图搭法把俱乐部重新组织成四张主题小图，图和图之间走到出口 → 圆形遮罩转场。

## 参考的地图原则（brief：`~/workspace/tennis-director-refs/club-redo/brief/analysis.md`「地图怎么搭」）

1. 一张图一个主题，一两屏大；图和图之间转场（坐车 + 圆形遮罩 + 黑屏加载）。
2. 边界是自然的东西（密林、崖、水、马路、山），没有围栏和空气墙；**边缘最密、中间最空**。
3. 地形 2～3 层，层间朝镜头的崖做暗带；最安静的大面在最低层（参考是水，我们是球场）。
4. 路分主次、要弯：一条主路斜着弯过画面，支路通兴趣点。
5. 一张图 = 入口 → 目的地 → 歇脚。
6. 小场景讲故事、不靠字。

## 做法（代码）

| 文件 | 内容 |
| --- | --- |
| `mapdef.ts` | 一张图的数据形状：台面 Plate（高度 h、周围高度 base；h > base = 台地，朝外的崖从 h 下到 base；h < base = 坑，朝里的壁）、带子 Strip（主路 / 踏脚石 / 马路线）、台阶 / 小桥 Stair、平涂球场 Court、摆件 Prop、不能走的 noWalk、出口 Exit、入口 Entry；画轮廓的 `rect` / `band`（干河床、峡谷这种带）/ `blob` / `cluster`（3～7 个一簇） |
| `maps.ts` | 四张图（每张 28 米宽的核心 × 56～60 米深 + 两边各 15 米的边框） |
| `build.ts` | MapDef → 画面 + 导航：台面平滑、坑自动挖洞（只挖最外层的坑）、亮唇 + 崖壁（沙岩元素）、水面（带"到岸距离"的格子网格 + 一纹素白水线）、踏脚石、台阶、木桥、球场（外场 / 内场 / 白线）；摆件（本地资产 > 复用 > 白模）、默认挡路（树干圆、包围盒、有顶棚的只挡后墙）；0.25 米的高度格子（NaN = 水面 / 河床 / 密林） |
| `world.ts` | 页面：管线、太阳（阴影相机跟着总监、按阴影纹素对齐，同 clubwalk）、daylight、玩法（`clubsite/play`，按住走 / 点地面）、出口检测 → 转场、`?audit=1` 能走范围、`?labels=1` 白模标签 |
| `iris.ts` | 圆形遮罩转场：**界面代理的 `clubsite/hud/iris.ts` 原样复制**（它的分支合进来以后改 import） |
| `gallery.ts` | 资产画廊（上 / 左 2×，下 / 右放大 3 倍，1.8 米的人当比例尺） |
| `palette.ts` / `grade.ts` | 调色板（餐车院子、泳池、会员场、中心球场的超集 + 新材质）、默认配色 `vista`（午后金光的亮档 + 低彩度冷灰紫的暗档，只在这个页面） |
| `assets/` | 新画的资产；`reuse.ts` 只读复用别处的 |

四张图叠在同一块坐标上（`MAP_GAP` 0），只显示当前那张；换图时换导航的高度函数、挡路形状、坡道（`play.nav.setBlocked` 重建 0.2 米的网格，一张图 13.6 万格 < 15 万，A* 整图搜，不走粗网格的近路 —— 第一版四张图并排铺成 92 万格，长路线因为粗网格走廊找不到路）。

工具（`docs/lab/2026-11-07-3d-pixel/tools/`）：`vistashot.mjs`（一轮的 8 张截图）、`vistanums.mjs`（裁掉界面跑 hues + stats）、`vistawalk.mjs`（14 条路线：点地面寻路走过去、出口转场到哪张图）。

### 第 1 轮：白模（72 × 60 米的横向图）

改了什么：四张 72 × 60 米的图（照横屏一屏 58 × 46 米设计），干河床 + 小桥、下沉球场（东西向）、绿洲池 + 瀑布、两片练习场。

数字（竖屏 / 横屏）：

| 图 | 冷 | 平静 | 饱和 | 强边缘 |
| --- | --- | --- | --- | --- |
| arrive | 17% / 12% | 84% / 86% | 0.38 / 0.41 | 0.022 / 0.016 |
| court | 62% / 55% | 92% / 92% | 0.44 / 0.42 | 0.014 / 0.011 |

评判原文（3/10）：
> 问题 1：四张图都是边缘空、中间满 —— arrive 横屏左右两大片空沙，只零星撒了几株一样大小的小植物；court 球场四周是光沙；practice 两块场地直接顶到画面边。沿三条边各摆 3～7 簇（棕榈、石丛、灌木，每种 2～3 个尺寸），占屏深 15～25%。
> 问题 2：手机竖屏取景不成立 —— court-port 主球场东西向横放，两头被裁掉；practice-port 只看得到一块场；arrive-port 看不到入口和巴士。中心球场转成南北向；每张图按竖屏定焦点。
> 问题 3：地形分层太弱，阴影边是毛的 —— court、practice 整张图一层平地；oasis 泳池和池边同高；崖面做 1.5～3 米高、暗带 ≥ 10 纹素；阴影改成硬边。
> 问题 4：最大的安静面放错了东西 —— 球场外围的灰蓝平板占屏 40～60%；oasis 水面高饱和青色、大块斑驳，是全屏最吵的一块；arrive 冷色、饱和度不达标；河床里粉紫的软边色斑要删。
> 问题 5：路不分主次，物件不成团讲故事 —— 路是浅沙带、和地面同一个明度；躺椅和伞排成一字；绿洲没有一棵棕榈。
> 分数：3/10。只有骨架：河床和桥、瀑布有点意思，但疏密、分层、竖屏取景三件地图层面的大事都还没立起来。

### 第 2 轮：竖屏优先的竖条图

改了什么：四张图全部重画成 28 米宽 × 56～60 米深的竖条（竖屏一屏 ≈ 18 × 54 米：从下往上"入口 → 目的地 → 歇脚"，镜头跟着人往上滚），两侧各 15 米的密边（横屏一屏 58 米正好看到）；球场真尺寸（连外圈 18.3 × 36.6 米）、南北向（主代理：不为了塞进一屏缩比例）；主路换成深一档的土路 `trail`，支路是踏脚石；池水 `lagoon`；云影只放在边框上（河床上那块粉紫的软斑没了）；投影毛边在这个场景的 mats 里压到 0.35。

评判原文（4/10）：
> 问题 1：竖屏的边框落在画面外，竖屏图边缘全空 —— arrive-port 大半屏是平沙加河床，左右两边一棵树都没有；oasis-port 几乎整屏是水；court-port 和 practice-port 整屏只有球场。每条路线两侧 ±9 米以内放密簇；也可以把图收窄到 20～22 米。
> 问题 2：四张图长得一样，court 和 practice 分不出 —— 四张横屏左边都是同一列等距、同大小的棕榈；给每张图一个第一屏就看得到的招牌轮廓（court 三面看台、practice 练习墙 + 凉棚 + 球筐 + 发球机一组、场地换颜色）；四张图边界各用不同的东西。
> 问题 3：层间崖太薄，看不出 2～3 层 —— 河床两岸的崖、practice 顶部的墙只有 2～4 纹素；court 看不出下沉；oasis 池子和沙同高、没有池沿。层高差做到 1.5～3 米，泳池下沉一层，加石沿和白色水线。
> 问题 4：河床是最吵的大面 —— 碎石块放大 2～3 倍，缝收到几乎和本色一样，明度压低、低彩度冷灰；沙地上的软边斑块一起删掉。
> 问题 5：球场外圈和影子同色，棕榈影子连成一大片 —— 外圈换成色相明显离开影子色的颜色；棕榈影子缩小，簇和簇之间留出空地。
> 分数：4/10。入口 → 桥 → 台阶这条主线弯得对，配色方向也对；但竖屏没有框，四张图认不出彼此，地形层次立不起来。

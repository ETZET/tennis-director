页面 `apps/sandbox/clubvista.html`（代码 `apps/sandbox/src/clubvista/`），资产画廊 `clubvista.html?asset=<id>`。
用户看了《垂钓手记》的溪流地图视频（参考帧只在本地 `~/workspace/tennis-director-refs/fishing-notes-stream/`），
想让俱乐部的地图也做到"画面干净、地图好"。这一页按参考的地图搭法把俱乐部重新组织成四张主题小图，图和图之间走到出口 → 圆形遮罩转场。
clubwalk（11 个小景连成的一整个世界）不动；这是另一条路的试验。

## 参考的地图原则（brief：`~/workspace/tennis-director-refs/club-redo/brief/analysis.md`「地图怎么搭」）

1. 一张图一个主题，一两屏大；图和图之间转场（坐车 + 圆形遮罩 + 黑屏加载）。
2. 边界是自然的东西（密林、崖、水、马路、山），没有围栏和空气墙；**边缘最密、中间最空**。
3. 地形 2～3 层，层间朝镜头的崖做暗带；最安静的大面在最低层（参考是水，我们是球场）。
4. 路分主次、要弯：一条主路斜着弯过画面，支路通兴趣点。
5. 一张图 = 入口 → 目的地 → 歇脚。
6. 小场景讲故事、不靠字。

## 做法（代码）

| 文件 | 内容 |
| --- | --- |
| `mapdef.ts` | 一张图的数据形状：台面 Plate（高度 h、周围高度 base；h > base = 台地，朝外的崖从 h 下到 base；h < base = 坑，朝里的壁）、带子 Strip（主路 / 踏脚石 / 马路线）、台阶 / 小桥 Stair、平涂球场 Court、摆件 Prop、不能走的 noWalk、出口 Exit、入口 Entry；画轮廓的 `rect` / `band`（干河床、峡谷这种带）/ `blob` / `cluster`（3～7 个一簇） |
| `maps.ts` | 四张图（每张 28 米宽的核心 × 56～60 米深 + 两边各 15 米的边框） |
| `build.ts` | MapDef → 画面 + 导航：台面平滑、坑自动挖洞（只挖最外层的坑）、亮唇 + 崖壁（沙岩元素）、水面（带"到岸距离"的格子网格 + 一纹素白水线）、踏脚石、台阶、木桥、球场（外场 / 内场 / 白线）；摆件（本地资产 > 复用 > 白模）、默认挡路（树干圆、包围盒、有顶棚的只挡后墙）；0.25 米的高度格子（NaN = 水面 / 河床 / 密林） |
| `world.ts` | 页面：管线、太阳（阴影相机跟着总监、按阴影纹素对齐，同 clubwalk）、daylight、玩法（`clubsite/play`，按住走 / 点地面）、出口检测 → 转场、`?audit=1` 能走范围、`?labels=1` 白模标签 |
| `iris.ts` | 圆形遮罩转场：**界面代理的 `clubsite/hud/iris.ts` 原样复制**（它的分支合进来以后改 import） |
| `gallery.ts` | 资产画廊（上 / 左 2×，下 / 右放大 3 倍，1.8 米的人当比例尺） |
| `palette.ts` / `grade.ts` | 调色板（餐车院子、泳池、会员场、中心球场的超集 + 新材质）、默认配色 `vista`（午后金光的亮档 + 低彩度冷灰紫的暗档，只在这个页面） |
| `assets/` | 新画的资产；`reuse.ts` 只读复用别处的 |

四张图叠在同一块坐标上（`MAP_GAP` 0），只显示当前那张；换图时换导航的高度函数、挡路形状、坡道（`play.nav.setBlocked` 重建 0.2 米的网格，一张图 13.6 万格 < 15 万，A* 整图搜，不走粗网格的近路 —— 第一版四张图并排铺成 92 万格，长路线因为粗网格走廊找不到路）。

工具（`docs/lab/2026-11-07-3d-pixel/tools/`）：`vistashot.mjs`（一轮的 8 张截图）、`vistanums.mjs`（裁掉界面跑 hues + stats）、`vistawalk.mjs`（14 条路线：点地面寻路走过去、出口转场到哪张图）。

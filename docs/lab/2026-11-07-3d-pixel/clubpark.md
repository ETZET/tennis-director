# clubpark · 停车场 / 到达区（白模阶段）

俱乐部东墙大门外：车从东边画外（车道穿过谷地通往山里）开进来，沿车道到大门口的落客区，代客（valet）接车、开去停，会员下车走进大门；自己停车的车在两片停车场的通道里慢慢找车位。主角 = **大门 + 代客岗亭 + 落客区**。和墙里面的前台场景（clubdesk）以东墙大门为界，两个场景用同一套世界坐标（`clubmap2/layout.ts`）。总监以后能操控（走、拿/用工具，同 desert3d-v2），这一轮只定构图、站位、路线和能走的范围。

- 页面：`http://[::1]:5190/clubpark.html`（构图 + 占位）。画廊：`clubpark.html?asset=<id>`（`&v=` 变体、`&ground=paver|asphalt|sand`、`&ref=0`、`&cy=`）。
- URL：`px`（默认 1）、`zoom`、`tx`/`tz`、`sunel`/`sunaz`（默认 44° / 偏东 22°）、`pause=1`、`labels=0`、`ph=0`、`nav=0`、`clouds=0`、`edges=1`、`warm`、`seed`、`pal`（不带 = 6 午后金光；右上角切换；左上角像素级别）。
- 标签：灰 = 占位（要画的新资产），绿 = 已画的新资产，青 = 复用的资产，米黄 = 区域名；洋红圆盘 = 站位，洋红小点 = 路线。
- 钩子：`window.__park = { scene, pipe, step, setSun, own, reused, palOpts }`、`window.__parkTerrain`（`groundAt`、`edgeX`、`outlines`）。
- 截图（不在仓库里）：`/private/tmp/claude-501/clubpark/blockout-{port,land}{,-labels}.png`。

- **视线**：车道从画面右边（横屏里从画外）进来 → 两个花坛夹着的口子 → 最亮的连锁砖落客区 → 门洞。会员的两条步道（墙边石板，上下两头）也收到门洞。
- **框**：左上蒲葵（墙边步道北头）、左下蒲葵（南头）、上下两个遮阳棚、左边的东墙 + 门柱。
- **安静的地方**（别往里加东西）：南近排和南通道（只一辆车、一块云影）、横屏右边的沙漠（车道两边）。
- **影子**：太阳 44°、偏东 22°，影子落向左下（每米高往 −x 0.38、往 +z 0.96）。落客区附近的花坛只种矮的；高的蒲葵放在墙边步道两头、北花坛东段、南花坛东段，投影都不上落客区。遮阳棚的投影把通道切成一明一暗。

### 每个资产的要点

**club-gate（主角的框）**——同 clubmap2 的尺寸。yaw 0 下门柱朝南的一面是暗档（大块梅紫），柱顶网球是画面最亮的点之一（暗档要露出来）；横梁沿 z，屏幕上是一根竖着的木条，压在门洞上面。**朝东的招牌在 yaw 0 下正好侧对镜头，看不见**（见「要商量的」1）。两根柱的南面：南柱的南面在落客区上方，是门童的背景。

**valet-booth（主角）**——小土坯亭子（灰泥面、陶砖压顶的平顶出檐 0.25），朝南（朝镜头）开一个宽窗（钥匙柜在窗后：一排小钥匙牌，≥ 3 纹素一个）+ 窗下一块小木台；窗上一条俱乐部奶油帆布雨篷（2～3 个大扇形垂边，蓝白条纹跟着条纹走）。朝镜头的墙落暗档：窗框、雨篷垂边是唯一的细节，别撒别的。侧墙上挂一块"代客泊车"小牌（signBoard 底 signPaint 字，字高 ≥ 7 纹素，读不出就画钥匙图标）。

**valet-podium**——斜面木台（放钥匙本），顶上一块深蓝牌面；后面一把大遮阳伞（伞面 canvas + 蓝条，伞杆 ≥ 2 纹素 steel）。伞的投影罩住代客站的位置。

**bag-trolley**——酒店式行李推车的球场版：铜色弓形顶杆（≥ 2 纹素）+ 底板 + 2～3 个胖网球包（红、蓝、白，各 ≥ 6 纹素宽）。

**valet-sign**——小立牌（A 字或单杆），"代客泊车"或钥匙 + 车的图标。

**club-monument**——土坯底座 + 陶砖压顶 + 朝南的深蓝牌面，奶油金的徽标（网球 + 交叉球拍）和俱乐部名（字高 ≥ 7 纹素，最多 4～6 个字）。朝镜头：`lightUp` 0.5～0.65 + 低 `bands`，牌面落中档。它替大门那块看不见的招牌在画面里说"这是俱乐部"。

**car / suv（量最大的东西）**——Q 版胖车：车身一个圆角盒（下半宽、上半窄的座舱），**顶面是这辆车的颜色块**（车漆亮档），侧面中档，朝镜头的车头/车尾暗档；挡风玻璃斜着、映天（glass 亮档），侧窗中档；4 个胖轮子只露下半（≥ 3 纹素）。车灯 2 纹素（白/红），**不画**雨刮、门把、后视镜细节（≤ 1 纹素的东西 = 噪点）。v8：两边前门打开（门板 ≥ 2 纹素厚）。动的车要有朝向（`rotY`）和能换车漆（`variant` → `CAR_PAINTS`）；停着的同款用 `InstancedMesh`（每种车漆一组）。

**valet**——用 `buildPerson` 换 Look：v0 代客 = 深蓝帽（signBoard）+ 珊瑚红马甲（clothRed）罩白衬衫；v1 门童 = 白礼帽 + 俱乐部蓝外套（counter）。"一眼认得出"的两块色只有帽子和身子；不加白领口、袖口。手里：v0 一串钥匙（≥ 2 纹素的亮点），v1 空手（要挥手的姿势）。

**carport**——停车场的遮阳棚：两排粗钢柱（≥ 3 纹素，steel）+ 前后两根梁 + 一整块绷紧的帆布顶（北高南低，往南斜 0.4 米），2～3 条俱乐部蓝的宽条纹南北走（屏幕上是竖条），南沿一道 0.3 米垂边（朝镜头 = 暗档，蓝白跟着条纹）。帆布 `noShadowReceive`、**要投影**（投影带是构图的一部分）。和前台凉棚同一块布（俱乐部的识别色）。

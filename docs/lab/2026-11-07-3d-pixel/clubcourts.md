# clubcourts · 会员场 + 青训场小景（白模阶段）

俱乐部西边的三片硬地：北排两片青训场（`practice_w` (−17, 6)、`practice_e` (17, 6)，中间 1 米步道 x ±0.5），南排会员双打场（`outer_1` (−17, 25)）。
**竖屏 = 西边一竖条**：上面青训西场教练隔网喂球给一排孩子（家长在场边伞下看），下面会员场四个人网前截击（场边遮阳帆、喷雾、长椅、记分牌），最下面会员场南边敞开、沙吹上场，**总监拿吹叶机面朝镜头往南吹沙**。两张网（x −17）上下对齐成画面的竖中轴。
**横屏 = 三片场全在**：再加中间 1 米步道、东边青训场的发球机和少年（加球的活）、右下 clubclay 的红土远场。

### 每个资产的要点

**#1 hard-court（地形级）**——俱乐部的新漆场，不是 desert3d-v2 那片晒旧的：漆面只要低频深浅块（`EL.hard`），线 2 纹素按屏幕行取整。状态格每格 0.5 米，两种状态叠在漆面上：
- **积沙**（会员场南沿，没有围网的那边）：舌头形、边是弯的硬边，上面 1 纹素的风纹（窄长浅条），**盖在线上面**。API：`sand.at(x,z)`、`sand.blow(x, z, dirX, dirZ, r, amount)`（吹叶机：沿锥往前推，推出场外就没了）、`sand.drift(dt, wind)`（风从南边慢慢补回来，远小于吹的速度，lessons「组装经验」8）。可以直接参考 desert3d-v2 `court.userData.sand` 的接口（画法从零画）。
- **水洼**：一团扁椭圆 + 北半边一道窄的亮反光；**在线下面**（线透过水还看得见）。API：`wet(x, z, r)`（喷雾每秒在帆前 2～4 米加一点）、`squeegee(x, z, dirX, dirZ, width = 0.9)`（推走，推到场边绿上变小、到围网脚下没了）、`dryStep(dt)`（沙漠里干得快：一盘 ≈ 干一半）、`wettest()`。

**#6 ball-machine**——方方的机身（俱乐部蓝或青绿），前面一根出球管，顶上一个敞口的球斗（球堆冒尖 = 满，见底 = 快空），后面两个小轮 + 一根拉杆。`userData.setCount(0..80)`、`fire()`（出球管一缩、球从 `muzzle()` 出去）、`setOn(bool)`（侧面一个小灯）。v0 满、v1 快空（场景里用 v1）。

**#7 mist-line**——一根金属管挂在帆的前梁下，每 1.2 米一个喷头；雾 = 几片竖的半透明白色小平面（FX 图层，不投影、不描边），往南下飘、慢慢散。`setOn(bool)`、`setWind(vec2)`。白模里雾是挂着的灰锥（看起来像冰柱，不代表最终样子）。

**#8 court-sail**——绷紧的俱乐部遮阳帆（desert3d-v2 的 shade-sail 是断了一角的破帆，不合适）：方形帆往南斜下（后杆 3.3、前杆 2.6），奶白底 + 俱乐部蓝宽条（≥ 6 纹素）；四根绿漆钢杆，前梁同时挂喷雾管。帆面 `noShadowReceive`、要投影（帆影是会员场北走廊的深色底，水洼要放在帆影外面）。v0 / v1 条纹方向不同。

**#9 squeegee**——0.9 米宽的刮水板：橡胶条（深色）+ 刮头壳（俱乐部蓝）+ 1.5 米柄（≥ 2 纹素）。工具代理画，带**握点**（`userData.grip`：at、axis、at2，见 clubsite/people/hold.ts），人用 `push` 姿势推。

**#10 drill-kit**——训练小件，三种变体（锥 / 圈 / 地标点）。锥是橙色胖锥（≥ 3 纹素宽），在青蓝上是最跳的小颜色点之一；地标点是贴地的彩色圆片（孩子排队站的位置）。

**#11 tennis-ball**——同 pickleball 的做法放大到 ⌀ 0.2；建议照 `clubsite/assets/pickleball.ts` 的 InstancedMesh + `setBalls / remove / count` 做一个网球版（捡球、发球机共用）。

## 共享坐标的建议

1. **会员场南边不拉围网**（同 clubclay 的建议 2）。这里把它变成玩法：地图南边是沙地，风把沙从南边吹上场 → "吹沙"这件活的来源。
2. **会员场南边一条 1.4 米的碎花岗岩小路**（z 33.6…35.0，西接西步道，东到红土场西围网），工具架靠在它南边。地图上会员场南边直接是沙地，总监拿工具没有路。
3. **三个新门**，围着中间步道的南口：青训西场南门 x −3.5、青训东场南门 x 3.5、会员场北门 x −3.5（地图的门都在北边离西头 3 米，从会员场去青训场要绕整个西步道 + 长廊）。clubclay 画的青训场南围网没有门，两个场景在这里不一致，等定。
4. **两排场之间（z 14.3 / 16.7）仍是两道围网**（同 clubclay 远场北边的做法）：叠成一条暗带正好当竖屏的中框；中间的步道被挡住，走过去时相机跟人。
5. **青训两片场的分工和游戏反过来了**：游戏里西边发球机、东边教练；这里西边教练喂球、东边发球机 —— 竖屏只能放西边一竖条（东边一竖条下面是 clubclay 的红土），而教练 + 一排孩子是最强的主角。不想反就把竖屏换成"西场发球机 + 会员场"（构图不变，主角弱一些）。见问题 1。
6. 青训场里的东西（目标锥、地标点）是这一轮手摆的，地图上没有对应。

## 玩法计划（stage 3；这一轮只定数据，`layout.ts`）

- **能走的地方**（`WALKABLE`）：会员场北边场边（喷雾、水洼、长椅）、南边场外 + 南小路（积沙）；会员场双打线以内比赛时不让进；青训西场教练那半场（捡球），孩子那一块训练时不让进；青训东场；两排场之间的步道、中间步道、西步道、长廊。进出场只走门（建议 3）。
- **站位**（`SPOTS`）：`blowNow`、`toolRack`、`squeegee`、`puddle`、`picker`、`cartDump`、`coach`、`kidHit`、`queue`、`parents`、`members`、`machineE`、`hopperE`、`teen`、六个门。
- **路线**（`ROUTES`）：`blow`（沿会员场南边从东往西，人面朝南把沙吹回沙地）、`squeegee`（每团水洼往北推一趟，到场边绿、围网脚）、`collect`（西场教练那半场之字推捡球器，最后倒进球车）、`refill`（会员场 → 北门 → 两排场之间 → 青训东场南门 → 捡球篮 → 发球机）、`rotate`（孩子打完绕到队尾）。
- **总监的四件活和取舍**（玩法准则 2）：
  1. **吹沙**（现在在做）：拿吹叶机（`blow`，`setBlowSweep(false)` 玩家用朝向瞄准），格子里的沙往吹的方向推，推出南沿就没了，尘团用浅色（lessons 9）。比赛中吹 = 噪音和尘，会员满意度掉一点；等换边再吹 = 沙爬到双打走廊，滑倒风险。
  2. **刮水**：喷雾开着，帆前的水洼一直在长；刮掉要停在场边好几秒。不刮 = 网前的人打滑；关掉喷雾 = 等下一场的会员热、满意度掉。
  3. **捡球**：孩子打回来的球越来越多（每一球留在教练那半场）；教练的球车见底时训练停。捡（`push` 推捡球器）→ 倒进球车（`dump`）。
  4. **给发球机加球**：发球机见底就停（少年站着等）；从捡球篮倒进去（`pickup` → `pour` 或新姿势）。要穿过两排场之间的步道，离开会员场那边的时间最长。
- **自动的**：教练一遍 `feed` ≈ 1.6 秒，孩子轮换（打 3 球回队尾）；会员双打一分 ≈ 12 秒（截击多拍），每两局换边、翻记分牌、去水站；家长偶尔 `clap`、站着的那个拍照；等着的会员 `sip`。

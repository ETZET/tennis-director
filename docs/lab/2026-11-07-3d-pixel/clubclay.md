# clubclay · 红土场小景（白模阶段）

### 每个资产的要点

**#1 clay-court（主角，地形级的资产）**——一片场 = 底色 + 状态网格 + 胶带线 + 小记号，替换 `terrain.ts` 的 `paintClay`。
- **状态网格**（照 desert3d-v2 `court.userData.sand` 的做法）：每格 0.5 米，四个状态 `dust → brushed → (wet) → normal`，状态之间的边按纹素取整、硬边（最多 1 纹素棋盘过渡）。API（stage 3）：`at(x, z)`、`drag(x, z, dirX, dirZ, width)`（拖垫走过：dust → brushed，留下扫痕方向）、`sweepLine(segment)`（tapeDust → tape）、`water(x, z, r, amount)`（→ wet，边上一圈半干）、`dry(dt)`（wet 慢慢回 normal、normal 打久了回 dust）、`mark(x, z)`（球印）、`slide(x, z, dir)`、`dirtiest()`。
- **元素**：起尘 = 土团 + 脚印（成串的 3×2 纹素小椭圆，沿走过的路线）+ 滑步痕（底线附近、沿 z 的 1.2～1.5 米浅条）；拖平 = 一道道 **1 纹素、只深 8 的弧形扫痕**（拖垫转弯的地方是同心的弧，直道是平行的横线；按屏幕行取整）+ 每道拖垫边上一条翻起的浅土（2 屏幕行）；湿 = 大块深浅不匀 + 一两个小水洼（缝色）+ 边上一圈半干（clay 色，1～2 纹素宽的弯边）；正常 = 低频深浅块 + 很少的擦痕。
- **胶带线**：2 纹素宽（0.18 米），钉子不画；线和红土交界一行按屏幕行取整。盖了土的线（`tapeDust`）不是整条换色，而是一段一段的（拖垫拖过的那几道才糊）。线是强边缘大户（白 244 vs 红土 127）：只在竖的线（底线、发球线）上数，现在整帧 0.016，余量很大。
- **球印**：0.32 × 0.16 米的小椭圆（4 × 2 纹素），`clayWet` 的亮档 + 一侧 1 纹素亮边（被球蹭起的土），只在近场、只在落点区（底线附近、发球区）。**不要满场撒**。
- 不接收投影的毛边问题：场面是平的，正常接受投影。

**#2 court-net**——整洁的俱乐部网（desert3d-v2 的 `net` 是废弃场那张撕破的，不合适）：网身一条暗带（`net`）+ 顶上 2 纹素白网带 + 中间一根白色中心带 + 两根 3 纹素粗的网柱（`metal`，柱帽亮）。yaw 0 下网南北向、侧对镜头：屏幕上是一条竖的网带 + 两端网柱 —— 看得到的主要是网带顶面和网柱。**不画网格**。三片场（含会员场、青训场）共用。

**#3 court-umbrella**——方形或八角的市场伞：伞面往下斜（扁锥），4～8 片，俱乐部蓝 / 奶白相间的宽条（每条 ≥ 6 纹素）；伞沿一圈扇形垂边（深 ≥ 3 纹素）；木杆（3 纹素）插在一个胖的方底座里（底座落在长椅后面、贴着围网）。伞面 `noShadowReceive`、**要投影**（投影落在双打走廊上，是场边的深色底座）。三个变体：条纹方向 / 稍歪 / 一把收起一半（v2 可选）。伞顶压在暗带 2 上，是这一排最亮的东西。

**#7 hose-reel**——卷盘车：两个侧盘（`metal`，3 纹素厚）中间卷着一卷绿水管（`seat` 俱乐部绿，读成一个绿色圆柱）、一个推把；水管从卷盘拖出来，是一条 1.3 纹素宽的绿色管子贴在地上（按纹素取整、转弯平滑，`HOSE.pts`），尽头一个橙色喷头（`toolOrange`，≥ 3 纹素）。stage 3：水管跟着总监走（卷盘放线 / 收线，长度上限 18 米），喷水时喷头前一道水雾弧（fx）。

**#8 kit-bag**——球拍包：一个胖胖的长圆筒（≥ 4 纹素高），两色（俱乐部蓝 / 红 + 一条白带），横放在长椅边的地上。场边的小颜色点。

**#9 court-light**——灯杆：0.22 米方杆（2.5 纹素，`metal`）+ 顶上一个朝场地斜的灯箱（`metal` + 底面 `clothWhite` 亮）。地图上每片场四角都有（8.5 米）。竖屏里看不到，横屏里是几根竖线 + 长投影（8.8 米，细）：**投影会横穿场地**，要么接受（像日晷），要么灯杆不投影（建议不投影，投影是噪点）。所有球场场景共用。

## 玩法计划（stage 3；这一轮只定数据，`layout.ts`）

- **能走的地方**（`WALKABLE`）：远场围场里面、近场的场边那一条（z 34…37.1）、两排场之间的步道、东步道、墙里的沙地；减掉网、裁判椅、长椅、伞杆、水站、记分牌、卷盘。进出场只走门（远场东门 z 19.6、北门 x 3.5；近场东门 z 35.2）。**近场双打线以内比赛时不让进**（以后接满意度：闯进去 = 打断一分）。碰撞照 desert3d-v2 的 `control.ts`；相机跟着总监。
- **站位**（`SPOTS`）：`dragNow` 拖场、`hoseReel` 卷盘 / `tap` 龙头、`lineBrush`、`hoseNozzle`、`doorFarE` / `doorNearE` / `doorFarN`、`toolRack`（东步道外）、`umpire`、`benchW` / `benchE`、`water`、`spectators`、`scoreboard`、`server` / `netE` / `netW` / `returner`、`eastWalkS`。
- **路线**（`ROUTES`）：`drag`（拖场：东西来回，每道 2.4 米，西半场已做完）、`hose`（卷盘 → 湿区）、`lines`（扫线：东底线 → 发球线 → 中线 → 边线）、`tools`（卷盘 → 东门 → 工具架）、`change`（换边：网前绕过裁判椅）。
- **远场：维护（总监，玩家操控）**，顺序和取舍：
  1. **拖场**：在 `dragNow` 附近按"拿起"（`pickup` 姿势）→ 拉着拖垫走（`drag` 姿势，1.1 米/秒），走过的格子 dust → brushed，拖垫后沿扬一点土（fx 尘团用路的浅色，lessons「组装经验」9）。一片场拖完 ≈ 14 道 × 33 米 ≈ 7 分钟游戏时间 —— 演出里压成 ≈ 20 秒（只拖东半场剩下的 4 道，同 lessons「组装经验」8）。
  2. **扫线**：拿扫线刷推着沿线走（`push`），线一段一段从 tapeDust 变回 tape。不扫 = 线看不清，近场以后会出"压线争议"（玩法：满意度、裁判卡）。
  3. **浇水**：从卷盘拉水管（水管跟着人放线），按住 = 浇（`water` 姿势，喷头前一道水雾弧），格子 → wet；湿太多 = 开场延后（要等干），太少 = 起尘、打滑（玩法：球场状况）。
  - **取舍**（玩法准则 2）：总监在远场维护时，近场的水站空了没人换、换边时记分牌没人翻、观众的伞歪了没人扶；远场维护期间关场（不能排人）。
- **近场：比赛（自动）**：一分 ≈ 12～15 秒（发球 → 4～8 拍 → 得分 → 走回位置），击球按"拍面到达击球点 = 球到"倒推（desert3d-v2 的做法）；每次落地在 `mark()` 留一个球印（池子 40 个，旧的慢慢淡）。每两局换边：四个人走 `change` 路线、在长椅坐下（`sit`）、去水站接水（水位掉一档）、记分牌翻一张。观众：头跟着球转（只转头）、一分结束鼓掌两帧；站着的那个偶尔换脚。裁判：头跟球、报分时抬手。
- **场边设施**（总监能点 / 拿的）：水站换桶（同 clubdesk）、记分牌翻牌、伞（风大时收起 —— 接天气）。

## 要商量的（提给用户）

1. **两道围网 → 一道**、**贴南墙的场不拉南围网**、**东步道接到南墙**、**红土场的门开在东边**（见「共享坐标的建议」1～4）。都只在这个场景里做了，地图没改。
2. **红土的颜色**：这里的红土比地图的红一档（砖红偏橙 vs 橙）。要不要全图统一成这个？要不要再亮一点（见「白模的数字」最后一条）？
3. **竖屏只看得到东半场**：网在左边、东底线在右边，西边接球的人在画外（只有横屏里有）。如果想竖屏里看到两边对打，只能把镜头放到网正中（x 17），那两条底线都出画、发球的人看不到；现在的取舍是"东边发球 + 两个网前的人"。
4. **远场的状态是"一个时刻"**：现在摆的是"西半场拖完、扫完线、浇过水；东半场拖到第 4 道"。玩的时候顺序是玩家决定的（拖 → 扫线 → 浇水，或者反过来）—— 要不要规定顺序（比如先浇水再拖就白拖）？
5. **人要坐下**：裁判和观众要 `sit` 姿势，总监要 `drag`、`water` 两个新姿势 + `line-brush`、`hose` 两个新道具。这是人物 rig（desert3d-v2/assets/player/rig.ts）的活，归谁做？
6. **记分牌谁翻**：俱乐部里一般是球员换边时自己翻。现在的计划是换边时自动翻；要不要让总监去翻（又一个"离开维护"的理由）？
7. **伞的颜色**：用了俱乐部蓝条纹（和红土互补）。clubdesk 的凉棚也是这套蓝条纹 —— 俱乐部的"标准色"就定成这个？

# clubdesk · 露天前台（白模阶段）

俱乐部东墙大门里面的露天前台：会员从大门进来，沿石板引导道排队，到 L 形柜台的转角签到、从总监手里拿毛巾，路过自助水站接水，再沿小路去草坪和西边的球场。主角 = **凉棚 + 柜台 + 总监 + 排队的会员**；大门（内侧）在右边做竖的框。和门外的停车场场景（clubpark）以东墙大门为界，两个场景用同一套世界坐标（`apps/sandbox/src/clubmap2/layout.ts`，只读）。总监以后能操控（走、站到柜台后面接待、拿/用工具，同 desert3d-v2），这一轮只定构图、站位、路线和能走的范围。

- 页面：`http://[::1]:5190/clubdesk.html`（构图 + 占位）· 画廊：`clubdesk.html?asset=<id>`（同 clubfront：`&v=` 变体、`&ground=sand`、`&ref=0`、`&cy=`）
- URL：`px`（默认 1）、`zoom`、`tx`/`tz`、`sunel`/`sunaz`（默认 44° / 偏东 8°）、`pause=1`（时间停在 0，截图稳定）、`labels=0`、`ph=0`（不放占位）、`nav=0`、`clouds=0`、`edges=1`、`warm`、`seed`、`pal`（不带 = 6 午后金光；右上角切换；左上角像素级别）
- 标签：**深灰 = 占位（#编号 = 下面清单的编号）**，绿 = 已画的新资产，青 = 复用的资产，洋红 = 站位（圆盘）、路线（小点）、凉棚下总监的可见界线（一排小方点），半透明黑 = 区域名

## 相机和取景

- 正交、俯角 45°、yaw 0（看向北），默认像素 1×（0.045 米/纹素，素材按 0.09 米的设计纹素建模）。
- **竖屏 390×844**：`TARGET.portrait = (53.7, 6.0)` → 画面 x 44.9…62.5（17.6 米），右边缘刚好在门外 2.5 米；地面纵深 z −21…+33。
- **横屏 1280×720**：`TARGET.landscape = (46.5, 4.5)` → 画面 x 17.7…75.3，四边都是地面（不是浮空岛了，没有天空）：左边西边两片球场（硬地、红土）的东半，右边门外的落客区、花坛和停车场（clubpark 那块地）；前台落在右边三分之一线上；门外车道（两棵蒲葵夹着）从右边把视线引进门。
- 太阳 `SUN = { el: 44, az: 8 }`：画面后方、只偏东 8°，影子几乎正对镜头往下落。试了三个方位：偏东 22°（clubfront / clubpark 现在的）南门柱的影子斜着横在排队的人身上；偏西 24° 凉棚投影池把前两个会员和引导道压进影子、门柱影子落到 clubpark 的落客区；偏东 8° 凉棚投影正好是柜台转角和总监脚下的深色底座，排队的人站在亮着的石板道上，门柱影子顺着墙往南落，两边场景都不压。**clubpark 现在是 44° / 偏东 22°，两边要统一（建议都用 44° / 偏东 8°）。**

### 每个资产的要点

**#1 desk-canopy（主角上半）**——四根 0.3 米染色木柱（世界 x 52.6 / 56.2、z 2.5 / 9.0）+ 东西两根主梁 + 南北向的椽子，**椽子头伸出东西两边 0.3 米**（剪影读成凉棚而不是盒子）。帆布一整块绷在顶上，两道俱乐部蓝宽条纹东西走向（地图上的 z ±2，每道 1.1 米 ≈ 屏幕上 9 行），北、东、西三边 0.3 米扇形垂边（扇深 ≥ 3 纹素）。**南沿不挂垂边**（只留 1 纹素的卷边）：南沿底必须 ≥ 3.28 米，否则总监的帽子被挡（见上面的遮挡算式）。帆布 `noShadowReceive`、**要投影**（投影池是构图的一部分）。条纹边是这块唯一的强边缘。

**#2 desk-counter（主角下半）**——L 形包住凉棚东南角：东段朝东（朝大门，会员沿着它排队），南段朝南（朝镜头）。yaw 0 下东段的正面是侧对镜头的一条线，**只有南段的正面看得见**：俱乐部蓝竖板 + 底下一道深色踢脚 + 正中一个网球徽标（≥ 6 纹素的圆，`ball`，`lightUp` 让它落中档）。台面浅石面、前沿伸出 0.06（凸边亮线）。台面上：南段西头一叠白/蓝条纹毛巾，东段靠转角一个铜铃；总监站的位置（55.55, 8.6）前面空着。南段比 DESK 的南沿多伸出 0.4 米（z 9.7）。

**#3 back-cabinet**——在凉棚西边一排、1.5 米高，yaw 0 下几乎全被帆布挡住（只有南头 0.3 米露出来）。只做剪影和暗档；要不要留见「要商量的」。

**#4 towel-cart**——两层木推车 + 4 个胖轮子（≥ 3 纹素）+ 铜把手；每层一排卷毛巾，端头朝镜头（3 纹素的圆点，白和蓝交替）；顶上搭一条展开的条纹毛巾垂下来。在投影池里，总监从它东头拿毛巾（站位 `towels`）。

**#5 water-station**——木架 + 一只大圆水桶（`jug`，球面法线、亮顶）+ 铁龙头 + 一摞白杯子；朝东（对着小路）。一半在投影池里。桶里的水位以后要能变（空了要总监来换）：桶做成单独的网格。

## 玩法计划（stage 3；这一轮只定数据，`layout.ts`）

- **能走的地方**（`WALKABLE`）：到达小院、长廊、两段小路、墙里的沙地、三段台阶；减掉匹克球围场、柜台、后柜、毛巾车、水站、工具架、凉棚柱，**以及凉棚下 `HEAD_LINE_Z`（z 8.02）以北**——进去了帽子就被帆布挡住，看不见总监 = 不让进。柜台后那一条（x 52.9…55.9、z 8.02…9.1）从员工口（`staffGap`，柜台南段西头和毛巾车之间 0.9 米）进出。碰撞照 desert3d-v2 的 `control.ts`（轮廓 + 资产脚印）；相机跟着总监（play 模式）。
- **站位**（`SPOTS`）：`deskStand` (55.55, 8.6) 总监接待；`serve` (57.2, 8.85) 签到的会员；`queue1..3` 沿引导道往大门排；`gateIn` (59.0, 0.6) / `gateOut` (63.0, 0.4) 换场景（clubpark 那边的 `gateIn` 是 (58.6, 0)，交接点要对一下）；`towels` (54.4, 8.75) 总监拿毛巾；`water` (54.3, 10.6) 会员接水 / 总监换水桶；`toolRack` (58.3, 14.15)；`pathTop`、`lawnPath`、`exitWest` (37, 16) 会员出画。
- **一个会员（≈ 15 秒，演出要短，见 lessons「组装经验」8）**：从 clubpark 进门 → 走到队尾 → 前面的人签完，整队往前挪一位 → 到 `serve`，侧身朝总监。
  1. **签到**：总监站在 `deskStand` 0.8 米内 + 点会员（或点柜台）→ 1.5 秒（总监低头写、按一下铜铃，会员头上冒一个对勾）。总监不在 → 队伍越排越长，排到 4 个以上，队尾的人在门口跺脚（以后接满意度）。
  2. **毛巾**：总监转身走 1.2 米到毛巾车 → `pickup` 姿势（desert3d-v2 的）→ 手里换成毛巾道具（新道具 `towel`，一卷白蓝条纹）→ 回到转角 → 递过柜台（新姿势 `hand`，0.5 秒）。
  3. **水**：会员自己拐到水站接一杯（0.8 秒）。水桶每人掉一档，空了会员皱眉走过；总监从员工口出来，到水站换桶（水桶网格的水位复原）。
  4. 会员沿小路往下、往西出画。
- **工具**：门洞一直往里吹沙，积在到达小院北半（安静区就是扫的地方）；总监去工具架拿扫帚 / 吹叶机清掉（desert3d-v2 的扫地、吹沙做法）。草坪、匹克球场边的球用捡球器。
- **黑板**：点黑板看今天的场地分配（以后接游戏里的场地排班）；排队的人会扭头看它。
- **取舍**（玩法准则 2）：总监站在柜台就没法扫地、换水；离开柜台，队伍就开始排长。

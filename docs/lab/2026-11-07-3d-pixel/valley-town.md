## 画面的几条硬约束（决定了下面所有的摆法）

1. **只看得见朝南的立面。** 相机 yaw 0、俯 45°，朝东 / 朝西的墙是一条线。原来报社、体育店的店面都朝棕榈谷大道（朝东）—— 等于没有门脸。**三栋的正门一律朝南**，门前留一块院子（`SITES`），东西面只做伸出来的竖招牌（板面朝南）。
2. **挂在立面上的东西挡住它下面一截立面**：立面上 ya 高、出挑 a 米的板，在屏幕上盖住立面 ya − a … ya 那一段。拱廊顶（3.2 米、深 2.6 米）把门整个盖住 → 报社的门那一跨**不盖拱廊**，门两边才是拱廊 / 塔；体育店的雨棚 3.2 米高、只出挑 1.2 米 → 只挡 2.0…3.2，橱窗（0.45…2.0）露出来。
3. **竖屏只有 17.5 米宽**（390 px × 0.045 米/纹素），总监站在画面中线偏上；**右上角是小地图**（x ≥ 255 px、y ≤ 135 px），左上是两个按钮。高的地标要落在画面左上或中间：报社的塔放在**门西边**（第一版放东南角，太阳牌正好被小地图盖住），体育店的大网球放在**门正上方**。
4. **朝南的立面永远在暗档**（太阳在画面后方）。招牌上的"亮色"在暗档里会变成褐 / 靛（白模里黄字是褐的）：立面上的招牌、字、太阳牌要给 `lightUp` + 低 `bands`（资产代理的经验：0.5～0.65 / [−0.45, 0.3]），让它们落中档；夜里招牌字走 `signPaint` 的自发光（town.ts 第 9 节已有）。
5. **拉远看是屋顶。** zoom 0.15 的总览里屋顶占了楼的九成：报社 = 红瓦尖塔 + 锯齿顶（横条纹）；体育店 = 屋顶前沿一颗大网球；五金 = 一大块平顶（要有东西：空调、天窗排、屋面分格，否则是一块 1300 平米的空板）。

### 1. 《沙漠太阳报》—— 西班牙复兴式的两层报馆 + 锯齿顶印刷车间

## 调色板（新材质；关卡 2 落在 `src/valley/palette.ts`）

**落地（2026-11-16 核心）**：下表的材质都在 `palette.ts` 的 `TOWN` 里，除了：`parapetTeal` → 换成 **`hwMustard`**（芥末黄）+ **`hwNavy`**（深海军蓝），值见下面第二张表；`wallGreen`（对墙）跟着试拍角删了；加了 **`slate`**（人字小黑板的板面，同 clubdesk）。`palette.test.ts` 查色阶差、PROXY 不漏参数。

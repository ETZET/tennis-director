# clubhouse · 会所（外观 + 里面三层：B1 健身房 / 1F 商店 / 2F 会员，白模阶段 · 第二版）

地图西北角的会所：西班牙复兴式、红瓦、钟楼、拱廊。用户原话（2026-11-09）："会所外观：红瓦西班牙式，带钟楼和拱廊，在地图西北角。会所里面：会员休息、更衣、理疗、穿线台、专卖店、咖啡吧。会所先见个白膜就好。"
2026-11-10 用户补充："他是个2层建筑，里面有很多商店和utility"，另外要求**健身房放在负一层**。所以里面重做成三层（B1 负一层、1F 一层、2F 二层），见「三层的方案」。
这一版只做 pixel-scene 的 stage 1：手摆构图、调色板、占位（冷灰体块 + "#编号 名字"）、站位、导航、门、楼梯和电梯。会所的**壳**（墙、地、屋顶、露台、楼梯）用现成材质直接建，要单独画的东西（钟楼、门窗、家具……）是灰盒。**等用户看过白模、点头以后才画素材。**

**里面和外面在同一套世界坐标里**（会所的脚印内）。clubwalk 把场景连成一个大世界时，总监从门口走进去，会所切成"剖面 / 娃娃屋"：看哪一层，就把它上面的楼层和屋顶藏起来，朝镜头的墙和隔墙切到 1 米。走上楼梯或者坐电梯，剖面跟着换层。

## 三层的方案 · 第二版（2026-11-11）

用户看了第一版（11-10）的反馈："目前造的太小了，太杂"、"地下一层应该是一个很大很丰富的健身房"、"一楼是商店层，只有商店"。
这一版：**地上的脚印、四扇外门的位置、楼梯芯、钟楼电梯都不动**；房间少一半、每间大一倍；**1F 只有商店**；**B1 是一整层健身房**，比会所大（伸到北巷、西巷、拱廊前沙地下面）；二层盖到东翼上面（后厨）、露台盖住拱廊。
截图、平面图、单文件可玩页在 `shots/clubhouse/`（png / html 不进仓库，见那里的 README）。

## 外观 ↔ 里面（三层；clubwalk 的接口）

- **看法**（`view.ts`）：`'out'` 外观、`'b1'` / `'1f'` / `'2f'` 看某一层的剖面。每个网格 / 摆好的资产带 `userData.houseViews`（在哪几种看法里显示），`applyView(组, 看法)` 切 `visible`。规则 `viewsFor(层, mode)`：东西属于某一层（−1 / 1 / 2），`mode` = `'in'`（只在剖面）/ `'out'`（只在外观）/ 不给（都在）。
  - 外观：`mode ≠ 'in'` 且在地上（层 ≥ 1）。
  - 看第 f 层：这一层的东西 `mode ≠ 'out'`；**下面的地上楼层按外观画**（看二层时一层的外墙整高、拱廊的瓦、东翼的屋顶）；上面的都藏；看一层、二层时 B1 整个藏起来。
  - 钟楼的墙（`tower: true`）外观被钟楼占位盖住，只在剖面里出现（看二层时一层的钟楼墙按外观画）；钟楼占位、烟囱、二层的落地门是 `views: ['out']`。
  - 旧的 `userData.houseMode = 'in' | 'out'` 照样认（当一层的东西）。
- `terrain.ts`：`buildHouse(ctx)`（会所的壳，世界坐标）、**`setView(组, 看法)`**、`setInside(组, on, floor = 1)`（旧接口不变，多一个可选的层）。地面（`top:grounds`）在会所的 L 形脚印处挖洞，会所自己铺每间房的地。
- `scene.ts`（`HouseRegion`）：`setInside(on)`（不变，用当前的层）+ **`setFloor(-1|1|2)`**、`floor()`、`onFloor(fn)`；`nav()` 返回当前层的 `{ bounds, walkable, blocked, surface }`（**有 `surface`，不给 `ramps`**：楼梯段是按层的）；`attach(play)` 登记电梯。
- `nav.ts`：`houseNav(层)`、`houseBlocked(层)`（墙 + 这一层看得见的家具 + 栏板 + 电梯井）、`surfaceOn(层)`、`floorFor(当前层, y)`、`liftNext(层)`。
- **clubwalk**（`clubwalk/main.ts`）：区域的导航给了 `surface` 就用它建 oracle；总监在会所里时按脚下高度 `floorFor` 换层 → `setFloor` → 重建会所的 oracle 和挡路的、只重建会所那块世界网格（≈ 80 毫秒，换层时一下小卡顿）。进出门切剖面照旧。会所区域建一次 ≈ 420 毫秒（11-09 版的白模是 50～140 毫秒一档；三层的壳 + 186 件占位、42 个人）。
- **`world.ts` 的 `CLUBHOUSE_DOORS`、会所脚印、四扇门的位置都没改。**

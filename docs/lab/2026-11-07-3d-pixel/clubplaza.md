# clubplaza · 棕榈喷泉广场（喷泉小景，白模阶段）

俱乐部东北角的棕榈喷泉广场（地图 `PLAZA` x 32…56、z −36…−12，喷泉 `FOUNTAIN` (44, −24)）：抬高 1.2 米的石板广场，正中一座两层碗的西班牙殖民式喷泉，一圈暖橙色陶砖托着一池冷青色的水。会员在蒲葵荫里的长椅上歇脚、在饮料车买喝的，孩子趴在池沿玩水，几只大尾拟八哥落在池沿喝水；总监的保养活是**用长杆捞网捞池里的蒲葵叶**、扫陶砖上的落叶、给台阶顶的花盆浇水。主角 = **喷泉（冷水 + 白水花）**；四棵蒲葵围成朝南（朝镜头）开口的马蹄形做框。和南边的 clubdesk 接得上：广场抬高、挡土墙、两段台阶、绿带里的植物都照 clubdesk 的（只读 import 它的 `layout.ts`），两个场景用同一套世界坐标（`apps/sandbox/src/clubmap2/layout.ts`，只读）。

- **横屏 1280×720**：`TARGET.landscape = (44, −22.5)` → 画面 x 15.2…72.8：左边中心球场东看台 + 场地东头（邻居）、建议加的去看台小路；中间整个广场；右边东墙、门外北停车场一角、右下角大门（clubdesk 的 `east-gate`）。上沿是北围墙，下沿是匹克球和西边硬地场的北围网。

### 每个资产的要点

**#1 palm-fountain（主角）**——池壁外半径 4.6、内 4.0、高 0.6；压顶 0.62 宽、伸出 0.08（`cap`，上沿一条凸边亮线，坐得下人、站得下鸟）。**池壁朝镜头的外面一圈塔拉韦拉蓝釉花砖带**（0.3 高 ≈ 3 行，4×4 纹素的方砖，钴蓝底 + 奶白花，两种砖交替）：朝镜头的立面永远是暗档，花砖带就是让这条暗带不发黑、留住蓝的东西（池壁下半截是土坯 `adobe`）。中间：八角柱座（r 0.9 → 0.55，高 1.9）→ 下碗（r 1.4，厚 0.3，碗沿下一圈花砖）→ 细颈 → 上碗（r 0.72）→ 顶上一颗陶罐形的出水口（3.6 米）。碗是浅色石（`cap` 的亮档 / `flagstone`），比池壁亮，碗的上沿在暗底（池水的暗档、背后的蒲葵影子）前面要读得出来。**池水是这个资产的一部分**：`fountainWater` 一整块平面（亮档为主），池底透出一圈砖缝（`seam`，1 纹素），水面再交给 #2 动。池壁投影：太阳在后面 → 后沿的影子落在水面后 0.4 米、前沿的影子落在陶砖上 0.6 米（一圈新月形暗带，好看，留着）。

**#2 fountain-spray（水在动，要便宜）**——全部在 shader 和少量四边形里，不用粒子系统：
- 两层碗沿的**溢流帘**：开口圆筒（r 1.38 / 0.7），竖向 3 档条纹往下滚（每 0.15 秒挪 1 纹素），条纹之间留 1 纹素的空（看得到后面的柱），下沿一圈 `foam` 虚线。
- 顶上一股往上冒的水柱（0.8 米，3 档竖条，顶上一团 3×3 纹素的白）。
- 池壁里面四股往里的弧形小水柱（45° 方向）：每股 6 颗 2×2 纹素的水珠沿抛物线走（0.9 秒一圈），落点一圈 `foam` 涟漪（3 个半径，1 纹素线，1.2 秒一循环）。
- **闪光**：水面 shader 里按纹素中心 hash，亮档里约 1% 的纹素在 0.25～0.6 秒之间随机亮成 `hi`（亮边色），只在亮档出现（影子里的水不闪）。
- 风（`uWind`、`uGust`）大的时候水柱往下风歪 1～2 纹素、溢流帘下风一侧变宽。

**#3 grackle**——大尾拟八哥（棕榈泉的喷泉边最常见的鸟）：黑身子 + 蓝紫金属光泽（亮档才露出来）、黄眼睛、**和身子一样长的上翘尾巴**（剪影就靠尾巴读成鸟，不是一颗黑豆）。两个姿势：站着（尾巴翘）、低头喝水；飞的那只翅膀张开 8 纹素宽。黑鸟放在亮的池沿 / 陶砖上（不要放在影子里，会消失）。

**#4 palm-litter**——一片枯的蒲葵叶（扇面 + 长柄）+ 两三片碎叶，平贴地面 / 水面。颜色就是蒲葵枯叶裙的草秆色，在陶砖上要比陶砖亮（拉开亮度，lessons 第 5 条）。漂在水上的那片底下一圈 1 纹素的水纹。

**#5 skim-net**——长杆（金属漆 `metal`，≥ 2 纹素粗）+ 网圈（5 纹素宽的椭圆）+ 网兜（垂下 3 纹素）。挂在总监身上（同 desert3d-v2 捡球器的做法：`setProp('net')`），姿势负责摆放。

**#6 leaf-cart**——两轮保洁车：一只大落叶桶（`toolOrange`，和吹叶机同一个工具橙 → 一眼读成"总监的工具"）、车架和把手、桶边插着扫帚和耙子、挂一只浇水壶。总监的工具都在它身上（取放点 `leafCart`）。桶里的落叶会满（顶上冒出枯叶的草秆色）→ 要推去倒。

**#7 drinks-cart**——木车厢 + 两个轮子 + 一根伞杆 + 八角遮阳伞（珊瑚 / 奶油条纹 —— 暖色，和池水一冷一暖；不要用俱乐部蓝，免得和水抢冷色）。车上两只大玻璃饮料桶（洛神花红、柠檬水黄，`jug` 的球面法线 + 液体颜色），前面挂一块小招牌（`signBoard`）。摊主站在车后面（北边）面朝镜头。

**#8 sit 姿势**——player rig 加一个 `sit`（座面 0.45 米：大腿水平、小腿垂直、上身直或后靠、手放膝上；变体：一手拿杯子喝）。rig 在 desert3d-v2 里（这一轮不能改），建议复制到共享的人物模块，或由 desert3d-v2 的维护者加。

**#9 drink-fountain**——一根方柱（土坯或水泥）+ 顶上一只小水盘 + 金属出水嘴；朝西（对着步道）。打完球的人喝水；以后会堵（水盘积水变绿 → 总监来通）。

## 玩法计划（stage 3；这一轮只定数据，`layout.ts`）

**总监的保养活（主线）**：
1. **落叶**：蒲葵每隔一阵掉一片枯叶（阵风 `uGust` 高的时候掉，约每 40 秒一片），落在陶砖上（`litter` 地上）或水里（漂着，慢慢往下风的池沿漂）。水里的叶子 ≥ 3 片：水面变暗一点、闪光变少；≥ 5 片：长椅上的会员皱眉走掉、鸟不来。
2. **捞叶子**：点水里的叶子（或点保洁车再点水）→ 总监走到保洁车（`leafCart`）→ `pickup` 姿势换上捞网（`setProp('net')`）→ 走到离叶子最近的池边捞点（`skimE/S/W/N` 四个，池壁外 0.5 米、朝池心）→ 新姿势 `skim`（两手握杆、往回拖，1.2 秒一次；网圈在水面上划出一道 `foam` 弧）→ 叶子跟着网圈走，到池边收进网兜 → 回保洁车倒掉（`dump` 姿势，桶里的叶子 +1）。一片 ≈ 6 秒。
3. **扫陶砖**：地上的枯叶用扫帚（现成的 `broom` 道具 + `sweep` 姿势）扫到保洁车。
4. **浇花**：浇水壶（新道具 `can`，新姿势 `pour` 1 秒）给两段台阶顶的花盆浇水（`potE`、`potW`）；陶罐口里的土变深一档，龙舌兰过几天不浇会发黄（以后接满意度）。
5. **倒落叶桶**：桶满了（> 12 片）要推去长廊尽头倒（或者推出画面 = 去 clubdesk 那边的垃圾点），这段时间广场上没人管。
- **取舍**（玩法准则 2）：总监在这里捞叶子、浇花，前台的队伍就开始排长（clubdesk）；不来，水变脏、长椅上的人走掉。

**广场上的生活（不用操控，循环）**：
- 会员：从西台阶（`stairW`）或东台阶（`stairE`）上来 → 饮水点喝水 / 去饮料车买一杯 → 找有荫的长椅坐 20～40 秒（`sit`，偶尔举杯喝）→ 从另一段台阶下去去球场。荫里的长椅先坐满（影子池就是"会员爱待的地方"）。
- 孩子：在池沿前来回（`kid` 路线），每隔几秒 `pickup` 姿势伸手拨水，溅起一团 `foam`（3×3 纹素，0.4 秒）；家长站着看，偶尔走过去把孩子拉回来。
- 鸟：2～3 只在池沿后段、上碗沿走走停停、低头喝水（0.6 秒一次）、甩尾巴；总监或孩子走近 1.5 米 → 一起飞到最近那棵蒲葵上（1.2 秒的弧线），8～15 秒后一只一只飞回来。
- 饮料车：摊主倒饮料（1 秒），买的人拿着杯子走开；午后人多时排 2～3 个人。
- 水：一直在动（#2），风大时水柱歪。

**能走的地方**（`WALKABLE`）：广场顶面减掉池子（r < 4.6）和道具脚印（蒲葵树根 r 0.5、长椅、饮料车、保洁车、花盆、饮水点）；两段台阶下到绿带和长廊（往南出画 = 去 clubdesk）；建议加的西台阶（去看台）。碰撞照 desert3d-v2 的 `control.ts`；相机跟着总监。
**站位**（`SPOTS`）：`leafCart` 取放工具；`skimE/S/W/N` 捞叶子；`sweepE/W` 蒲葵下的落叶；`potE/W` 浇花；`stairW/E` 会员上下；`benchW/N`；`drinks`；`kid`；`birdRim`、`birdPerch`（鸟落脚 / 躲到蒲葵上）。
**路线**（`ROUTES`）：`member`（西台阶 → 西长椅）、`member-drinks`（东台阶 → 饮料车）、`kid`、`director-skim`（保洁车 → 池边一圈四个捞点）、`director-sweep`、`director-pots`。

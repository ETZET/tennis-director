# 会所里面 · 三层白模第二版（stage 1，2026-11-11）

用户反馈："目前造的太小了，太杂"、"地下一层应该是一个很大很丰富的健身房"、"一楼是商店层，只有商店"。
这一版：**1F 只有商店**（专卖店、穿线 · 试拍吧、咖啡吧、纪念品店、运动营养 · 饮品、便利店 + 商店街、楼梯、电梯、货梯厅）；**2F 会员层**（休息室 + 酒吧、露台、总监办公室 · 董事会、宴会厅、后厨）；**B1 一整层健身房**（714 m²，比会所大：伸到北巷、西巷和拱廊前沙地下面；更衣淋浴、理疗都在这层）。说明见 `../../clubhouse.md`「三层的方案 · 第二版」。

试玩：用浏览器打开同目录的 `clubhouse-inside.html`（右下角切 2F / 1F / B1 / 外观；拖动走路、点地面走过去；钟楼电梯、东翼货梯的门口按动作键换层）。

这个目录里的 png / html 没提交（refcheck 会误报，用户还没定）；只有这份 README 进仓库。

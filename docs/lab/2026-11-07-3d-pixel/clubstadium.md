## stage 3 · 演出 + 玩法（2026-11-09）

默认打开就是玩法模式：一场表演赛从进场到散场一圈一圈地循环（`life.ts`），总监交给玩家（`play.ts`，`clubsite/play` 接的）。
`?play=0` = stage 2 的静态画面（和 stage 2 的截图逐像素一样，画廊不变）；`?play=0&life=1` = 看戏模式（只看比赛，沙、伞、杯子自己好）。
新 URL：`games=<抢几局>`（默认 2）、`pre=<开场倒计时秒>`（默认 40）；玩法模式下标签默认关（`labels=1` 打开）。
钩子：`window.__stadium.life`（`state`、`debug()`、`skip('match' | 'changeover' | 'exit')` 截图用）、`window.__stadium.play`（`clubsite/play` 的测试接口）。

### 一圈（默认 ≈ 5 分钟）

| 段 | 演什么 | 总监能干什么 / 后果 |
|---|---|---|
| 开场前（40 秒，之后每场 50） | 看台按块从座位下面冒出来（`crowd.setFill`，一块一块进场）；一个找座位的人沿长廊 → 西头端梯 → 横走道 → 走道下去；卖水的在东边走道上上下下吆喝；球员、裁判、球童在拱门西边等 | 吹沙、补线、撑伞补水、收上一场的杯子。**倒计时到了任何一个沙堆 ≥ 55% → 推迟开场**：裁判"场边有沙，推迟开场"，每 6 秒看台三处"嘘—"、上座率掉 7%（等烦了的走了） |
| 出场（≈ 20 秒） | 球员从拱门走到球员席前站一下，裁判从北边梯子爬上椅子，球童分南北两队小跑到网柱旁（蹲）和四个底线角（站）；看台起立欢呼 → 鼓掌 | 场地还开着 |
| 比赛 | 单打、无占先、抢 2 局。击球不等球（同 clubclay：出手那一刻算好轨迹，挥拍按"拍面到达击球点 = 球到"倒推）；看台、球童、裁判的头跟着球；记分牌翻分；裁判举手报分（`call`）；球停了离得最近的球童跑去捡 | **场地关上**（`MATCH_RECT` 进不去，网两边过不去，贴着边走冒"比赛中，不能进场"）；场边那一条（南看台脚下、底线后）能走，三个沙堆都够得着。总监在场上时不开打：裁判"请离场"，等他出去 |
| 一分打完 | **全场鼓掌**：六成的人把手举过头顶拍（手在帽子上一开一合）、其余在胸前拍，拍的时候整个人颠、头和帽子左右抖（各 1 纹素）；赢球那边一半人站起来。好球（制胜分或 ≥ 6 拍）全场起立欢呼 | 底线磨淡（踩出来的）不补：长了的出界球落在断掉的那截线附近 → "压线了！" / 裁判"出界"、看台嘘、停 2.6 秒 |
| 换边（单数局后，13 秒） | 两人走到各自的球员席坐下（靠网那把椅子；靠外那把在大伞底下，45° 俯视里伞把人整个挡住）；一个球童撑伞站在旁边、另一个递毛巾；冰箱补过的喝水（`sip`）；**第一次换边看台起一圈人浪**（8 米/秒，北看台从西往东扫过去） | **场地放开**（能进场吹沙）。没撑伞 → "好晒…"，冰箱没补 → "冰箱是空的！"（`complaints`） |
| 散场（≈ 35 秒） | 全场起立；两人到网前握手、朝北看台举拍、从拱门走掉；裁判爬下来走掉；两个球童去收伞（伞合上、冰箱空了）；看台一块一块走空，**走空的那块座位前留下杯子**（每 7 个人一个，白 / 红两种） | 下一场来的人 = 1 − 0.45 × min(1, 杯子 / 40)（最少 45%） |

### 总监的活（`play.ts`）

- **吹叶机**（西南工具角的工具架上，"拿吹叶机" / "挂回去"）：按住动作键 —— 场边的沙堆旁 = "吹沙"（出风口 2.2 米内的沙堆变薄，0.9 → 0 约 3 秒，沙色小方块往前喷）；**看台上 = "吹杯子"**：上看台只有一条路（广告板挡住走道下口）：西头端梯 → 最高一级的横走道 → 四条走道往下；站在走道上，上下 1.7 米、沿 x 7.5 米以内的杯子往走道滑、到走道就收走（一团小尘 + "收了 N 个杯子"）。
- **划线车**（工具角）："拿起 划线车"（拿着吹叶机走过去 = "换划线车"，吹叶机顺手挂回架上）→ 推着走（1.5 米/秒，人物的推车握法）：出漆嘴走过的底线那几段变回新的白线。
- **球员席**（网两边）：空手"撑伞·补水"（2 秒）：大伞撑开、冰箱补满。
- 沙：开场前积得慢（0.004 × 阵风），比赛中风大（0.016 × 阵风）—— 一场打完三个沙堆都要再吹一遍。
- 底线：每 0.27 米一段，站在底线附近的人每秒磨 0.012、发球脚下 0.04；断掉的段 = 一块和内场同色的小片盖住线（每段的阈值随机，越磨越断）。开局两条底线中间那段已经磨得断断续续（49% 完好）。
- 顶栏：比赛（倒计时 / 推迟 / 比分 / 换边 / 散场）、沙（最厚的那堆，≥ 55% 标"挡开场"）、底线、伞·水、杯子、观众。

7. 东看台背后去喷泉广场的台阶（`EAST_STAIRS`）这一版不能走 —— 等 clubwalk 把场景连起来。
8. 总监在看台横走道上会从坐着的观众前面穿过（观众不挡路）。

- **视线**：长廊上的会员 → 西南角的总监（橙色吹叶机是画面下半最暖的一点）→ 球员 A → 球 → 网顶 → 裁判椅 → 看台中间那块 → 记分牌。一条从左下往上、往中间收的 S 线。
- **框**：上面记分牌 + 后墙、两边看台的空座位、下面南看台背墙 + 青训围网两条暗带。
- **明暗横带怎么不变成噪点**（这个场景的关键）：
  1. 立面不接收投影 → 每条立面是干净的一整条暗档；踏面接收投影 → 每级的影子袋也是整条的。横带的明暗来自几何，不来自颜色。
  2. 观众只用 5 种衣服色（白 / 奶油 / 俱乐部蓝 / 红 / 黄，**不用青绿 = 总监、不用紫**），白和奶油占 7 成；六成的人戴帽子（草帽 / 白帽两种浅色）→ 45° 俯视里帽子就是头，每排人读成一条浅色的点子带。
  3. 人按 2～4 个一组坐（组之间空位），一组人一半同色 → 是"一小团一小团"的人，不是逐个随机的彩色碎点。
  4. 空位成片（看台两头、最上面一两排）露出深青绿座椅 = 看台上安静的地方。走道（`aisle`，比看台亮一档的冷灰白）竖着切开横带，看台读成"几块"。
  5. 观众身子矮（上身 0.42 + 大头 0.34）：画面里主要是头和肩，一人约 9 × 13 纹素（1× 下）。
- **安静的地方**（别往里加东西）：场地的蓝内场和绿外圈、看台两头的空座、墙外沙漠、长廊、青训场面。
- **云影**只走墙外沙漠（z −46）和长廊 / 青训场（z −1）两条带，永远不上场地和看台（人群上的云影 = 一大块脏灰）。

### 每个资产的要点

**#1 stadium-stands（色块白模已经在 terrain.ts 里，资产阶段换掉）**——尺寸照 clubmap2/build.ts（北 6 级 × 0.9 × 1.2、东 3 级 × 0.8 × 1.2、南 2 级 × 0.6 × 1.1）。**构图靠的是：立面 `noShadowReceive`（干净暗带）、踏面接收投影（影子袋）**，这两条资产阶段必须保持。立面的浇筑缝 1 纹素、每级一道；座椅画成一个个塑料座（6 纹素宽，影子里深青绿、前沿一行亮边），不要做成几百个网格（一条座椅条 + 元素图案）。北看台四条走道每级两步（0.45），走道两侧一道 2 纹素的扶手（`metal`，可选）。广告板：俱乐部名 + 网球徽标（`ball`），朝镜头用 `lightUp` 落中档、留住蓝。后墙白灰泥 + 陶砖压顶（和会所一家）。东看台背后一段上看台的台阶（`EAST_STAIRS`），西头一道端梯。

**#2 crowd（便宜！）**——占位版已经是可用的数据结构（`placeholders.ts` 的 `seats()` / `buildCrowd`）：每种颜色一个 `InstancedMesh`（衣服 5 + 皮肤 3 + 帽子 2 = 10 次 draw call），一人 = 上身 + 大腿（衣服色一个几何体）+ 头 + 六成戴帽子。资产阶段：头换球面法线、帽檐一纹素亮边、上身加两条胳膊（同一个几何体）。**不加阴影投射**（几百个小影子 = 噪点），不接收投影。动画全在顶点着色器里（`aInst` 相位）：鼓掌（胳膊上下 1 纹素，0.3 秒）、站起来欢呼（整个人 y + 0.35，0.6 秒）、人浪（按 x 延迟的站起来）、转头跟球（头左右 1 纹素）。`userData`：`setFill(blockIdx, 0..1)`（进场 / 散场）、`cheer(x, strength)`、`wave(dir)`、`lookAt(x)`。

**#3 stadium-scoreboard**——深色牌面（朝镜头 = 暗档，`slate` 正好），顶上一条俱乐部蓝名牌；两行比分（球员名 = 3 个色块、局分 3 格），数字是亮黄的点阵（3×5 纹素，`emissive` 一点，影子里也亮）。`userData.setScore(sets, games, points)`；换分时数字翻一下（0.2 秒）。两根腿落到看台后面的地上（≥ 4 纹素粗）。

**#4 player-bench**——两把带靠背的椅子 + 中间一只冰箱（饮料）+ 椅背搭一条毛巾；v0 / v1 冰箱一蓝一红，区分两个球员。换边时球员坐下（`sit`），球童撑伞。

**#7 umpire / 球童 / 观众的姿势**（人物代理，`src/clubsite/people/`）：裁判 `sit`（手放膝上、偶尔举手报分）；球童：统一的一套（白帽 + 俱乐部蓝 Polo + 白短裤），`crouch`（网柱旁蹲着、双手扶膝）、`stand-back`（底线角站着、手背在身后）、`roll`（把球滚给球童）。白模里球童 = 球员缩到 0.74。

**#8 sand-drift**——状态网格（同 desert3d-v2 的沙堆）：`userData.amount` 0..1，吹叶机对着吹时按距离往下风减；风大时（`uGust`）三个角慢慢积回来（速度远小于吹的速度，lessons「组装经验」8）。

**#9 line-marker**——划线车（白漆桶 + 两轮 + 滚轮 + 推把）。**握点**（grip）：推把横杆中点，本地 (0, 0.88, −0.7)，朝 −z；总监用 `push` 姿势推（desert3d-v2 的捡球器姿势），后面在地上留下一条 2 纹素的白线（线的磨损状态归场地资产 / terrain 的线图层）。

**#10 players-gate**——两根白灰泥门柱（1.0 见方 3.2 米）+ 顺着 z 的门楣 + 红瓦小坡顶；门楣南头一块俱乐部蓝的牌子（"CENTRE COURT"，不写真字，画 3～4 条粗划）。yaw 0 下侧对镜头：一根竖着的门楣 + 两根柱的南面，横屏左边的竖框。

## 玩法计划（stage 3；这一轮只定数据，`layout.ts`）

**总监的保养活**（工具都在西南工具角）：
1. **吹沙**：风从西头敞口灌进来，沙积在三处（`sandSW` 南看台脚下、`sandNW`、`sandNE` 两个角；阵风大时慢慢变厚）。点沙堆 → 总监去工具架拿吹叶机（`pickup`）→ 走到沙堆下风一侧（`blowSW`）→ `blow`，沙往西吹出敞口，露出下面的绿（desert3d-v2 的做法）。沙堆厚到盖住线 → 比赛不能开始（裁判不上椅子）。
2. **补线**：底线 / 边线按比赛的跑动磨淡（场地资产的线图层，按段记磨损）。点淡了的线 → 推划线车（`lineCart`，`push` 姿势）沿线走一遍（`lineW0 → lineW1`），身后的线变回亮白。
3. **收拾看台**（散场后）：看台上留下杯子、节目单（`crowd` 资产散场时撒的小白点，每块看台一个计数）；总监拿吹叶机 / 扫帚沿走道从上往下清；不清 → 下一场进场的人少（以后接满意度）。
4. **开场前**：把两把遮阳伞撑开、冰箱补水（点长椅）。
- **取舍**（玩法准则 2）：比赛中总监不能进场（网两边不能过、场地上只有换边的 90 秒能吹沙）；开场前沙没吹完 → 推迟开场，看台上的人开始嘘、陆续走。

**比赛和看台的生活（不用操控，循环 ≈ 60 秒一幕）**：
1. **进场**：观众从长廊西南角 / 东边小路进来，沿端梯和走道找座（`setFill` 按块从 0 涨到目标）；卖水的在走道上上下。
2. **球员出场**：从会所露台经拱门走到长椅（`players-walkout`），放包、喝水；球童就位；裁判爬梯子上椅子。
3. **对打**：一分 ≈ 6～10 秒（desert3d-v2 的击球演出，打到边线外的球球童跑去捡、滚给网柱旁的球童）；每分结束看台鼓掌（`cheer`），好球全场站起来；记分牌翻分。

## 退化成色块的

睡莲叶、台阶、房子石墙/门/门前石板、石板路（尤其阴影里）、崖壁、灌木、阴影里的草地、栈桥上的木箱。

共同原因：**一整片朝同一方向的平面**，光照只给它一个颜色；复刻只在上面画了深色线，于是变成"一块颜色 + 几条线"。好的物件之所以好，是因为它们的明暗变化不全靠法线。

## 规范（每个材质都要满足）

1. **元素**：每种表面先定它由什么"元素"组成——石块、木板、叶团、草叶、冰块、切面。元素有形状和尺寸（一般 4～12 纹素），不是逐纹素的随机点。
2. **元素自己的深浅**：同一档光照里，元素之间要有 2～3 个颜色（本档色、高一级、低一级），按元素随机取，整块元素同一个颜色。一块亮着的平面里至少能数出 3 个颜色。
3. **元素的亮边和暗边**：朝光那一侧（俯视 45° 下通常是元素的上沿）1 纹素亮一级；背光一侧或缝是 1 纹素暗色。
4. **阴影里纹理还在**：进阴影 = 整套颜色换成暗档那一套（元素色、亮边、缝都换），元素和缝照样清楚。不能进了阴影就只剩一个颜色或一片渐变。
5. **线都是 1 纹素、按纹素/屏幕行取整**；元素噪声按纹素中心取，不逐像素抖动。
6. **调色板按材质给 3 档 × 3 色**：每档（亮/中/暗）一个本色、一个高一级、一个低一级，外加缝色、亮边色。暗档色相偏冷，不是亮档乘系数。
7. **自检**：参考和复刻同一块裁出来 3× 并排；数亮区颜色数（≥ 3）；看阴影里元素是否还在；看每个元素有没有亮边。
8. **按物件量明暗分档，不凭印象**（第四轮加）：每个物件、每块大区域在参考和复刻上各框一个框，量平均亮度和暗（L < 120）/中（< 170）/亮三档占比，差 ±10 以内才算对。"颜色对了"不等于"明暗对了"：灌木的颜色一直是从参考图取的，但亮档占 57%（参考 23%）。
9. **矮墙不挂缕**（第四轮加）：只有屏幕上露出 ≥ 20 行的墙（池塘那圈 2 米）挂长苔藓缕和中间苔藓带；露出 9～18 行的台地墙是实心靛色石墙 + 草沿（亮边 1 行、深绿线 1 行、短须 1～2 行）。在矮墙上挂缕，45° 下就是一排梳齿。
10. **细节密度按斑块变**（第四轮加）：草叶、短划这类"撒"的细节，密度要在 3 米左右的斑块之间从 ≈ 1% 变到 25～30%；处处一样密就是一层噪点（边缘密度超标的主要来源）。

### 共用机制（`ramp.ts`，所有材质一套）

- **调色板 `Tones`**：`bands[档] = [本色, 高一级, 低一级]` × 3 档 + `seam[档]` + `hi[档]`，进 shader 是 `uTone[9] / uSeam[3] / uHi[3]`。材质不给就由 `autoTones(ramp, alt)` 推：高一级 = 往上一档挪 30%（亮档往白 12%），低一级 = 往下一档挪 30%（暗档往"× (0.78, 0.8, 0.92)"的冷暗），缝 = alt[0]，亮边 = 往上一档挪 55%。
- **元素 = `vec2(id, 是否缝)`**，`elemCol(cur, up, band)`：缝 → `uSeam[band]`；屏幕上一个纹素是缝或别的元素 → `uHi[band]`；否则 `toneOf(band, id)` 按 `toneW`（默认 28% 高一级、24% 低一级、其余本色）挑。
- **元素坐标一律是屏幕纹素（y 朝上）**：地面用 `sc = floor((x, (y − z)·0.70711) / 纹素 + 0.5)`（跟世界锚定，上一个纹素就是 `sc + (0, 1)`）；竖直墙用 uv（米）换算 `(uv.x, uv.y·0.70711) / 纹素`，上一个纹素用 `e + dFdy(e)`（斜放的房子、弯的崖壁都对）。`voroEl(p, cell, seam)` 是带缝的 Voronoi 元素。
- **阴影保留纹理（规范第 4 条的真正病根是云影）**：原来云影是在所有细节画完以后 `mix(col, 暗档本色, cs)`，路、草、台阶进云影就成了一片渐变。现在云影在细节**之前**算：`cs + 抖动(±0.15) > 0.6` 直接把 band 换成 0（整套换暗档、细节照画）；边上一圈按 3 级量化，用"本档本色 → 暗档本色"的**比例**压暗（`col × 暗/本`，纹理跟着压）。

### 规范里要改的

1. 第 4 条「阴影里纹理还在」最大的来源是**云影**，不是太阳投影：投影本来就是先换档再画细节，云影却是最后整片混色。云影必须在细节之前换档。
2. 第 3 条「元素的亮边」不能每个元素都画：墙、灌木上每个元素都有亮边时，45° 下全变成横线。亮边只画在**缝的下面**（墙）或少数元素上（灌木 15%）；崖壁基本不画。
3. 第 5 条「线按纹素」对竖直面要明确：竖直 1 米 = 0.707 / 纹素 **屏幕行**；原来崖壁按 uv/纹素，石块在屏幕上被压成 0.7 倍、苔藓带不到一行。
4. 台阶：45° 俯视时踏面只露 1～2 行，立面露 2～3 行 —— 规范只写了踏面分段不够，立面也要分段、取暗档三色。
5. 睡莲：参考图的亮边是**一整圈**（下沿也亮），暗的是亮边下面那一行厚度；不是"下沿一圈暗边"。
6. 灌木格子"约 2"可行，但要配"少量亮边"；只换小格子不加元素色的话灌木还是一块平涂（灌木大部分在亮档，档位交界穿不过去）。
7. 描边 pass 会盖掉细纹理：台阶 edge 0.6 时 70% 的像素被凸边/深度边改色，降到 0.2。

## 沙漠移植（phase A，2026-11-08）：把这套元素机制搬到 desert3d-v2 的大面积表面

desert3d-v2 被评为"大块平涂"：每个调色板条目只有三档光照色，表面没有元素。机制搬进了 `src/desert3d-v2/toon.ts`（还是 MeshToonMaterial 的 onBeforeCompile，贴图/顶点色/实例/蒙皮照旧；给了 `elem` 的材质才编进元素库），API 和每个 kind 的参数写在 `src/desert3d-v2/ASSETS.md` 开头「材质规范 v2」。

### 和池塘版的区别

- 元素坐标用 `mat3(viewMatrix) * 世界坐标 / 纹素`（任意 yaw/俯角都是屏幕纹素），取整用 `floor(x + 0.25)`：沙漠的低分辨率目标宽高奇偶不定，片元中心落在整数或半整数上，池塘的 `+0.5` 在半整数时会来回跳。
- 调色板顺序跟 desert 的 palette 一样是 [亮, 中, 暗]；`tn(亮, 中, 暗, 缝, 亮边)`。
- 云影是贴图阈值（强度 0.25），改成按"本档本色 → 低一档本色"的比例压：平涂材质结果和以前一模一样，有元素的材质纹理跟着压。**（第二轮换成了手摆的硬边云，见下面「第二轮」）**
- 元素图案取风摆**之前**的位置（树冠摆的时候叶团不在叶子上游）；`space: 'local'` 以物件原点为锚。
- 矮墙规则靠几何体的 `aElem.x`（`wallGeo` 的第 6 个参数按墙外 0.35 米处的地面高度算露出多少米）。

### 每块表面

| 表面 | 元素 | 做法 |
|---|---|---|
| 沙（台面、低地、地上的沙斑） | `ripples` | 本色为主；低频深沙斑（约 12% 面积）= 矮沙丘朝镜头的背风坡，**上沿 1 纹素丘顶亮边**（断续七成）；浅沙斑；沙纹 = 一行暗划（缝色）+ 上一行短一点的亮划，每 4 行一行候选、按 13 纹素分段，整片一起 ±1 行起伏（连起来是平行的弯线），段的密度按 3.5 米斑块 1.5% → 42%；碎石 2 暗 + 1 亮 |
| 崖壁 | `strata` | （第二轮改了石块的深浅和竖缝，见下）一层 4～6 行（每层随机），层界沿墙 ±1 行起伏；每层里石块宽 12～26 纹素、四成五有竖缝；整层偏一个深浅（沉积的带）+ 两成五石块自己挑；层缝一行（两成断开），**亮边只在层缝下面那行**（45%）；墙顶第一行是唇下暗线；≥ 18 行的高墙（岛外沿、东台）成簇淌 1～3 行沙；< 9 行的矮墙（池壁 0.7 米、西台对球场 1 米）= 实心一条 |
| 步道 | `pebbles` | 有机形状的土团（fbm 两道阈值，块约 10×6 纹素）、少数斑块里有龟裂（Voronoi 缝）、成对的 2×1 脚印、嵌着的碎石 |
| 台阶 | `treads` | 池塘 `KIND_STAIRS` 原样搬：每级踏面分几段石条（6～14 纹素）、前沿磨亮条（越往下越多）、前后两行高一级、立面顶上一行暗线；**踏面本色从 #fae8c4 降到 #e8d0a8**，不然磨亮条（#fffcf2）在近白的踏面上看不见；竖缝只留 55%（全画像木板）；描边 edge 0.5 → 0.18、convex 1 → 0.25 |
| 球场漆面 | `paint` | （晒白块第二轮改成硬边两色，见下）有机形状的深浅块（差 6 个亮度，内场 26×15 纹素），≤ 3% 的擦痕；Voronoi 块是直边多边形，看着像低多边形的切面，换成 fbm。白线、裂缝不加元素。晒白块边缘多一层高频噪声（缺口），上沿一行 `courtWorn`（漆边的影子）、下沿外一行 `courtLip`（漆边迎光的亮唇） |
| 场上积沙 | `drift` | 迎风坡（法线朝西北）上有沙纹；背风脚下一圈暗边（CPU 每次重建高度场时把"南边或东边已经没沙"的格子写进 alphaTex 的 b 通道），扫、吹、风积以后跟着变 |
| 绿洲池 | `water` + `dash` | 水面换成盖住包围盒的格子（池外部分被地面/池壁挡住），顶点带"往北到岸、到岸"的距离：横向拉长的斑块、北岸脚下天光带、中间深水；泡沫圈是虚线，空隙用水的亮边色（白泡沫对水差 80 个亮度，对亮边色只差 45 → 不算强边缘） |

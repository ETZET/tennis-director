# 场景物理：走路和开车（2026-11-12）

只动 `apps/sandbox`。三块：走路的腿（所有场景共用的 rig）、clubpark 的车、clubpark 的人走路。
验证靠无画面探针（Node / vitest，替身物件，不要渲染器），固化成测试；浏览器里只看了静帧（headless，软件渲染，帧率不算数）。

## 走路的腿（`clubsite/people/rig/rig.ts`）

- **原来：** 腿绕髋按正弦摆 ±0.55 弧度，踝离髋 0.44 米，一个周期身子只该走 4 × 0.44 × sin 0.55 ≈ 0.92 米，
  各场景却按 1.25 米推 phase → 着地脚往后溜 36%；髋按固定正弦起伏、鞋跟着腿一起歪 → 脚离地 / 扎地。
- **现在（`walkLegs`、`strideAmp`、`levelShoe`）：** 着地的半个周期脚相对髋匀速往后（= 身子的速度），另半个周期缓进缓出摆回去
  （比着地脚慢半拍 → 离地一点，从不低于地面）；髋高度按着地那条腿算（倒摆）；鞋绕腿轴上的踝点反着转、保持水平。
- **步幅：** `WALK_STRIDE`（≈ 0.92）是默认；`strideOf(obj)` = 这个人一个周期实际走多远（孩子的腿短，`userData.strideK`）；
  走得快的给 `userData.stride`（`setStride(obj, stride)`），腿摆大一点：总监小跑 1.3、clubpark 代客跑着去车位 1.55。
  各场景的走路函数（clay / desk / courts / stadium / plaza / food / pickle / park、`clubsite/play/control.ts`）都按它推 phase。
- **画面变化：** 同样的速度，人每秒多迈约 35% 的步（腿长决定的）。
- **测试：** `clubsite/people/rig/walk.test.ts` —— 真的 rig 摆过一个周期，着地脚前后溜 < 每帧位移的 5%，鞋底高度 ±2 毫米，摆腿的脚不低于地面。

## clubpark 的车（`clubpark/life.ts`、`clubpark/assets/vehicle/build.ts`）

| 量（12 分钟） | 原来 | 现在 |
|---|---|---|
| 最大横向加速度 v·ω | 29 m/s²（> 4 的帧 2211） | 2.9 m/s² |
| 后轴横向滑动 | 最大 14.5 m/s（> 0.2 的帧 8376） | 最大 0.25 m/s |
| 开着的车压进别的车 | 345 帧，最深 1.84 米 | 0 |
| 一帧的加速度尖峰 | 542 m/s² | 30 m/s² |
| 车流（送走的会员） | 7 | 6（30 分钟 13） |

- **运动学自行车模型（`drive`、`stepPose`、`leaderPath`）：** 作者画的还是车中心的路；前进时前轴沿路走、后轴被拖着（拖车曲线），
  倒车时后轴沿路走、车头每米最多转 0.6 弧度。每段路从车现在真正的位置起（差的那点前几米里并过去），到段尾那一帧就结束。
- **过弯限速：** 按曲率（横向加速度 ≤ 2.2 m/s²），从段尾往回推减速。
- **避让（`sweep`、`wouldHit`）：** 沿路往前把整个车身的矩形一步步摆过去（和真开时同一个模型），按离障碍多远限速；
  硬约束：这一步会压得更深就不走。车和车按矩形比（分离轴），人、推车是圆。删掉了"无视别的车 2 秒"（`ghost`）。
  两车顶牛 1.2 秒，该让的那辆（`yieldsTo`）直着往后退 3.5 米、等 2.5 秒。
- **交通规则：** 一条通道同时只有一辆在开的车（`askAisle` 排号，等的车停在车道上、车位里）；落客点一次一辆（`askBay`，后面的在 x 84 东边等）；
  从进出口开上车道先等车道上的车过去（`mouthGate`）。
- **三点掉头（`turnBack`）：** 车道 8 米宽，U 形掉头掉不过来（原来的 `UTURN` 实际半径 1.2 米）。现在沿西行车道往东倒、车尾甩进进出口
  （去南停车场 / 出画倒进北口，去北停车场倒进南口），再往前开过车道。
- **倒车入位：** 按后轴画四分之一圆弧（半径 = 到车位中线的距离）；进通道的拐角改成直角 + 5 米直道。
- **车身（`carMotion` → 车的 `setMotion`）：** 从位姿差分出前轮转角和纵向 / 横向加速度：前轮两个转向节打方向（±37°）；
  车身挂在弹簧上（1.3 Hz、阻尼 0.45），刹车点头、起步抬头、转弯往外倾。
- **保险：** 被一辆停着的车真卡死 20 秒就放行并 `console.warn`（探针里从没触发）。

## clubpark 的人（`life.ts` 的 `walk`）

- 加减速（2.5 / 2.2 m/s²）；身子朝哪走哪，转身每秒最多 7 弧度（拐角走成小圆弧）；中间的拐点离 0.3 米就换下一个、不停帧。
- 过马路先看车（开过来的车 1.2 秒内要经过面前就等）；停在路上的车从旁边绕；车等一个人超过 2.5 秒，那个人往旁边让。
- 离终点还远时前面的人往旁边让、贴到 0.5 米以内往外挪。
- 代客去落客的车门口从车头前面绕（原来的路线从车头里穿过去）。
- 探针（12 分钟）：一帧起步 / 一帧停 300 / 269 → 7 / 0；人和人 < 0.45 米的帧 357 → 28。

## 没做的

- 别的场景的走路逻辑（匀速、拐点停一帧、人穿人）：把 clubpark 的 `walk` 收进 `clubsite/people` 给各场景用。
- 打球时的移动（面朝球网横着走，播的是往前走的腿）：要加侧滑步 / 跑 / 后退的姿势。
- 坐下 / 站起来的瞬移、`face()` 最后一下跳过去、台阶当斜坡、总监没有加减速。
- 排队时落客的车在车道上等，自己停车的车会被它挡在后面（同一条车道）；玩法模式里总监拿着钥匙不挂，代客就不去取车（落客点被占着）。
- 真机上的观感（车身点头 / 侧倾的幅度、前轮转角在 1× 像素下看不看得出）没看过。

# clubpickle · 匹克球场小景（白模阶段）

前台西边的匹克球围场（`PICKLE` x 36…52、z −3…15，两片场 `pickle_1` / `pickle_2`，网都在 x 44、南北走向）。主角 = **2 号场的双打**（四个人都压在厨房线上轻吊 dink —— 匹克球最有辨识度的一幕）+ **两片场中间那条场边生活带**（挂拍排队的拍架、长椅 + 遮阳伞下的观众、翻牌记分牌、水站、器材箱）。1 号场这一轮停用：网松了，**总监在南网柱边摇绞盘重新绷网**，场上散着一地球（下一个活：推捡球器捡球）。和 clubdesk（东边的露天前台）用同一套世界坐标和同一份地面几何：clubdesk 横屏左边画着的就是这个围场，两边一模一样（同一个 fence-screen、同一套场面色、同样的步道和草坪）。

- 页面：`http://[::1]:5190/clubpickle.html`（构图 + 占位）· 画廊：`clubpickle.html?asset=<id>`（同 clubdesk：`&v=` 变体、`&ground=sand`、`&ref=0`、`&cy=`）

## 相机和取景

- 正交、俯角 45°、yaw 0（看向北），默认像素 1×（0.045 米/纹素，素材按 0.09 米的设计纹素建模）。太阳 `{ el: 44, az: 8 }`（同 clubpark / clubdesk）。
- **竖屏 390×844**：`TARGET.portrait = (43.6, 6.5)` → 画面 x 34.8…52.4（17.6 米）：左边露出南北步道 x 34…36（西门外）、右边刚好到东围网外 0.4 米（到达小院的陶砖边）。上沿 z ≈ −19（广场 +1.2；喷泉在画外 —— 试过 tz 4.8，喷泉的粗占位圆盘从上沿露出来，抢眼，没用）；下沿 z ≈ 33（草坪）。围场从北围网顶到南围网脚占画面高的 38%，中心比画面中心高 1 米。
- **横屏 1280×720**：`TARGET.landscape = (42.5, 5.6)` → 画面 x 13.7…71.3：围场在正中偏右一点；左边练习硬地场的东半（网在 x 17，红土场的东北角在左下），右边三分之一是前台、大门和门外的落客区（clubdesk 的那一套，原样复用）。
- 网是南北走向的：yaw 0 下**网面侧对镜头**，屏幕上只是一条 2～3 纹素的竖线 + 两根网柱。所以网两边的深色厨房带是让"这是匹克球场、网在这里"读出来的主要手段；网松了也只能靠网身往东鼓出来（x 方向的位移）才看得见（见 #1）。

### 每个资产的要点

**#1 pickle-net（两张，1 号场松 v1 / 2 号场紧 v0）**——匹克球网：网柱 0.914（36 英寸）、中间 0.86（34 英寸），柱在边线外 0.3（两柱中心距 6.7）。yaw 0 下网面侧对镜头，屏幕上是：一条 **2～3 纹素宽的竖线**（网带 `netTape` 的顶面亮、网身 `net` 暗靛压在它下面一纹素）+ 两根胖网柱（0.2 见方，柱帽亮一行）+ 网的投影（偏西一纹素）。网带的 x 厚度给到 0.18～0.27 米，否则在 1× 下断成点。**中心带**：网正中一条竖的白带（netTape，宽 2 纹素）下到地面一个小扣 —— 屏幕上是竖线中段一个亮点，匹克球网的记号。**南柱上的绞盘**：3×3 纹素的方块 + 往东伸出一根 2 纹素的摇把（总监摇的就是它）。**v1 松的网**：网身中段往东鼓出 0.25 米（侧对镜头时只有 x 方向的位移看得见；y 方向的下垂在屏幕上和 z 叠在一起、看不出来），中心带的扣脱开、白带拖在地上；网带一头从柱顶滑下来半截。stage 3 绷网时 v1 → v0 插值（`userData.setTension(0..1)`）。

**#2 paddle-rack（挂拍排队）**——匹克球场特有的排队方式：来的人把拍子插进门口的架子，按顺序上场。两根木立柱 + 一块开 6 个槽的横板 + 底座，横板上沿一行亮边。槽里竖着插拍子，**拍面朝镜头、柄朝下**，每把一个颜色（`paddle` 珊瑚、黄、俱乐部蓝、橙、紫、白），排成一排彩色小方块 —— 场边带最艳的一处，饱和度靠它。插满 4 把、空 2 个槽（排队的长度看得见）。顶上可以有一块小黑板条（`slate`，不写真字）。`userData.setCount(n)` 0..6，从左往右插。

**#3 shade-umbrella（两把）**——方形配重底座（`concrete`）+ 细杆（≥ 2 纹素，`metal`）+ 八角伞面：8 片 `canvas` 奶白 / `canvasStripe` 俱乐部蓝相间（和前台凉棚同一家），每片三角形是一个平面（多切面 → `convex` ≤ 0.3），伞缘一圈 2 纹素的扇形垂边，顶上一个小尖。**伞往北（朝太阳）斜 9°**：影子往回收，落在长椅和观众身上，少落到 2 号场上（不斜时影子中心在 z 7.6，正好压在 2 号场北边的球员脚下）。伞面 `noShadowReceive`、要投影。v1 = 伞面转半片（两把不一模一样）。

**#4 flip-scoreboard（翻牌记分牌）**——两条金属腿 + 一块深青黑的板（`slate`）+ 木顶条，板上三张奶白翻牌（`signPaint`），**三个数字**（匹克球双打报分是三个数：发球方得分 - 接发球方得分 - 第几发球员，例如 4-2-1），数字是 3×5 纹素的粗笔画；第三张小一点。翻牌挂在顶条的铜环上（`brass` 1 纹素）。朝南（2 号场的人看）。stage 3：翻牌绕上沿转半圈（0.3 秒）。

**#5 gear-box（器材箱）**——俱乐部蓝的竖板箱（`counter`，和前台柜台同一家：这是前台的东西），盖子掀开 30°，里面露出一卷备用网（`net` 暗卷 + `netTape` 白边）、绞盘摇把（`metal`）、一根捡球管的头。箱前角一个铜扣。总监在这里拿 / 还工具（`SPOTS.gearBox`）。

**#6 pickleball**——穿孔塑料球。真球 0.074 米在 0.09 米/纹素下不到一个纹素，照网球的做法放大到 0.18（2 纹素），亮档是画面里最亮的点之一；顶上一个 1 纹素的暗点（孔）—— 近看才看得出来，远看就是亮黄点。多数 `ball` 黄绿，少数 `toolOrange` 橙（户外球常见两色，也和网球分开）。散的球用一个 InstancedMesh（`userData.setBalls(points)`、`remove(i)`），不接投影。

**#7 paddle（球拍道具）**——实心的圆角矩形拍面（不画网线：和网球拍一眼分开）+ 短木柄。人物骨骼归 desert3d-v2 管：要在 `player/rig.ts` 的 `Look.hold` 加 `kind: 'paddle'`，`setProp('paddle')`；球员变体的拍面颜色按 OUTFITS 的 `frame` 换成 `paddle` / `flowerYellow` / `counter` / `toolOrange`。

**#8 新姿势**——`sit`（坐在长椅上：大腿水平、小腿垂直，脚跟着地；观众要它，现在白模里观众站在长椅前面）、`crank`（总监半蹲、右手在柱边画圈，0.6 秒一圈）、`dink`（低重心、拍面朝上轻推，正手 / 反手各一，0.5 秒；比 forehand 幅度小一半）。

## 玩法计划（stage 3；这一轮只定数据，`layout.ts`）

- **能走的地方**（`WALKABLE`）：围场里面（1 号场整片、场边带减家具的脚印、2 号场 z ≤ 12.8；网和网柱钻不过去），围场外的长廊、南北步道、去草坪的小路、到达小院。进出：西门（3 米），以后加东北员工小门（提议 2）。有人打球时走进 2 号场 = 干扰（玩法上记一次打断）。碰撞照 desert3d-v2 的 `control.ts`（轮廓 + 资产脚印）。
- **站位**（`SPOTS`）：`netCrank1` (43.55, 5.45) / `netCrank2` (43.55, 6.55) 两片场的绞盘（都在场边带上，背对背）；`basket` 捡球篮；`gearBox` 器材箱；`water` 水站；`rackDrop` 拍架；`scoreFlip` 记分牌；`doorOut` / `doorIn` 西门外 / 里；`serviceGate`（提议）；`sweepStart` 1 号场捡球起点。
- **双打对攻（≈ 6～8 秒一分，循环）**：发球（下手，`serve` 改小）→ 四个人上到厨房线 → 4～8 拍 dink（球的弧顶 1.1 米，每拍 0.9 秒，落点在对面厨房里）→ 一个人突然抽一拍（forehand）→ 球出界、滚到围网边 → 最近的观众扔回来。**打完一分**：发球方的人走到记分牌翻一张（0.3 秒），头上冒三个数的漫画字（"4-2-1"）。小彩蛋：有人踩进厨房截击 → 冒一个"厨房！"的字，算违例。
- **挂拍排队**：从南北步道来的人进西门 → 在拍架前弯腰插拍子（`pickup`，拍架 `setCount +1`）→ 站在旁边聊天。2 号场打完一局（演示里每 3 分），两个人拿起自己的拍子去水站接水、走南边小路回前台；拍架最左边两把被拿走，那两个人上场。
- **观众**：`sit` 坐在伞下的长椅上，头跟着球转（±25°），一分打完拍手。
- **总监的活**（这一轮的静态摆位 = A）：
  - **A 绷网**：去器材箱拿摇把（`pickup`）→ 到 1 号场南网柱 → `crank` 4 秒，网从 v1 插值到 v0（鼓出去的网身收回、中心带扣上）。1 号场停用期间排队变长（拍架插满 6 把以后新来的人站在门口跺脚）—— 绷好网，拍架上的两个人去 1 号场。
  - **B 捡球**：拿捡球器（desert3d-v2 的 `picker`，`push` 姿势已有）在 1 号场来回三趟（`ROUTES.director-sweep`），笼子经过 0.4 米内的球就收进去（`setCount +1`、球的实例删掉），最后到捡球篮 `dump`。
  - **C 换水**：水站空了（每个人接一杯掉一档），从前台拿桶来换（clubdesk 的 `water-station` 已有 `setLevel` / `jug`）。
- **点选**（手机）：点网柱 = 绷网，点散落的球 = 捡球模式，点水站 = 换水，点记分牌 = 清零；总监要先走到 0.8 米内。
- **取舍**（玩法准则 2）：总监在这里绷网、捡球的时候，前台没人签到（clubdesk 的队伍越排越长）；不绷网，1 号场一直停着，拍架上的人等不到场。

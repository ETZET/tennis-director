# clubgolf · 南墙外的沙漠高尔夫（白模阶段）

地图上的高尔夫（`GOLF` x −64…92、z 53…74，`GOLF_POND` (−30, 66) 7.5 × 4.5）一直只是景观：clubmap2 的一条弯弯的球道 + 三块果岭 + 水塘。
这一版做 stage 1：**一条 156 × 21 米的细长地块里，只在水塘边做一个洞当主画面 —— 第 7 洞，三杆洞，过水**（发球台在东、果岭在西、水塘在中间），
两头用低成本的球道条带延伸到地块的两头。沙漠高尔夫的样子：**修剪整齐的绿草是"岛"，岛与岛之间是沙漠砂石地（碎花岗岩）+ 红岩 + 仙人球**；
沿南墙一排蒲葵和一条球车道。总监从**西步道南头新开的南墙门**出来就是球车道。

- 页面：`http://127.0.0.1:<端口>/clubgolf.html`（构图 + 占位）· 画廊：`clubgolf.html?asset=<id>`（`&v=` 变体、`&ground=lawn|sand|gravel|green`、`&ref=0`、`&cy=`）
- URL：`px`（默认 1）、`zoom`、`tx`/`tz`、`sunel`/`sunaz`（默认 44° / 偏东 8°）、`pause=1`、`labels=0`、`ph=0`（不放占位）、**`accent=2`（颜色白模：占位换成计划的主体材质）**、`nav=0`、`clouds=0`、`edges=1`、`warm`、`seed`、`pal`（不带 = 6 午后金光）
- 标签：**深灰 = 占位（#编号 = 下面清单的编号）**，青 = 复用的资产，洋红 = 站位（圆盘）、路线（小点）、建议的门洞（一圈小方点），橙 = 共享坐标的建议，半透明黑 = 区域名

## 相机和取景

- 正交、俯角 45°、yaw 0（看向北），默认像素 1×（0.045 米/纹素，素材按 0.09 米的设计纹素建模）。
- **竖屏 390×844**：`TARGET.portrait = (−40, 69)` → 画面 x −48.8…−31.2（17.6 米宽）、地面 z ≈ 42…96。
- **横屏 1280×720**：`TARGET.landscape = (−26.7, 63.6)` → 画面 x −55.5…2.1、地面 z ≈ 41…87：整个第 7 洞。
- 太阳 `SUN = { el: 44, az: 8 }`（同其他小景）。影子往南（朝镜头）略偏西，长 ≈ 1.04 × 高。**墙边的棕榈（8 米）影子落到 z ≈ 62**：
  所以棕榈只放在 x −57.4、−32.6、−21、−1.8（影子落在水塘北岸、两个岛之间的砂石地、发球岛东边），**不放在果岭（x −46…−39）和发球台（x −13…−7）的正北**；

### 每个资产的要点

**#1 flagstick（主角的点睛）**——旗杆是画面里最细的竖线，按规则 2 纹素粗；旗面朝东飘（风从西来，和 clubsite 的风向一致），红旗在果岭亮绿上最跳。脚下的洞杯 = 一个暗圈（地面里画也行）。userData（stage 3）：`setPulled(on)`（扶旗的人拔起来拿着）、`setWind(k)`。

**#2 golf-cart**——奶白车身 + 俱乐部绿的帆布顶（`seat` 绿，和看台座椅一个绿），从侧面（yaw 0 下车身沿 x）一眼认出：四个小轮、平顶、车尾立着两只球包。
朝镜头的车身侧面在暗档 → `lightUp` + 低 `bands`（clubdesk 柜台的做法），顶是亮档（主色放在顶上）。人坐上去：座面 0.62（`setSeat(0.62, 0.22)`）。
userData：`seats`（司机 / 乘客的本地坐标）、`setBags(n)`、`drive(speed)`（轮子转）。

**#3 golf-bag**——斜靠在两条支腿上的圆筒，顶上露出三四个杆头（`metal` 亮档的小块）。包身两种颜色（变体）。

**#4 tee-markers**——两个大球（⌀ 0.26）标出发球区前沿；东头一根洗球器（2 纹素杆 + 一个小箱）；西头一块洞号牌（三个点 = 三杆洞），图标不写字。

**#6 golf-gate（入口）**——东门柱照墙上原有的壁柱（1.1 见方、2.4 高、压顶）；西门柱就是原来的壁柱 x −39.2（不新画）。门楣是一根铁梁（2 纹素）+ 正中一块小牌（旗子图标）。
两扇铁门往外（往南）开、平时开着；门扇竖条要稀（规则：网用暗带表示，不画几十条 1 纹素的细杆）。

**#7 ducks / #8 roadrunner**——生活：鸭子在水面慢慢漂（`update` 里绕圈），走鹃在砂石地里一阵小跑、停、再跑（演出）。都很小，先定"一眼认出"的两块色（鸭：白身 + 绿头；走鹃：棕斑身 + 长尾）。

### 人物要加的（给人物代理）

- 姿势：`golfSwing`（站位 → 上杆 → 击球 → 收杆；击球那一帧杆头在球上，不停顿）、`putt`（弯腰、双手握推杆、钟摆）、`tendPin`（扶着旗杆站在洞边）、`searchBall`（弯腰拿杆拨草丛）、`rake`（耙沙坑，两手握长柄来回）。
  现在用 `serve`（挥杆）、`idle`（推杆、扶旗）、`pickup`（找球）代，手里用 `hold()` 挂一根占位球杆。
- 道具：`golf-club`、`putter`（hold）、球包背在肩上（`carryBag`）。
- 衣服：打高尔夫的会员可以复用 player 的四套（球员的白 / 红 / 蓝 polo 就像），加一顶遮阳帽（visor）就够分开"打网球的"和"打高尔夫的"。

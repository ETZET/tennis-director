# 0011 经营循环 v2：季节、日程公告板、动作圈、精力

- 状态：已采纳
- 日期：2026-10-31

## 背景

第一轮试玩评审后，负责人给了三条新的玩法准则（CLAUDE.md 第 4–6 条）：事件是偶发而有分量的；日常经营靠和界面互动；
玩家不操作时会所基本不变，但模拟、天气、季节和画面一直在动。v1 的循环是"卡片流水线"：每天几张卡，经营几乎全靠回应卡，
不回应时数值也在漂。负责人还定下：第一幕六周（夏末到初秋）；每季有日程安排、偶尔有事件；点了之后总监跑过去做一个动画，
跑多快看当天的效率（季初跑得冒烟，精力低了慢慢走）；界面以手机竖屏为主，排日程用拖动。

## 决定

- **季节和天气**（`act.seasons`、`act.weather`）：季节按天切换；每天的天气按季节权重从种子随机数里抽。雨天关掉没有
  `rain_ok` 的设施（室外场地和它们的收入）。条件里可以用 `weather`、`season`、`weekday`。
- **总监精力**（0–100，`act.energy`）：速度系数 = slow…fast 之间按精力插值，走路和干活的时间都除以它。过夜 +6，换季回满。
- **现场动作**（`data/actions/*.yaml`）：挂在地点上，有花费、精力、工时、冷却、一次性、成功率和效果。选了以后总监先走过去，
  到了开始干活时才扣钱和精力；还在路上时点了别处就作废；干活中不能走开。动作只是"内容"，新加一个不用改代码。
- **日程公告板**：`plan[时段][星期]`，时段是上午 9 点、下午 3 点、晚上 6 点。活动带 `program: {parts, requires}` 才能上板。
  每季开头弹出公告板、时间停住，改动免费；锁定后季中再改每次花 4 点精力，当天的活动重排。`planPreview` 在克隆的状态上
  算出"每周会怎样"（现金、会员、质量会稳定在多少、课时、匹克球压力、哪些格子因为设施没修好而排不上）。
- **不操作时不漂**：会员和声望的自然变化只在每周日结算一次；导演抽卡的间隔是 2 天加抖动，同时最多一张，暂停卡开着时不抽新卡。
- **界面（手机优先）**：公告板是整屏软木板，便条用 Pointer Events 拖进 7×3 的格子；点地点牌弹出动作圈，选中的动作在屏幕
  底部（拇指区）显示全部代价和"去做"；事件卡加了"谁来找你"、处境标签和每个选项的代价标签（由内容里的效果生成，文案不写数字）。
  公告板或动作圈开着时时间停住。
- **存档**：`SAVE_VERSION = 2`，旧档迁移时补上精力、计划、季节和天气。

## 后果

- 卡从"主要玩法"变成"偶发事件"；内容里的卡少了九张，多了 16 个现场动作和 8 个日程活动。
- 机器人要会排日程和做动作（`planCommands`、`pickerBot` 的 `act` 选项）；平衡区间（贪心 70–95%、随机 3–25%）不变，
  见 `docs/balance/hollow-creek.md`。
- 默认日程下质量稳定在 23 左右，这是故意的：不主动修场地、排课，会所不会自己变好。
- 试玩桥加了 `/plan`、`/lock`、`/tap`、`/act`，默认手机视口 390×844。

# 0021 地图跟着选路长出去：★3 收回高尔夫西段，★4 岛在东南角长出去

- 状态：提议
- 日期：2026-11-03
- 修订：[0005](0005-scenes-are-islands.md)（浮空岛是一块方形地台）、[0018](0018-palm-oasis-map.md)（高尔夫只是景观）
- 补充：[0016](0016-single-map-site.md)（整局一张地图）、[0020](0020-progression-structure.md)（★3、★4 的选路卡）
- 依据：`docs/design/research-map-growth.md`；预览见 `docs/archive/pre-3d/v0.5-preview-deck.pdf` 的"地图"一节

## 背景

用户觉得现在的小地图（围墙内 124 × 95 米，开局就定死）太局限，限制了多样性。第一版扩建的样稿在 ★3 往岛边贴三块空地，用常驻的"地块 A"牌子加列表买地，★4 再往里复制现有的球场和泳池。用户说它显得很随意。研究把原因归成：没有伏笔和来历；没接上现有的路；是商店，不是事件；是"更多同样的东西"。另外按投影，那三块地都让竖屏画面变宽，而竖屏最缺的就是宽度。

## 决定（提议）

规则和初值见设计文档"地图怎么长大"。

- **地从岛上本来就有的地方来。**
  - ★2 不加地。
  - ★3 收回南墙外高尔夫的西段：这块地本来就在地台里，岛的轮廓不改。
  - ★4 岛第一次长出去，长在东南角，因为那里在竖屏上只加高度、不加宽度：赛事广场（车位挪到新长出的地上），或者学院岛（天上的小岛靠岸，搭一座桥）。
- **伏笔从 ★0 起就在画面里。** 西步道断头处砌死的南门；一周比一周荒的高尔夫西段；东南天上带两根旧网柱的小岛。
- **开地 = 选路卡 + 3–5 张清理工单 + 启用。** 不加卡，不加买地牌，不加列表（准则 1、4、5）。
- **种子只在手画的地块变体里挑。** 结构层在模拟里、写进存档；外观层在 iso 里，每块地用自己的随机流。各变体的步行分钟差在 ±10% 以内。
- **地台是一个会长大的轮廓。** "基础地台 + 已启用的地"合并后画侧面，土层按高度对齐，切角只留在外角。
- **导航只加不挪。** 新地接在现有步道的断头上；只加锚点和导航边，不移动现有锚点。

## 后果

- **iso：** `createIsoWorld` 的 `slab` 从一个矩形变成几块拼出的轮廓（或多边形）；`IsoView` 的地台侧面按合并后的整体画；地面贴图的范围跟着变。要同时更新 `docs/design/iso-architecture.md`。Palm Oasis 的 `ground.ts`、`build.ts` 加新地的画面层，新东西加在构建顺序的最后，或者用单独的随机流，原来那座岛的像素不变。
- **Site 接口：** 锚点、站位、步道要能按"哪些地已经启用"增减；游戏照旧只通过 `Site` 拿地图（ADR 0016）。
- **模拟和内容：** 地块状态（未开、施工、启用）和变体写进状态和存档；地块的清理工单和启用后的岗位；`nav` 分钟数按新步道重新生成，`game.test.ts` 照旧检查；内容编译时把每块地的每个变体走一遍（走得到、分钟数对得上、路不断在岛边）。
- **界面：** 选路卡上的半透明预览和"镜头先转过去"；HUD 上的"回到会所"按钮；拿着人拖到屏幕边自动平移。
- **平衡：** 南门离大门约 98 分钟，是平均的两倍多；南场选项要先用机器人算。
- **以后：** 现在能扩的地太小（★3 只有高尔夫西段，★4 只有东南一角）。以后加大：整片高尔夫、西北角、更多卫星岛、第二季的大块地，还是按"竖屏只加高度"来排。

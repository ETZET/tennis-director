# 0005 每个场景是一座孤岛

- 状态：已采纳
- 日期：2026-10-30

## 背景

原型的地面是一整片 460×460 的草地，伸到画面外，看不出俱乐部在哪里结束。设计上想要一种与世隔绝的感觉：玩家的世界就是这家俱乐部，边界清楚，外面没有可去的地方。

## 决定

- 场景的可玩区域做成一座岛：海岸线（`onIsland` / `coastDistance`）、分层的海岸悬崖、四周的海，远处的海面靠雾融进天色。
- 海岸线由圆角矩形加确定性的正弦起伏构成，不消耗随机数；测试保证台地、场地四角和所有命名锚点都在岛上。
- 离岛只有一条路：Hollow Creek 东侧公路沿堤道向南伸进雾里，车从这里开走。
- 原型的场景构建照常运行，只是体素批处理器在海岸线外不放盒子（随机数照样消耗，岛上细节不变）；岛屿本身用单独的随机流。
- 相机最远可以拉到 0.32，看见整座岛；起始视角不变。
- 之后迁移的 Maple Ridge、Palm Oasis 用同样的方式做成岛。

## 后果

- 画面与原型不再相同。M0-2 的原型对比结论停在提交 498030d（四个角度差异像素 0.0000%）；之后的画面回归以 `tools/screenshot/baselines` 为准。
- 场景的边界同时就是导航和放置的边界，M1 的导航图和锚点只需要在岛内定义。

# 0005 每个场景是一座浮空岛

- 状态：已采纳（2026-10-30 修订：从海上孤岛改为浮空岛，依据设计稿「Floating island」）
- 日期：2026-10-30

## 背景

原型的地面是一整片 460×460 的草地，伸到画面外，看不出俱乐部在哪里结束。设计上想要一种与世隔绝的感觉：玩家的世界就是这家俱乐部，边界清楚，外面没有可去的地方。

第一版做成了海上的孤岛（海岸悬崖、海、东侧堤道）。之后设计稿 *Tennis Director · Design Options* 的「Floating island」一页定下了浮空岛：俱乐部是一块悬在天上的土台，边外什么都没有。

## 决定

- 可玩区域是一块方形土台，笔直的硬边、四角切角（`ISLAND`、`onIsland`、`coastDistance`）。边外只有天空。
- 岛底剖面是画面的一部分（`UNDERSIDE`）：草皮唇边、两层土、从土层垂下的根须，下面的岩层逐层往里收成钝底。剖面单独一个批次，带一点自发光，背光面也看得出土是棕的、石头是灰的。
- 天空（`ambient/sky.ts`）：平涂的方块云在岛的四周和下方漂，几块长草的小土块浮在岛边轻轻上下晃。
- 小溪两头在岛边前用矮石岸截住，不往外流；岛边不出现任何瀑布（试过，显得多余）。下雨按设计稿 Day · Rain：天色变成石板灰，云变灰，雨一直落到岛底下。
- 东侧公路在岛的南边缘断开。车开到路的尽头缩小消失。
- 天色按设计稿：多云的下午 `#a3bac8`，下雨 `#728694`。
- 原型的场景构建照常运行，只是体素批处理器在岛外不放盒子（随机数照样消耗，岛上细节不变）；岛屿和天空各用单独的随机流，天空不碰 `Math.random`。
- 相机最远可以拉到 0.26，看见整座岛和岛底；起始视角不变。
- 之后迁移的 Maple Ridge、Palm Oasis 按设计稿做：Maple Ridge 用一座小桥接在学校旁边，Palm Oasis 是一座精致的岛，带几座卫星小岛（学院、匹克球）。

## 暂不做

设计稿的「时间 × 天气」矩阵（黎明 / 白天 / 黄昏 / 夜晚 × 晴 / 多云 / 雨 / 大风 / 酷热）需要一个由模拟驱动的时间和天气系统，放到 M1 以后。现在只做了演示剧情用到的两种：多云的下午和下雨。

## 后果

- 画面与原型不再相同。M0-2 的原型对比结论停在提交 498030d（四个角度差异像素 0.0000%）；之后的画面回归以 `tools/screenshot/baselines` 为准。
- 场景的边界同时就是导航和放置的边界，M1 的导航图和锚点只需要在岛内定义。

## 修订（2026-11-03，ADR 0019）

画面换成 2.5D 等距像素后，浮空岛保留，画法换了：岛是一块像素地台（`createIsoWorld` 的 `slab`，Indian Wells 是 `site/indian-wells/ground.ts` 的 `SLAB`），
地面贴图只覆盖地台，地台侧面由 `IsoView` 画成土层，外面是背景的荒原和群山。`ISLAND`、`onIsland`、`UNDERSIDE`、`ambient/sky.ts` 随 `packages/render` 删掉；
云、鸟、风滚草在 `site/<地图>/sky.ts`。动画库的小岛（`activities/diorama.ts`）是同样的小地台。上面关于 Hollow Creek 小溪、东侧公路、相机 0.26 的条目只是历史。

## 修订（2026-11-08，ADR 0027）

不再是浮空岛：3D 像素场景的地面铺出画面，地图边是低成本的山（ADR 0027）。原来的修订提议 0021（地图长大）随 2.5D 主线作废，2026-11-12 删除。

# 0018 地图照参考图重排成 Palm Oasis Racquet Club

- 状态：已采纳
- 日期：2026-11-02
- 修订：[0016](0016-single-map-site.md)（整局一张地图）的布局和画面；[0015](0015-jobs-unlock-from-repairs.md) 的设施不变

## 背景

用户给了一张参考图（Palm Oasis Racquet Club，Indian Wells, CA）：一块围墙围起来的俱乐部，
北边中心球场、西北会所和露台、西边泳池、中间两排球场、东边匹克球、球员草坪和棕榈喷泉，
东墙大门外是代客泊车和停车场；画法是饱和的体素、不投阴影、画出来的天空和山、像素字体的 HUD。
原来的 Indian Wells 网球园区是按真实场馆摆的：三座体育场、208 × 152 米、浅沙色。

## 决定

**地图照参考图重排，模拟的设施和锚点 id 不变，名字和画面换掉。**

| 设施 id | 原来 | 现在 | 变化 |
| --- | --- | --- | --- |
| `stadium_1` | Stadium 1 | 中心球场 | 表演赛和通关条件不变 |
| `practice` | 练习场 | 青训场（两块硬地，发球机、球筐） | |
| `outer_1` | 外场 1 | 会员场（喷雾杆、遮阳帆） | |
| `outer_23` | 外场 2–3 | 红土场（两块） | |
| `clubhouse` | 会所 | 会所和露台餐厅 | |
| `plaza` | 广场 | 棕榈喷泉 | 球员草坪归它（烧烤会演在草坪上） |
| `stadium_3` | 下沉的 Stadium 3 | 匹克球场（两片） | 联赛演匹克球 |
| `stadium_2` | Stadium 2 | 泳池和小木屋 | 不再算球场（`courts` 去掉）；岗位改成小木屋服务、水中健身课，不演球场上的活动 |

- 复原目标仍是 0/8；存档、工单、卡、岗位的 id 都不变，旧档能直接读。
- 俱乐部改名 Palm Oasis 网球俱乐部 / Palm Oasis Racquet Club（不用真实场馆的名字）；内容里地图 id 仍是 `indian_wells`。
- 地图变小（围墙内 124 × 95 米），走路速度从 3 改成 1.6 米/游戏分钟，地点之间的平均分钟数和原来差不多（41 → 42）；
  内容里的 `nav` 按新步道重新生成，`game.test` 检查两边一致。
- 画面：不投阴影；天空、山脊和一天的光（早晨、白天、黄昏、夜里）跟游戏时钟走（`world/daylight.ts`）；
  灯头、窗户、串灯在夜里亮。渲染保持全分辨率（参考图的 Fine 档）。
- 球员草坪、高尔夫、墙外沙漠只是景观。

## 后果

- `packages/render/src/scenes/indian-wells/` 的 layout、build、overlays、wear、ambient 重写；导出名（`F_O1` 等）保留，测试和 app 不用改引用。
- 泳池不算球场：会员上限少一块场地，平衡报告重跑。
- 文案（中英）里所有地名换掉；卡的正文里提到体育场的地方按新设施改写。

"高尔夫只是景观"：ADR 0021（提议）让 ★3 收回南墙外高尔夫的西段，变成南场或绿洲草坪。采纳以后这一条跟着改。
